# Build-your-app

A growing collection of small, focused projects:

- `Tools/` — browser-only utilities for everyday development work
- `Templates/` — starter projects for many stacks and languages

Open `Tools/index.html` in a browser to get started, or browse a template from `Templates/<Category>/<Template>/`.

## Tools

See `Tools/index.html` for the full list. Highlights:

- API Tester — REST client with history
- Base64 Tool — encode / decode text or files
- Color Palette — generate schemes and export CSS variables
- Cron Parser — explain cron expressions and preview the next fires
- Diff Viewer — unified or side-by-side text diff
- Hex Viewer — inspect files as raw bytes
- HTML Entities — encode / decode named, decimal, and hex entities
- JSON Formatter — pretty-print, minify, and validate JSON
- JWT Decoder — inspect JWT header, payload, and claims
- Lorem Ipsum — placeholder text generator
- Markdown Preview — live editor with side-by-side rendering
- Password Generator — strong passwords with entropy meter
- Regex Tester — live highlighting and capture groups
- SVG Optimizer — strip comments, metadata, and whitespace
- Timestamp Tool — convert between Unix, ISO, and human dates
- URL Encoder — percent-encode / decode for components, paths, and forms
- UUID Generator — v4 / v7 in hyphen, urn, hex, or base36
- Website To EXE — wrap a website into a Windows executable

## Templates

`Templates/` is organized by category (AI, Architecture, Bots, Browser-Extensions, CLI, Cybersecurity, Databases, Desktop, DevOps, Embedded, Engines, Frameworks, Languages, Minecraft, Mobile, Tools, Web, Web-Apps). Each template has a `README.md` with a description, feature list, and usage notes in German and English.
