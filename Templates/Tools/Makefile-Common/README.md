# Makefile Pack

> Wiederverwendbare Makefile-Snippets für typische Tasks. / Reusable Makefile snippets for typical tasks.

## Features
- `make help` zur Übersicht / `make help` for overview
- Standard-Targets für Build/Test/Clean / Standard targets for build/test/clean
- Konfigurierbar per ENV / Configurable via env

## How to Use
```bash
cd Makefile-Common
cp Makefile.node Makefile  # or any other target
make help
```

## Tech Stack
- GNU Make

## Extension Ideas
- Docker-Targets / Docker targets
- Release-Target mit Tagging / Release target with tagging
- Self-Documented Makefile / Self-documented Makefile
