# GitHub Actions Node Template

> CI-Workflow für Node.js mit Lint, Test und Build. / CI workflow for Node.js with lint, test, and build.

## Features
- Trigger auf Push und PR / Trigger on push and PR
- Matrix über Node-Versionen / Matrix over Node versions
- Artifact-Upload / Artifact upload

## How to Use
Kopiere `.github/workflows/ci.yml` in dein Repo. / Copy `.github/workflows/ci.yml` into your repo.

## Tech Stack
- GitHub Actions
- Node.js
