# Arduino Blink Template

> Klassisches Arduino-Blink mit klarer Struktur. / Classic Arduino blink with clean structure.

## Features
- setup() und loop() / setup() and loop()
- Konfigurierbare Pin-Nummer / Configurable pin number
- Saubere Hilfsfunktionen / Clean helper functions

## How to Use
Öffne `sketch.ino` in der Arduino IDE und lade es auf dein Board hoch. / Open `sketch.ino` in the Arduino IDE and upload it to your board.

## Tech Stack
- Arduino (C/C++)

## Extension Ideas
- Mehrere LEDs / Multiple LEDs
- Sensor-Input lesen / Read sensor input
- Sleep-Mode für Batteriebetrieb / Sleep mode for battery operation
