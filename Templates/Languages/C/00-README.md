# C-Vorlagen / C Templates

Willkommen bei den C-Projektvorlagen. Diese Vorlagen decken CLI, Spiele, Grafik,
Netzwerk, Systemwerkzeuge, eingebettete Systeme und Datenstrukturen ab.
Jede Vorlage verwendet C23/C11 mit ordnungsgemäßer Speicherverwaltung und Header-Guards.

Welcome to the C project templates. These templates cover CLI, games, graphics,
networking, system tools, embedded systems, and data structures. Each template
uses C23/C11 with proper memory management and header guards.

## Verfügbare Vorlagen / Available Templates
- **CLI-Tool** – Kommandozeilenwerkzeug
- **CLI-Game** – Konsolenspiel
- **Game-SDL2** – Spiel mit SDL2
- **Graphics-OpenGL** – OpenGL-Grafik
- **Network-Server** – TCP-Server
- **Network-Client** – TCP-Client
- **SystemTool** – Systemwerkzeug
- **Embedded** – Eingebettet (AVR/ARM)
- **DataStructure** – Datenstrukturen
