# AIOHTTP Template

> Async Webserver mit aiohttp. / Async web server with aiohttp.

## Features
- Async Request-Handler / Async request handlers
- JSON-Antworten / JSON responses
- In-Memory-TODO-Resource / In-memory TODO resource
- Statischer File-Serve / Static file serving

## How to Use
```bash
cd Web-AIOHTTP
pip install -r requirements.txt
python app.py
```

## Tech Stack
- Python 3.11+
- aiohttp
