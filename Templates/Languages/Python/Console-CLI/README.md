# Console-CLI Template

> Einfache CLI-Anwendung in Python. / Basic CLI application in Python.

## Features
- Einfacher, sofort nutzbarer CLI-Einstieg / Simple, ready-to-use CLI entry point
- Typisierte Ausgaben mit `rich` (optional) / Typed output with `rich` (optional)
- Fehlerbehandlung / Error handling
- UTF-8 Support

## How to Use
```bash
cd Console-CLI
python main.py
```

## Tech Stack
- Python 3.11+
- `rich` (optional, für bessere Ausgabe)
