# Network-Scraper Template

> Web Scraper mit requests und BeautifulSoup. / Web scraper with requests and BeautifulSoup.

## Features
- HTTP-GET-Anfragen / HTTP GET requests
- HTML-Parsing mit BeautifulSoup / HTML parsing with BeautifulSoup
- Extraktion von Links, Text, Tabellen / Extract links, text, tables
- Fehlerbehandlung / Error handling
- User-Agent-Steuerung / User agent control

## How to Use
```bash
cd Network-Scraper
pip install -r requirements.txt
python scraper.py
```

## Tech Stack
- Python 3.11+
- requests
- beautifulsoup4
