# Web-Streamlit Template

> Daten-App mit Streamlit (schnelle UI aus reinem Python). / Data app with Streamlit (quick UI from pure Python).

## Features
- Kein HTML/JS nötig / No HTML/JS needed
- Widgets (Slider, Button, Charts) / Widgets (slider, button, charts)
- Reaktives Caching / Reactive caching
- Integrierte Chart-Unterstützung / Built-in chart support

## How to Use
```bash
cd Web-Streamlit
pip install -r requirements.txt
streamlit run app.py
```

## Tech Stack
- Python 3.11+
- Streamlit
- Pandas (optional)
