# Web-Flask Template

> Webanwendung mit Flask (minimalistisches Web-Framework). / Web application with Flask (minimalist web framework).

## Features
- Routen und Templates / Routes and templates
- Jinja2-Templating
- GET/POST-Verarbeitung / GET/POST handling
- Entwicklungsserver / Development server

## How to Use
```bash
cd Web-Flask
pip install -r requirements.txt
python app.py
# Open http://127.0.0.1:5000
```

## Tech Stack
- Python 3.11+
- Flask
- Jinja2
