# PyTorch Template

> Minimaler Trainingsloop für PyTorch. / Minimal training loop for PyTorch.

## Features
- Dataset- und DataLoader-Setup / Dataset and DataLoader setup
- Trainings- und Evaluationsschritte / Training and evaluation loops
- Modell-Checkpointing / Model checkpointing
- Konfiguration über dict / Configuration via dict

## How to Use
```bash
cd ML-PyTorch
pip install -r requirements.txt
python train.py
```

## Tech Stack
- Python 3.11+
- PyTorch

## Extension Ideas
- Hydra / OmegaConf für Configs / Hydra / OmegaConf for configs
- Weights & Biases Logging / Weights & Biases logging
- Mixed-Precision-Training / Mixed-precision training
