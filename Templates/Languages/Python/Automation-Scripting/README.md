# Automation-Scripting Template

> Datei-/OS-Automation mit pathlib und shutil. / File/OS automation with pathlib and shutil.

## Features
- Dateien erstellen, kopieren, verschieben / Create, copy, move files
- Verzeichnisstruktur-Manipulation / Directory structure manipulation
- Datumsbasierte Organisation / Date-based organization
- Batch-Operationen / Batch operations

## How to Use
```bash
cd Automation-Scripting
python automate.py
```

## Tech Stack
- Python 3.11+
- pathlib, shutil, os (Standardbibliothek)

## Extension Ideas
- Watchdog für Echtzeit-Überwachung / Watchdog for real-time monitoring
- ZIP-Archivierung / ZIP archiving
- Logging in Datei / Logging to file
- Konfiguration via JSON/YAML / Configuration via JSON/YAML
