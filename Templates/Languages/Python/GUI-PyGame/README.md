# GUI-PyGame Template

> Grafikfenster mit Pygame (ideal für Spiele und Visualisierungen). / Graphics window with Pygame (ideal for games and visualizations).

## Features
- Game-Loop mit fester FPS / Game loop with fixed FPS
- Ereignisverarbeitung (Tastatur, Maus) / Event processing (keyboard, mouse)
- Bildschirm-Zeichnen / Screen drawing
- Grundlegendes Rendering / Basic rendering

## How to Use
```bash
cd GUI-PyGame
pip install -r requirements.txt
python main.py
```

## Tech Stack
- Python 3.11+
- Pygame

- Sound-Effekte / Sound effects
