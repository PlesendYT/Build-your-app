# TelegramBot Template

> Telegram-Bot mit python-telegram-bot. / Telegram bot with python-telegram-bot.

## Features
- Command-Handler (/start, /help) / Command handlers (/start, /help)
- Message-Handler / Message handlers
- Async/await Architektur / Async/await architecture
- Environment-Variablen für Token / Environment variables for token

## How to Use
```bash
cd TelegramBot
pip install -r requirements.txt
# Set TELEGRAM_TOKEN environment variable
python bot.py
```

## Tech Stack
- Python 3.11+
- python-telegram-bot
