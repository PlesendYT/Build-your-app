# GUI-Kivy Template

> Mobile-ready App mit Kivy. / Mobile-ready app with Kivy.

## Features
- Touch-freundliche UI / Touch-friendly UI
- .kv-Datei für Layout-Trennung / .kv file for layout separation
- Plattformunabhängig (Desktop + Mobile) / Cross-platform (desktop + mobile)
- Widget-Baum / Widget tree

## How to Use
```bash
cd GUI-Kivy
pip install -r requirements.txt
python main.py
```

## Tech Stack
- Python 3.11+
- Kivy

## Extension Ideas
- `Buildozer` für Android-APK / `Buildozer` for Android APK
- `KivyMD` für Material Design
- Mehrere Screens / Multiple screens
- Datenanbindung / Data binding
