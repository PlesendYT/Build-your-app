# Game-Pygame Template

> Vollständiges Pygame-Spiel mit Spieler, Gegnern und Kollisionen. / Full Pygame game with player, enemies, and collisions.

## Features
- Game-Loop mit fester FPS / Game loop with fixed FPS
- Spieler-Steuerung (Pfeiltasten) / Player controls (arrow keys)
- Gegner-Spawning und -Bewegung / Enemy spawning and movement
- Kollisionserkennung / Collision detection
- Punkte-System / Score system
- Game-Over-Zustand / Game over state

## How to Use
```bash
cd Game-Pygame
pip install -r requirements.txt
python main.py
```

## Tech Stack
- Python 3.11+
- Pygame
