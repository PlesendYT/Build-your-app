# GUI-Tkinter Template

> Desktop-Anwendung mit Tkinter (Standard-GUI-Bibliothek). / Desktop application with Tkinter (standard GUI library).

## Features
- Fenster mit Titel und Größe / Window with title and size
- Button, Label, Entry Widgets
- Ereignisgesteuerte Programmierung / Event-driven programming
- Plattformunabhängig / Cross-platform

## How to Use
```bash
cd GUI-Tkinter
python main.py
```

## Tech Stack
- Python 3.11+
- `tkinter` (Standardbibliothek)

## Extension Ideas
- `ttk` für modernere Widgets / `ttk` for modern widgets
- Mehrere Fenster / Multiple windows
- Menüleiste / Menu bar
- Dateidialoge / File dialogs
