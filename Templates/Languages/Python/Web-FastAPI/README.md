# Web-FastAPI Template

> REST-API mit FastAPI (async, automatische Docs). / REST API with FastAPI (async, automatic docs).

## Features
- Automatische OpenAPI-Dokumentation / Automatic OpenAPI docs
- Async/await Support
- Pydantic-Modelle für Validierung / Pydantic models for validation
- Interaktive Swagger-UI / Interactive Swagger UI

## How to Use
```bash
cd Web-FastAPI
pip install -r requirements.txt
python main.py
# Open http://127.0.0.1:8000/docs
```

## Tech Stack
- Python 3.11+
- FastAPI
- Pydantic
- Uvicorn
