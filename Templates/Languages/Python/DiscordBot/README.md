# DiscordBot Template

> Discord-Bot mit discord.py (Slash-Commands). / Discord bot with discord.py (slash commands).

## Features
- Slash-Command-Support / Slash command support
- Cogs für modulare Struktur / Cogs for modular structure
- Environment-Variablen für Token / Environment variables for token
- On_ready Event

## How to Use
```bash
cd DiscordBot
pip install -r requirements.txt
# Set DISCORD_TOKEN environment variable
python bot.py
```

## Tech Stack
- Python 3.11+
- discord.py
