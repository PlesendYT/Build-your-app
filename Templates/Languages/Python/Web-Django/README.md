# Web-Django Template

> Vollständiges Django-Projekt. / Full Django project.

## Features
- Projektstruktur mit `manage.py` / Project structure with `manage.py`
- Eigene App mit View / Custom app with view
- URL-Routing / URL routing
- Bereit für Datenbank-Migrationen / Ready for database migrations

## How to Use
```bash
cd Web-Django
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
# Open http://127.0.0.1:8000
```

## Tech Stack
- Python 3.11+
- Django
