# GUI-PyQt Template

> Desktop-Anwendung mit PyQt6. / Desktop application with PyQt6.

## Features
- Moderne Qt6-Widgets / Modern Qt6 widgets
- Signal-Slot-Architektur / Signal-slot architecture
- Hauptfenster mit Menüleiste / Main window with menu bar
- Layout-Management / Layout management

## How to Use
```bash
cd GUI-PyQt
pip install -r requirements.txt
python main.py
```

## Tech Stack
- Python 3.11+
- PyQt6

## Extension Ideas
- `Qt Designer` .ui-Dateien / `Qt Designer` .ui files
- Datenbankanbindung / Database connectivity
- Grafiken mit `QtCharts` / Graphics with `QtCharts`
- Mehrsprachigkeit / Internationalization
