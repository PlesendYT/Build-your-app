# DataScience-Analysis Template

> Datenanalyse mit Pandas, Matplotlib und Seaborn. / Data analysis with Pandas, Matplotlib, and Seaborn.

## Features
- DataFrames importieren und erkunden / Import and explore DataFrames
- Statistische Zusammenfassungen / Statistical summaries
- Visualisierungen (Linien-, Balken-, Streudiagramme) / Visualizations (line, bar, scatter plots)
- Jupyter-Notebook-kompatibel / Jupyter notebook compatible

## How to Use
```bash
cd DataScience-Analysis
pip install -r requirements.txt
python analysis.py
python notebook.py  # Interactive exploration
```

## Tech Stack
- Python 3.11+
- Pandas
- Matplotlib
- Seaborn
- NumPy
