# Automation-Testing Template

> Testautomatisierung mit pytest. / Test automation with pytest.

## Features
- Unit-Tests mit pytest / Unit tests with pytest
- Parametrisierte Tests / Parametrized tests
- Fixtures für Testsetup / Fixtures for test setup
- Ausführlicher Testreport / Verbose test report

## How to Use
```bash
cd Automation-Testing
pip install -r requirements.txt
pytest -v
```

## Tech Stack
- Python 3.11+
- pytest

## Extension Ideas
- Code Coverage (pytest-cov) / Code coverage (pytest-cov)
- Mocking (unittest.mock) / Mocking (unittest.mock)
- Integrationstests / Integration tests
- CI/CD-Anbindung / CI/CD integration
