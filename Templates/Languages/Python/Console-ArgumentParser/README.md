# Console-ArgumentParser Template

> CLI mit `argparse` für professionelle Kommandozeilenargumente. / CLI with `argparse` for professional command-line arguments.

## Features
- Strukturierte Argument-Definition / Structured argument definition
- Hilfe-Text automatisch generiert / Auto-generated help text
- Typsichere Parameter / Type-safe parameters
- Subcommands möglich / Subcommands possible

## How to Use
```bash
cd Console-ArgumentParser
python main.py --name Alice --count 3
python args.py --help
```

## Tech Stack
- Python 3.11+
- `argparse` (Standardbibliothek)

## Extension Ideas
- `click` oder `typer` als Alternative / `click` or `typer` as alternative
- Konfigurationsdateien / Configuration files
- Environment-Variablen / Environment variables
