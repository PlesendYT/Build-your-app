# Console-Interactive Template

> Interaktive Konsolenanwendung mit Menüführung. / Interactive console application with menu navigation.

## Features
- Endlos-Loop mit Exit-Option / Infinite loop with exit option
- Benutzereingabe-Verarbeitung / User input processing
- Klare Menüstruktur / Clear menu structure
- Fehlertolerante Eingabe / Fault-tolerant input

## How to Use
```bash
cd Console-Interactive
python main.py
```

## Tech Stack
- Python 3.11+
- `sys` / `os` Standardbibliothek

## Extension Ideas
- `curses` für TUI / `curses` for TUI
- Befehlshistorie / Command history
- Plugin-System / Plugin system
