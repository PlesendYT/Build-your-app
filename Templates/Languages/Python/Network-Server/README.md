# Network-Server Template

> TCP/HTTP-Server in Python. / TCP/HTTP server in Python.

## Features
- TCP-Echo-Server / TCP echo server
- HTTP-Server mit http.server / HTTP server with http.server
- Multi-Client-fähig (Threading) / Multi-client capable (threading)
- Socket-Programmierung / Socket programming

## How to Use
```bash
cd Network-Server
python server.py
# In another terminal: nc 127.0.0.1 8888
```

## Tech Stack
- Python 3.11+
- socket (Standardbibliothek)
- threading (Standardbibliothek)
