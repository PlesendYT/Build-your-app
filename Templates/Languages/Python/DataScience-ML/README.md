# DataScience-ML Template

> Maschinelles Lernen mit scikit-learn (Pipeline). / Machine learning with scikit-learn (pipeline).

## Features
- Train-Test-Split / Train-test split
- Preprocessing-Pipeline / Preprocessing pipeline
- Modelltraining und Evaluation / Model training and evaluation
- Metriken (Genauigkeit, Klassifikationsreport) / Metrics (accuracy, classification report)

## How to Use
```bash
cd DataScience-ML
pip install -r requirements.txt
python train.py
```

## Tech Stack
- Python 3.11+
- scikit-learn
- Pandas
- NumPy
