# Lua Scripting

🇩🇪 Allgemeines Lua-Scripting-Projekt für Datenverarbeitung, Datei-I/O und Automation.

🇬🇧 General Lua scripting project for data processing, file I/O, and automation.

## Features
- Datei-Lesen/Schreiben
- CSV-Parsing
- JSON-Verarbeitung (mit dkjson)
- Template-Engine
- Kommandozeilen-Argumente

## How to use
```bash
lua src/process.lua input.csv output.json
```

## Tech stack
- Lua 5.4
- dkjson (LuaRocks)
- Standard Libraries
