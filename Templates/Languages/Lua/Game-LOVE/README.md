# Lua Game-LOVE

🇩🇪 2D-Spiel mit LÖVE (Love2D) Framework für Lua.

🇬🇧 2D game with LÖVE (Love2D) framework for Lua.

## Features
- LÖVE Game Loop (load, update, draw)
- Spieler-Steuerung (Tastatur)
- Kollisionserkennung
- Partikel-Effekte
- Punktestand

## How to use
```bash
love src/
```

## Tech stack
- Lua 5.1/LuaJIT
- LÖVE 11.x
