# Lua CLI-Tool

🇩🇪 Kommandozeilen-Tool in Lua 5.4 mit Argument-Parsing und modularem Aufbau.

🇬🇧 Command-line tool in Lua 5.4 with argument parsing and modular structure.

## Features
- Argument-Parsing
- Modulare Befehlsstruktur
- Farbige Ausgabe (ANSI)
- Fehlerbehandlung

## How to use
```bash
lua src/main.lua greet Welt
lua src/main.lua calc add 5 3
```

## Tech stack
- Lua 5.4
- LuaRocks (optional)

## Extension ideas
- Add JSON (dkjson)
- Add HTTP requests (lua-http)
- Add Readline support (lua-readline)
