# ASP.NET Core MVC Template

> Razor-Pages-Stil-Webapp mit ASP.NET Core. / Razor-pages-style web app with ASP.NET Core.

## Features
- Razor-View mit Layout / Razor view with layout
- Model-Binding für GET-Formulare / Model binding for GET forms
- Tag-Helpers / Tag helpers

## How to Use
```bash
cd Web-MVC
dotnet run
# Open http://localhost:5xxx
```

## Tech Stack
- .NET 8
- ASP.NET Core MVC
