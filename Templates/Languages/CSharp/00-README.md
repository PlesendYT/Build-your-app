# C#-Vorlagen / C# Templates

Willkommen bei den C#-Projektvorlagen. Diese Vorlagen decken Konsolen-Apps,
REST-APIs, Desktop-GUIs (WPF, MAUI, WinForms), Spiele (MonoGame, Stride, Unity)
und Desktop-Werkzeuge ab. Jede Vorlage verwendet C# 12 mit .NET 8, async/await
und LINQ.

Welcome to the C# project templates. These templates cover console apps,
REST APIs, desktop GUIs (WPF, MAUI, WinForms), games (MonoGame, Stride, Unity),
and desktop tools. Each template uses C# 12 with .NET 8, async/await, and LINQ.

## Verfügbare Vorlagen / Available Templates
- **Console-CLI** – Konsolen-CLI
- **RESTAPI-ASP** – REST-API mit ASP.NET Core
- **GUI-WPF** – Desktop-GUI mit WPF
- **GUI-MAUI** – Multiplattform-App mit .NET MAUI
- **GUI-WinForms** – Desktop-GUI mit WinForms
- **Game-MonoGame** – Spiel mit MonoGame
- **Game-Stride** – Spiel mit Stride
- **Unity-Script** – Unity-Skript
- **Desktop-Tool** – Desktop-Werkzeug
