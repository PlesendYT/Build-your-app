# Nim-Vorlagen / Nim Templates

Willkommen bei den Nim-Projektvorlagen. Diese Vorlagen decken die häufigsten
Anwendungsfälle ab: CLI-Tools, GUIs, Spiele, Web-Server und Systemwerkzeuge.
Jede Vorlage verwendet modernes Nim mit ordnungsgemäßer Modulstruktur,
Typklassen und idiomatischem Code.

Welcome to the Nim project templates. These templates cover the most common
use cases: CLI tools, GUIs, games, web servers, and system tools. Each template
uses modern Nim with proper module structure, type classes, and idiomatic code.

## Verfügbare Vorlagen / Available Templates

- **CLI-Tool** – Kommandozeilenwerkzeug mit parseopt
- **GUI** – Desktop-GUI mit NiGui
- **Game** – 2D-Spiel mit Raylib-Nim
- **WebServer** – HTTP-Server mit Jester/AsyncDispatch
- **SystemTool** – Systemüberwachung mit Laufzeitinformationen
