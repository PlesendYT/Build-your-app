# Game

**Deutsch:** Ein 2D-Spiel in Nim mit Raylib-Nim. Enthält Spielersteuerung,
Kollisionserkennung und Punktesystem.

**English:** A 2D game in Nim with Raylib-Nim. Includes player controls,
collision detection, and scoring system.

## Features
- Raylib-Rendering (DE) / Raylib rendering (EN)
- Tastatur-Steuerung (DE) / Keyboard controls (EN)
- Kollisionserkennung (DE) / Collision detection (EN)
- Highscore-Tracking (DE) / High score tracking (EN)

## Verwendung / Usage
```bash
nimble run
```

## Tech Stack
Nim 2.0+, raylib-nim, math
