# GUI

**Deutsch:** Eine Desktop-GUI-App in Nim mit NiGui. Enthält Fensterverwaltung,
Buttons, Textfelder und Menüs.

**English:** A desktop GUI app in Nim with NiGui. Includes window management,
buttons, text fields, and menus.

## Features
- Hauptfenster mit Menüleiste (DE) / Main window with menu bar (EN)
- Button- und Textfeld-Steuerelemente (DE) / Button and text field controls (EN)
- Ereignisbehandlung (DE) / Event handling (EN)
- Dialogfenster (DE) / Dialog windows (EN)

## Verwendung / Usage
```bash
nimble run
```

## Tech Stack
Nim 2.0+, NiGui, os
