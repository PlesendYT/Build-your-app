# Web-Angular — Angular + TypeScript

## Beschreibung
Angular Standalone-Komponente mit TypeScript. Modernes Angular mit Signals und Control Flow.

## Description
Angular standalone component with TypeScript. Modern Angular with signals and control flow.

---

## Features
- Angular 19 Standalone API
- TypeScript strict
- Signals (Reaktivität)
- HTTP Client
- Control Flow (@if, @for)

## How to use / Verwendung
```bash
cd Web-Angular
npm install
npx ng serve
```

## Tech Stack
- Angular 19
- TypeScript 5 (strict)
- Angular CLI
- RxJS

## Extension ideas / Erweiterungsideen
- Angular Router
- Reactive Forms
- Angular Material
- NgRx / Signal Store
