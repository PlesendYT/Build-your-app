# CLI — TypeScript CLI Tool

## Beschreibung
Kommandozeilenwerkzeug mit TypeScript, strikten Typen und modernem async/await. Kompiliert mit `tsc`.

## Description
Command-line tool with TypeScript, strict types, and modern async/await. Compiles with `tsc`.

---

## Features
- Strikte TypeScript-Typen
- Kommando-Parsing
- Dateioperationen mit `fs/promises`
- Farbige Terminal-Ausgabe
- Fehlerbehandlung

## How to use / Verwendung
```bash
cd CLI
npm install
npm run build
npm start -- --help
```

## Tech Stack
- TypeScript 5 (strict)
- Node.js 20+
- ESM
