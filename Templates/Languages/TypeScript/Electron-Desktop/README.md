# Electron-Desktop — Electron + TypeScript

## Beschreibung
Desktop-Anwendung mit Electron und TypeScript. Hauptprozess, Renderer, Preload mit IPC.

## Description
Desktop application with Electron and TypeScript. Main process, renderer, preload with IPC.

---

## Features
- Electron Hauptprozess (TypeScript)
- Renderer-Prozess
- Preload mit Context Bridge
- IPC-Kommunikation
- Strikt typisiert

## How to use / Verwendung
```bash
cd Electron-Desktop
npm install
npm run dev
```

## Tech Stack
- Electron 33
- TypeScript 5 (strict)
- Node.js 20+
