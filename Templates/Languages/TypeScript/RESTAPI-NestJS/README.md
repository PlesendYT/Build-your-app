# RESTAPI-NestJS — NestJS REST API

## Beschreibung
NestJS REST API mit Modulen, Controllern und Services. Verwendet Decorator-basierte Architektur.

## Description
NestJS REST API with modules, controllers, and services. Uses decorator-based architecture.

---

## Features
- NestJS CLI-Struktur
- Module / Controller / Services
- Pipes für Validierung
- OpenAPI (Swagger) Unterstützung
- Dependency Injection

## How to use / Verwendung
```bash
cd RESTAPI-NestJS
npm install
npm run start:dev
# http://localhost:3000/api/users
```

## Tech Stack
- NestJS 11
- TypeScript 5
- Express (default)
