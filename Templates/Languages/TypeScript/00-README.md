# TypeScript Templates — Übersicht / Overview

Diese Vorlagen bieten fertige Startprojekte für verschiedene TypeScript-Anwendungen mit strikten Typen und modernen Patterns.

These templates provide ready-to-use starter projects for various TypeScript applications with strict types and modern patterns.

---

## Verzeichnisse / Directories

| Verzeichnis | Beschreibung | Description |
|---|---|---|
| **CLI** | TypeScript CLI Tool | Kommandozeilenwerkzeug |
| **RESTAPI-Express** | Express + TS | Express REST-Schnittstelle |
| **RESTAPI-NestJS** | NestJS REST API | NestJS REST-Schnittstelle |
| **Web-React** | React + TS | React SPA mit TypeScript |
| **Web-Vue** | Vue 3 + TS | Vue 3 Composition API |
| **Web-Angular** | Angular + TS | Angular Standalone-Komponente |
| **Web-NextJS** | Next.js App | Next.js App Router |
| **Game-Phaser** | Phaser 3 + TS | Phaser 3 Spiel |
| **DiscordBot** | Discord Bot + TS | discord.js Bot |
| **Electron-Desktop** | Electron + TS | Desktop-Anwendung |

## Verwendung / Usage

Jedes Verzeichnis enthält eine `package.json` und Quelldateien:

```bash
cd <template-name>
npm install
npm run dev      # Entwicklung
npm run build    # Produktion
npm start        # Ausführung
```
