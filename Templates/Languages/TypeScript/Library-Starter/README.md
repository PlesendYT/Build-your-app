# TypeScript Library Template

> npm-Bibliothek mit TypeScript und tsup. / npm library with TypeScript and tsup.

## Features
- ESM- und CJS-Build / ESM and CJS build
- Type-Declarations / Type declarations
- Vitest für Tests / Vitest for tests
- ESLint + Prettier / ESLint + Prettier

## How to Use
```bash
cd Library-Starter
npm install
npm test
npm run build
```

## Tech Stack
- TypeScript 5
- tsup, vitest

## Extension Ideas
- Changesets für Versionierung / Changesets for versioning
- GitHub-Actions für CI / GitHub Actions for CI
- tsup-Plugins für Banner / tsup plugins for banner
