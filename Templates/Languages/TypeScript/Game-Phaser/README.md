# Game-Phaser — Phaser 3 + TypeScript

## Beschreibung
Ein Spiel mit Phaser 3 Game Engine und TypeScript. Szenen-Management, Arcade Physics und Asset-Loading.

## Description
A game built with Phaser 3 game engine and TypeScript. Scene management, arcade physics, and asset loading.

---

## Features
- Phaser 3 Arcade Physics
- Szenen-Management
- TypeScript strict
- Spielersteuerung
- Partikel-Effekte

## How to use / Verwendung
```bash
cd Game-Phaser
npm install
npm run dev
```

## Tech Stack
- Phaser 3
- TypeScript 5 (strict)
- Vite
- Canvas/WebGL
