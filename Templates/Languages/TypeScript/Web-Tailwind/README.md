# Tailwind + Vite + TS Template

> Tailwind-CSS mit Vite und TypeScript. / Tailwind CSS with Vite and TypeScript.

## Features
- Vite-Dev-Server mit HMR / Vite dev server with HMR
- Tailwind 3 mit JIT / Tailwind 3 with JIT
- Beispielkomponente / Example component

## How to Use
```bash
cd Web-Tailwind
npm install
npm run dev
```

## Tech Stack
- Vite, TypeScript, Tailwind CSS

- PostCSS-Plugins / PostCSS plugins
