# DiscordBot — discord.js + TypeScript

## Beschreibung
Discord Bot mit discord.js v14 und TypeScript. Slash-Commands, Event-Handling, Embeds.

## Description
Discord bot with discord.js v14 and TypeScript. Slash commands, event handling, embeds.

---

## Features
- discord.js v14
- TypeScript strict
- Slash-Commands
- Event-Handler
- Embed-Nachrichten

## How to use / Verwendung
1. Bot erstellen auf https://discord.com/developers
2. `export DISCORD_TOKEN=...`
3. ```bash
   cd DiscordBot
   npm install
   npm run dev
   ```

## Tech Stack
- discord.js v14
- TypeScript 5 (strict)
- Node.js 20+
