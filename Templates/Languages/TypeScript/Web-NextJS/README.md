# Web-NextJS — Next.js App

## Beschreibung
Next.js App mit App Router, TypeScript und Server Components. Modernes React-Framework mit SSR.

## Description
Next.js app with App Router, TypeScript, and Server Components. Modern React framework with SSR.

---

## Features
- Next.js App Router
- TypeScript strict
- Server & Client Components
- API-Routes
- CSS Modules

## How to use / Verwendung
```bash
cd Web-NextJS
npm install
npm run dev
# http://localhost:3000
```

## Tech Stack
- Next.js 15
- React 19
- TypeScript 5
- CSS Modules
