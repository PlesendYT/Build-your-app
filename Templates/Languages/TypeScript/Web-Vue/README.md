# Web-Vue — Vue 3 + TypeScript

## Beschreibung
Vue 3 SPA mit TypeScript, Composition API und `<script setup lang="ts">`.

## Description
Vue 3 SPA with TypeScript, Composition API, and `<script setup lang="ts">`.

---

## Features
- Vue 3 + TypeScript
- `<script setup lang="ts">`
- Vite Build
- Scoped CSS

## How to use / Verwendung
```bash
cd Web-Vue
npm install
npm run dev
```

## Tech Stack
- Vue 3
- TypeScript 5 (strict)
- Vite
- Vue Router (optional)
