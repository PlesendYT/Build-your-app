# Web-React — React + TypeScript

## Beschreibung
React SPA mit TypeScript. Funktionale Komponenten mit strikten Typen, Hooks und Vite.

## Description
React SPA with TypeScript. Functional components with strict types, hooks, and Vite.

---

## Features
- React 19 + TypeScript
- Vite Build
- Strict Types
- CSS Modules
- Hot Module Replacement

## How to use / Verwendung
```bash
cd Web-React
npm install
npm run dev
```

## Tech Stack
- React 19
- TypeScript 5 (strict)
- Vite
- CSS Modules

- React Router

- React Query / SWR
