# RESTAPI-Express — Express + TypeScript

## Beschreibung
Express REST API mit TypeScript. Strikte Typen, CRUD-Endpunkte, Middleware und Fehlerbehandlung.

## Description
Express REST API with TypeScript. Strict types, CRUD endpoints, middleware, and error handling.

---

## Features
- Express.js mit TypeScript
- Strict Types
- CRUD-Endpunkte
- Middleware
- CORS

## How to use / Verwendung
```bash
cd RESTAPI-Express
npm install
npm run dev       # Entwicklung (tsx --watch)
npm run build     # Produktion
npm start         # dist/index.js ausführen
```

## Tech Stack
- Express.js 5
- TypeScript 5 (strict)
- Node.js 20+
