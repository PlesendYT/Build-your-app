# Embedded

**Deutsch:** Embedded-Rust-Vorlage für Mikrocontroller (no_std). Basis
für Cortex-M-basierte Projekte mit embedded-hal.

**English:** Embedded Rust template for microcontrollers (no_std). Base
for Cortex-M-based projects with embedded-hal.

## Features
- no_std-Umgebung (DE) / no_std environment (EN)
- Cortex-M-Unterstützung (DE) / Cortex-M support (EN)
- embedded-hal-Schnittstellen (DE) / embedded-hal interfaces (EN)

## Verwendung / Usage
```bash
cargo build --target thumbv7em-none-eabihf
```

## Tech Stack
Rust 2024, cortex-m, cortex-m-rt, embedded-hal
