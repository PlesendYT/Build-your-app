# CLI-Game

**Deutsch:** Ein einfaches Konsolenspiel (Zahlenraten) in Rust. Demonstriert
Schleifen, Benutzereingabe und Zufallszahlen.

**English:** A simple console number-guessing game in Rust. Demonstrates loops,
user input handling, and random numbers.

## Features
- Zufallszahlengenerierung (DE) / Random number generation (EN)
- Eingabevalidierung (DE) / Input validation (EN)
- Versuchszähler (DE) / Attempt counter (EN)

## Verwendung / Usage
```bash
cargo run
```

## Tech Stack
Rust 2024, rand, anyhow
