# Game-Macroquad

**Deutsch:** Ein einfaches 2D-Spiel mit Macroquad. Sammle Münzen mit
den Pfeiltasten ein.

**English:** A simple 2D game with Macroquad. Collect coins using the
arrow keys.

## Features
- 2D-Grafik (DE/EN)
- Kollisionserkennung (DE) / Collision detection (EN)
- Bildschirmbegrenzung (DE) / Screen boundary (EN)

## Verwendung / Usage
```bash
cargo run
```

## Tech Stack
Rust 2024, Macroquad 0.4, rand
