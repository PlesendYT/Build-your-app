# Rust-Vorlagen / Rust Templates

Willkommen bei den Rust-Projektvorlagen. Diese Vorlagen decken die häufigsten
Anwendungsfälle ab: CLI, Web, GUI, Spiele, Systemwerkzeuge, vernetzte Anwendungen
und eingebettete Systeme. Jede Vorlage verwendet die Rust 2024 Edition mit
modernen Idiomen, ordnungsgemäßer Fehlerbehandlung und idiomatischem Code.

Welcome to the Rust project templates. These templates cover the most common
use cases: CLI, Web, GUI, Games, System Tools, Networked Applications, and
Embedded Systems. Each template uses the Rust 2024 Edition with modern idioms,
proper error handling, and idiomatic code.

## Verfügbare Vorlagen / Available Templates

- **CLI-Tool** – Kommandozeilenwerkzeug mit clap
- **CLI-Game** – Konsolenspiel (z. B. TicTacToe)
- **WebServer-Actix** – REST-API mit Actix-Web
- **WebServer-Rocket** – REST-API mit Rocket
- **WebServer-Axum** – REST-API mit Axum
- **GUI-Egui** – GUI mit egui (immediate mode)
- **GUI-Gtk** – GUI mit GTK4
- **GUI-Tauri** – Desktop-App mit Tauri
- **Game-Bevy** – Spiel mit Bevy Engine
- **Game-Macroquad** – Spiel mit Macroquad
- **SystemTool** – Systemüberwachungswerkzeug
- **Network-Async** – Async-TCP/UDP-Kommunikation
- **Embedded** – Embedded / no_std (für Mikrocontroller)
