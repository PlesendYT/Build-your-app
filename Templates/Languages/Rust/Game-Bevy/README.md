# Game-Bevy

**Deutsch:** Ein einfaches 2D-Spiel mit der Bevy Engine. Der Spieler
sammelt Gegner mit den Pfeiltasten ein.

**English:** A simple 2D game with the Bevy Engine. The player collects
enemies using the arrow keys.

## Features
- ECS-Architektur (DE/EN)
- Spielerbewegung (DE) / Player movement (EN)
- Kollisionserkennung (DE) / Collision detection (EN)
- Punktezähler (DE) / Score counter (EN)

## Verwendung / Usage
```bash
cargo run
```

## Tech Stack
Rust 2024, Bevy 0.14, rand
