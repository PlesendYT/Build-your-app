# Network-Async

**Deutsch:** Async-TCP-Server/Client mit Tokio. Broadcast-Nachrichten
an alle verbundenen Clients.

**English:** Async TCP server/client with Tokio. Broadcasts messages
to all connected clients.

## Features
- TCP-Server/Client (DE/EN)
- Broadcast-Kommunikation (DE) / Broadcast communication (EN)
- Async I/O (DE/EN)

## Verwendung / Usage
```bash
cargo run -- server
cargo run -- client
```

## Tech Stack
Rust 2024, Tokio, futures-util, clap
