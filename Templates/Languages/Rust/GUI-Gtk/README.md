# GUI-Gtk

**Deutsch:** Desktop-GUI mit GTK4. Enthält Fenster mit Label, Texteingabe,
Button und Zähler. Nutzt GTK4 und glib.

**English:** Desktop GUI with GTK4. Includes a window with label, text entry,
button, and counter. Uses GTK4 and glib.

## Features
- Native GTK4-Oberfläche (DE) / Native GTK4 interface (EN)
- Signalbasierte Events (DE) / Signal-based events (EN)
- Modernes Layout (DE) / Modern layout (EN)

## Verwendung / Usage
```bash
cargo run
```

## Tech Stack
Rust 2024, gtk4 0.8, glib 0.19
