# GUI-Egui

**Deutsch:** Desktop-GUI mit egui (Immediate-Mode). Enthält Textfelder,
Zähler und eine scrollbare Liste. Zustand wird automatisch gespeichert.

**English:** Desktop GUI with egui (immediate-mode). Includes text fields,
a counter, and a scrollable list. State is automatically persisted.

## Features
- Immediate-Mode-GUI (DE/EN)
- Zustandsspeicherung (DE) / State persistence (EN)
- Scrollbare Liste (DE) / Scrollable list (EN)

## Verwendung / Usage
```bash
cargo run
```

## Tech Stack
Rust 2024, egui 0.27, eframe 0.27, serde
