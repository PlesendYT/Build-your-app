# GUI-Tauri

**Deutsch:** Desktop-App mit Tauri 2. Enthält Rust-Backend mit
Tauri-Kommandos und HTML/CSS/JS-Frontend.

**English:** Desktop app with Tauri 2. Includes Rust backend with
Tauri commands and HTML/CSS/JS frontend.

## Features
- Native Desktop-App (DE/EN)
- Rust-Backend + Web-Frontend (DE/EN)
- IPC-Kommunikation (DE/EN)

## Verwendung / Usage
```bash
npm install
cargo tauri dev
```

## Tech Stack
Rust 2024, Tauri 2, HTML/JS
