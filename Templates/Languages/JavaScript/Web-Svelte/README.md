# Web-Svelte — Svelte Komponente

## Beschreibung
Svelte 5 Single-File-Komponente mit Vite. Reaktivität ohne virtuelles DOM — echte Kompilierung.

## Description
Svelte 5 single-file component with Vite. Reactivity without a virtual DOM — true compilation.

---

## Features
- Svelte 5 mit Runes (Reaktivitätssyntax)
- Vite Build
- Scoped CSS
- Minimaler Bundle-Size

## How to use / Verwendung
```bash
cd Web-Svelte
npm install
npm run dev
```

## Tech Stack
- Svelte 5
- Vite
- ESM

## Extension ideas / Erweiterungsideen
- SvelteKit (Full-Stack)
- Routify (Routing)
- Stores für State-Management
- Motion/Transition-Animationen
