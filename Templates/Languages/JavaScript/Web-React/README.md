# Web-React — React SPA

## Beschreibung
Moderne React SPA mit funktionalen Komponenten, Hooks und JSX. Verwendet React 19 mit Vite als Build-Tool.

## Description
Modern React SPA with functional components, hooks, and JSX. Uses React 19 with Vite as build tool.

---

## Features
- React 19 mit Vite
- Funktionale Komponenten mit Hooks (useState, useEffect)
- CSS-Module
- Hot Module Replacement

## How to use / Verwendung
```bash
cd Web-React
npm install
npm run dev
```

## Tech Stack
- React 19
- Vite
- CSS Modules
- ESM

## Extension ideas / Erweiterungsideen
- React Router
- Context API / Zustand
- API-Integration
- Testing (Vitest + Testing Library)
