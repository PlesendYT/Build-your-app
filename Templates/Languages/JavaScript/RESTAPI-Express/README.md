# RESTAPI-Express — Express.js REST API

## Beschreibung
REST-API mit Express.js. CRUD-Endpunkte, Middleware, Fehlerbehandlung und CORS.

## Description
REST API built with Express.js. CRUD endpoints, middleware, error handling, and CORS.

---

## Features
- Express.js Router
- JSON Middleware
- CORS-Unterstützung
- Strukturierte Fehlerbehandlung
- Async-Handler-Wrapper

## How to use / Verwendung
```bash
cd RESTAPI-Express
npm install
node index.js
# http://localhost:3000/api/users
```

## Tech Stack
- Express.js
- Node.js 20+
- ESM

## Extension ideas / Erweiterungsideen
- Datenbank (Prisma, SQLite, PostgreSQL)
- Authentifizierung (JWT)
- Validierung (Zod, Joi)
