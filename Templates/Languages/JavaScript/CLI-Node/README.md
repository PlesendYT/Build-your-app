# CLI-Node — Node.js CLI Tool

## Beschreibung
Kommandozeilenwerkzeug mit Node.js. Nutzt `process.argv`, `fs/promises` und `readline`. Ideal für Automation und Scripting.

## Description
Command-line tool built with Node.js. Uses `process.argv`, `fs/promises`, and `readline`. Ideal for automation and scripting.

---

## Features
- ESM-Module
- Async/Await
- `fs/promises` für Dateioperationen
- Farbige Ausgabe (ANSI)
- Fehlerbehandlung

## How to use / Verwendung
```bash
cd CLI-Node
node index.js --help
node index.js greet --name Welt
```

## Tech Stack
- Node.js 20+
- ESM
- Native Node.js APIs
