# BrowserExtension — Manifest V3 Browser Extension

## Beschreibung
Browser-Erweiterung nach Manifest V3 für Chromium-Browser. Enthält Service Worker, Popup und Content Script.

## Description
Browser extension following Manifest V3 for Chromium browsers. Includes service worker, popup, and content script.

---

## Features
- Manifest V3
- Service Worker (Background)
- Popup mit UI
- Content Script für Seiten-Manipulation
- Messaging zwischen den Komponenten

## How to use / Verwendung
1. Öffne `chrome://extensions`
2. Aktiviere "Entwicklermodus"
3. Klicke "Erweiterung laden" → wähle dieses Verzeichnis

## Tech Stack
- Manifest V3
- JavaScript ES2022+
- Chrome Extension APIs

## Extension ideas / Erweiterungsideen
- Optionsseite
- Storage API
- Context Menus
- Tabs API
- Netzwerk-Requests abfangen
