# Three.js Template

> Minimal-Setup für Three.js-Szenen. / Minimal setup for Three.js scenes.

## Features
- WebGL-Renderer mit Resize-Handling / WebGL renderer with resize handling
- OrbitControls für Kamera-Navigation / OrbitControls for camera navigation
- Animationsloop / Animation loop
- Beispiel-Kugel und Beleuchtung / Example sphere and lighting

## How to Use
```bash
cd Web-ThreeJS
npm install
npm run dev
```

## Tech Stack
- Three.js
- Vite

## Extension Ideas
- GLTFLoader für Modelle / GLTFLoader for models
- Postprocessing mit EffectComposer / Postprocessing with EffectComposer
- Raycaster für Picking / Raycaster for picking
