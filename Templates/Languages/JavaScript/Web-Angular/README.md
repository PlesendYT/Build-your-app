# Web-Angular — Angular Komponente (JavaScript)

## Beschreibung
AngularJS (1.x) Komponente mit modernem JavaScript. Diese Vorlage zeigt eine AngularJS-Komponente mit双向 Datenbindung und Dependency Injection.

## Description
AngularJS (1.x) component with modern JavaScript. This template shows an AngularJS component with two-way data binding and dependency injection.

---

## Features
- AngularJS 1.x mit Komponenten-Architektur
- Zwei-Wege-Datenbindung
- Dependency Injection
- Eigener HTTP-Service

## How to use / Verwendung
```bash
cd Web-Angular
npx serve .
```

## Tech Stack
- AngularJS 1.x (via CDN)
- JavaScript ES2022+
- HTML5 / CSS3

## Extension ideas / Erweiterungsideen
- Routing mit `ngRoute`
- Eigene Direktiven
- Filter/Pipes
