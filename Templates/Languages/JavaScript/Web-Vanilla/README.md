# Web-Vanilla — Vanilla HTML/CSS/JS App

## Beschreibung
Eine moderne Webanwendung mit reinem HTML, CSS und JavaScript (ES2022+). Nutzt den DOM, Fetch API und CSS Custom Properties. Ideal zum Einstieg oder für einfache Projekte ohne Framework.

## Description
A modern web application using pure HTML, CSS, and JavaScript (ES2022+). Uses the DOM, Fetch API, and CSS Custom Properties. Ideal for getting started or simple projects without a framework.

---

## Features
- ES2022+ JavaScript mit ESM-Modulen
- CSS Custom Properties für einfaches Theming
- Responsive Design
- Fetch API für HTTP-Anfragen
- Zero dependencies

## How to use / Verwendung
```bash
cd Web-Vanilla
npx serve .      # oder beliebiger Static-Server
```

## Tech Stack
- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- JavaScript ES2022+ (ESM)
