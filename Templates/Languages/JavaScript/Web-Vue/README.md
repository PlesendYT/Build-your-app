# Web-Vue — Vue 3 SPA

## Beschreibung
Vue 3 SPA mit Composition API, `<script setup>` und Vite. Modernes Vue mit Single-File-Komponenten.

## Description
Vue 3 SPA with Composition API, `<script setup>`, and Vite. Modern Vue with single-file components.

---

## Features
- Vue 3 Composition API
- `<script setup>` Syntax
- Vite Build
- Scoped CSS

## How to use / Verwendung
```bash
cd Web-Vue
npm install
npm run dev
```

## Tech Stack
- Vue 3
- Vite
- Vue Router (optional)

## Extension ideas / Erweiterungsideen
- Pinia Store
- Vue Router
- API-Integration mit axios
- Component Libraries (PrimeVue, Naive UI)
