# RESTAPI-Fastify — Fastify REST API

## Beschreibung
REST-API mit Fastify. Performant, schema-basiert mit JSON-Schema-Validierung.

## Description
REST API built with Fastify. Performant, schema-based with JSON Schema validation.

---

## Features
- Fastify Server
- Schema-Validierung
- CORS
- Automatische Serialisierung
- Strukturierte Logs (Pino)

## How to use / Verwendung
```bash
cd RESTAPI-Fastify
npm install
node index.js
# http://localhost:3000/api/users
```

## Tech Stack
- Fastify 5
- Node.js 20+
- ESM
