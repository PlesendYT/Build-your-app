# Commander.js Template

> Strukturierte CLI mit Commander.js. / Structured CLI with Commander.js.

## Features
- Sub-Commands mit Optionen / Sub-commands with options
- Automatische Hilfe-Texte / Auto-generated help
- TypeScript-frei / TypeScript-free

## How to Use
```bash
cd CLI-Commander
npm install
node cli.js greet --name World
node cli.js add 1 2 3
```

## Tech Stack
- Node.js 18+
- Commander.js
