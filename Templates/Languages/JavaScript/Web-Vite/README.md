# Vite + Vanilla JS Template

> Vite als Dev-Server und Build-Tool für Vanilla-JS. / Vite dev server and bundler for vanilla JavaScript.

## Features
- Hot-Module-Replacement / Hot module replacement
- ES-Modul-Imports out-of-the-box / ES module imports out of the box
- Produktions-Build nach `dist/` / Production build into `dist/`

## How to Use
```bash
cd Web-Vite
npm install
npm run dev
npm run build
```

## Tech Stack
- Vite 5
- Vanilla JS (ES modules)

## Extension Ideas
- TypeScript hinzufügen / Add TypeScript
- Vitest für Unit-Tests / Vitest for unit tests
- Tailwind CSS / Tailwind CSS
