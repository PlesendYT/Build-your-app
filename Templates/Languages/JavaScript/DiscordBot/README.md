# DiscordBot — discord.js Bot

## Beschreibung
Discord Bot mit discord.js v14. Enthält Slash-Commands, Event-Handling und Embed-Nachrichten.

## Description
Discord bot built with discord.js v14. Includes slash commands, event handling, and embed messages.

---

## Features
- Slash-Commands (/ping, /say)
- Event-Handler (ready, interactionCreate)
- Discord Embeds
- Modulare Command-Struktur

## How to use / Verwendung
1. Erstelle einen Bot auf https://discord.com/developers
2. Kopiere den Token
3. Setze Umgebungsvariable: `export DISCORD_TOKEN=...`
4. ```bash
   cd DiscordBot
   npm install
   node index.js
   ```

## Tech Stack
- discord.js v14
- Node.js 20+
- ESM
