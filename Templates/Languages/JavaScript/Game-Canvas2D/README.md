# Game-Canvas2D — HTML5 Canvas Spiel

## Beschreibung
2D-Spiel mit der HTML5 Canvas API. Enthält Spielersteuerung, Kollisionserkennung und Spielschleife.

## Description
2D game using the HTML5 Canvas API. Includes player controls, collision detection, and game loop.

---

## Features
- Canvas 2D Rendering
- requestAnimationFrame-Spielschleife
- Tastatursteuerung (WASD / Pfeiltasten)
- Kollisionserkennung
- Punkte-System

## How to use / Verwendung
```bash
cd Game-Canvas2D
npx serve .
```

## Tech Stack
- HTML5 Canvas
- JavaScript ES2022+
- Keine Dependencies
