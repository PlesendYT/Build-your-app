# Game-Phaser — Phaser 3 Spiel

## Beschreibung
Ein Spiel mit der Phaser 3 Game Engine. Enthält Szenen-Management, Physik und Asset-Loading.

## Description
A game built with Phaser 3 game engine. Includes scene management, physics, and asset loading.

---

## Features
- Phaser 3 Arcade Physics
- Mehrere Szenen (Boot, Game, GameOver)
- Spielersteuerung (Pfeiltasten)
- Gegner & Punkte
- Partikel-Effekte

## How to use / Verwendung
```bash
cd Game-Phaser
npm install
npx serve .
```

## Tech Stack
- Phaser 3
- JavaScript ES2022+
- Canvas/WebGL Renderer
