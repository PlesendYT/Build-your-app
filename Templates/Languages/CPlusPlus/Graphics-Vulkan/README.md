# Graphics-Vulkan

**Deutsch:** Vulkan-Grafik mit GLFW. Erstellt Vulkan-Instanz, wählt
physisches Gerät und erstellt logisches Gerät.

**English:** Vulkan graphics with GLFW. Creates Vulkan instance, picks
physical device, and creates logical device.

## Tech Stack
C++23, Vulkan 1.3, GLFW, GLM, CMake
