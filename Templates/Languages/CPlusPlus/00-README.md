# C++-Vorlagen / C++ Templates

Willkommen bei den C++-Projektvorlagen. Diese Vorlagen decken CLI, GUI, Spiele,
Grafik, Netzwerk, Systemwerkzeuge und eingebettete Systeme ab. Jede Vorlage
verwendet modernes C++20/23 mit RAII, Smart Pointern und STL.

Welcome to the C++ project templates. These templates cover CLI, GUI, games,
graphics, networking, system tools, and embedded systems. Each template uses
modern C++20/23 with RAII, smart pointers, and STL.

## Verfügbare Vorlagen / Available Templates
- **CLI-Tool** – Kommandozeilenwerkzeug
- **CLI-Game** – Konsolenspiel
- **GUI-Qt** – GUI mit Qt6
- **GUI-SFML** – GUI mit SFML
- **GUI-SDL2** – GUI mit SDL2
- **Game-Console** – Konsolenspiel
- **Game-SFML** – Spiel mit SFML
- **Game-SDL2** – Spiel mit SDL2
- **Graphics-OpenGL** – OpenGL-Grafik
- **Graphics-Vulkan** – Vulkan-Grafik
- **Network-Server** – TCP-Server
- **Network-Client** – TCP-Client
- **SystemTool** – Systemwerkzeug
- **Embedded** – Eingebettet (PIO)
