# CLI-Tool

**Deutsch:** Modernes C++-CLI-Werkzeug mit cxxopts und nlohmann/json.
Unterstützt Unterbefehle, Konfigurationsdateien und Dateiverarbeitung.

**English:** Modern C++ CLI tool with cxxopts and nlohmann/json. Supports
subcommands, config files, and file processing.

## Tech Stack
C++23, CMake, cxxopts, nlohmann/json
