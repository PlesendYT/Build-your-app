# Java Android-Game

🇩🇪 2D-Spiel für Android mit SurfaceView und Game-Loop.

🇬🇧 2D game for Android with SurfaceView and game loop.

## Features
- Dedizierte Game-Loop in eigenem Thread
- Touch-Steuerung
- Canvas-Rendering
- Kollisionsdetektion

## How to use
In Android Studio öffnen und auf Gerät/Emulator ausführen.

## Tech stack
- Java 21
- Android SDK 34
- Gradle
- Canvas API

## Extension ideas
- Add SoundPool for SFX
- Add Spritesheet-Animation
