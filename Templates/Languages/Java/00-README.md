# Java Templates

🇩🇪 Diese Vorlagen bieten fertige Java 21-Projekte mit modernen Sprachfeatures wie Records, Sealed Classes, Pattern Matching und Streams. Perfekt für den schnellen Start neuer Projekte.

🇬🇧 These templates provide ready-to-use Java 21 projects with modern language features like Records, Sealed Classes, Pattern Matching, and Streams. Perfect for quickly bootstrapping new projects.

## Verfügbare Vorlagen / Available Templates

| Vorlage / Template | Beschreibung / Description |
|---|---|
| CLI-Tool | Kommandozeilen-Tool mit Args-Parsing / Command-line tool with args parsing |
| GUI-Swing | Desktop-GUI mit Swing / Desktop GUI with Swing |
| GUI-JavaFX | Moderne GUI mit JavaFX / Modern GUI with JavaFX |
| RESTAPI-Spring | REST-API mit Spring Boot / REST API with Spring Boot |
| RESTAPI-JAXRS | REST-API mit JAX-RS / REST API with JAX-RS |
| Game-LibGDX | 2D-Spiel mit LibGDX / 2D game with LibGDX |
| Game-JMonkey | 3D-Spiel mit jMonkeyEngine / 3D game with jMonkeyEngine |
| Android-App | Android-App mit Activities / Android app with Activities |
| Android-Game | Android-Spiel mit Canvas/OpenGL / Android game with Canvas/OpenGL |
| Desktop-Tool | Desktop-Werkzeug mit modernem UI / Desktop tool with modern UI |
