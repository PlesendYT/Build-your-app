# Java Game-JMonkey

🇩🇪 3D-Spiel mit jMonkeyEngine 3 und Java 21.

🇬🇧 3D game with jMonkeyEngine 3 and Java 21.

## Features
- 3D-Rendering mit OpenGL
- First-Person-Controller
- Kollisionserkennung
- Asset-Loading
- Szenegraph-Architektur

## How to use
```bash
mvn package
java -jar target/jmonkey-game.jar
```

## Tech stack
- Java 21
- jMonkeyEngine 3.6
- Maven
