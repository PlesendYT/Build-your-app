# Java RESTAPI-JAXRS

🇩🇪 REST-API mit JAX-RS, CDI, und Jakarta EE 10 auf Payara/TomEE.

🇬🇧 REST API with JAX-RS, CDI, and Jakarta EE 10 on Payara/TomEE.

## Features
- JAX-RS Resource-Klassen
- JSON mit Jackson
- CDI-Dependency-Injection
- Bean Validation

## How to use
```bash
mvn package
# Deploy target/jaxrs-api.war auf Payara/TomEE
```

## Tech stack
- Java 21
- Jakarta EE 10 (JAX-RS, CDI)
- Maven
- H2 Database

## Extension ideas
- Add JPA with Hibernate
- Add JWT authentication filter
- Add OpenAPI with MicroProfile
