# Java GUI-JavaFX

🇩🇪 Moderne Desktop-GUI mit JavaFX, FXML, und Java 21-Sealed-Interfaces.

🇬🇧 Modern desktop GUI with JavaFX, FXML, and Java 21 sealed interfaces.

## Features
- MVC-Architektur mit FXML
- CSS-Styling
- Responsive Layouts
- Internationalisierung

## How to use
```bash
mvn package
java -jar target/javafx-app.jar
```

## Tech stack
- Java 21
- JavaFX
- Maven

## Extension ideas
- Add Charts (JavaFX Charts API)
- Add WebView for embedded browser
- Add MediaView for audio/video
