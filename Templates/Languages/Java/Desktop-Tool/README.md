# Java Desktop-Tool

🇩🇪 Modernes Desktop-Werkzeug mit Swing, SQLite-Datenbank und Java 21.

🇬🇧 Modern desktop tool with Swing, SQLite database, and Java 21.

## Features
- SQLite-Datenbank mit JDBC
- Tabellenansicht mit JTable
- CRUD-Operationen
- Export-Funktion

## How to use
```bash
mvn package
java -jar target/desktop-tool.jar
```

## Tech stack
- Java 21
- Swing
- SQLite via JDBC
- Maven
