# Java Game-LibGDX

🇩🇪 2D-Spiel mit LibGDX, ECS-Architektur und Java 21.

🇬🇧 2D game with LibGDX, ECS architecture, and Java 21.

## Features
- Entity-Component-System
- Textur-Rendering
- Eingabe-Verarbeitung
- Audio-Wiedergabe
- Bildschirm-Management

## How to use
```bash
mvn package
java -jar target/libgdx-game.jar
```

## Tech stack
- Java 21
- LibGDX 1.12
- Maven
- LWJGL 3
