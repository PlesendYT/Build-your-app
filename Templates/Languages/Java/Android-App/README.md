# Java Android-App

🇩🇪 Native Android-App mit Activities, Fragments und Material Design.

🇬🇧 Native Android app with Activities, Fragments, and Material Design.

## Features
- RecyclerView mit Adapter
- ViewBinding
- Activity + Fragment-Architektur
- Material Design 3

## How to use
In Android Studio öffnen und auf Gerät/Emulator ausführen.

## Tech stack
- Java 21
- Android SDK 34
- Gradle (Kotlin DSL)
- Material Design 3

## Extension ideas
- Add Retrofit for API calls
- Add Room database
- Add Navigation Component
- Add Hilt DI
