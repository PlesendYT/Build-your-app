# Java GUI-Swing

🇩🇪 Desktop-GUI-Anwendung mit Swing, Java 21 Records und modernen UI-Patterns.

🇬🇧 Desktop GUI application with Swing, Java 21 Records, and modern UI patterns.

## Features
- Benutzerdefinierte Swing-Komponenten
- Event-Handling mit Records
- Responsive Layouts
- Internationalisierung

## How to use
```bash
mvn package
java -jar target/swing-app.jar
```

## Tech stack
- Java 21
- Swing
- Maven
