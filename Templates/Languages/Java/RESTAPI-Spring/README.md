# Java RESTAPI-Spring

🇩🇪 REST-API mit Spring Boot 3, Records, und modernen Java 21-Features.

🇬🇧 REST API with Spring Boot 3, Records, and modern Java 21 features.

## Features
- CRUD-Endpunkte mit Records
- Virtuelle Threads (Project Loom)
- OpenAPI-Dokumentation
- Datenbank mit Spring Data JPA

## How to use
```bash
mvn package
java -jar target/spring-api.jar
# http://localhost:8080/api/tasks
```

## Tech stack
- Java 21 + Virtual Threads
- Spring Boot 3.2
- Spring Data JPA + H2
- Maven
