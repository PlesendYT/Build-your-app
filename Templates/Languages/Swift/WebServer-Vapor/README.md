# WebServer-Vapor

**Deutsch:** Ein moderner Web-Server mit Vapor 4. Enthält Routing, Middleware,
Templates (Leaf) und JSON-API-Endpunkte.

**English:** A modern web server with Vapor 4. Includes routing, middleware,
templates (Leaf), and JSON API endpoints.

## Features
- Async/await Routing (DE) / Async/await routing (EN)
- Leaf-Template-Engine (DE) / Leaf template engine (EN)
- Middleware (Logging, CORS, Fehler) (DE) / Middleware (logging, CORS, errors) (EN)
- Health-Check-Endpunkt (DE) / Health check endpoint (EN)

## Verwendung / Usage
```bash
swift run
# Server läuft auf http://localhost:8080
```

## Tech Stack
Swift 5.9+, Vapor 4, Leaf, async/await, Codable
