# iOS-App

**Deutsch:** Eine moderne iOS-App mit SwiftUI. Verwendet MVVM-Architektur mit
async/await für Netzwerkaufrufe und SwiftData für lokale Persistenz.

**English:** A modern iOS app with SwiftUI. Uses MVVM architecture with
async/await for network calls and SwiftData for local persistence.

## Features
- MVVM-Architektur (DE) / MVVM architecture (EN)
- SwiftData Persistenz (DE) / SwiftData persistence (EN)
- Async/await Netzwerkschicht (DE) / Async/await networking layer (EN)
- NavigationStack Routing (DE) / NavigationStack routing (EN)

## Verwendung / Usage
Öffne `App/` in Xcode und starte auf einem iOS 17+ Simulator.
Open `App/` in Xcode and run on an iOS 17+ simulator.

## Tech Stack
Swift 5.9+, SwiftUI, SwiftData, async/await, Codable
