# SwiftUI iOS Template

> Minimal-iOS-App mit SwiftUI. / Minimal iOS app with SwiftUI.

## Features
- App-Einstiegspunkt mit @main / App entry point with @main
- InhaltView mit Counter-State / Content view with counter state

## How to Use
1. Erstelle ein neues Xcode-Projekt (App, SwiftUI) und ersetze die generierten Dateien / Create a new Xcode project (App, SwiftUI) and replace the generated files
2. Oder nutze den Swift Package Manager / Or use Swift Package Manager

## Tech Stack
- Swift 5.9+
- SwiftUI

## Extension Ideas
- NavigationStack / NavigationStack
- Combine für reaktive Daten / Combine for reactive data
- URLSession + Codable / URLSession + Codable
