# GUI-SwiftUI

**Deutsch:** Eine moderne macOS-Desktop-App mit SwiftUI. Nutzt das neueste
SwiftUI mit Observation-Framework für reaktive Datenverwaltung.

**English:** A modern macOS desktop app with SwiftUI. Uses the latest SwiftUI
with the Observation framework for reactive data management.

## Features
- Sidebar-Navigation mit List (DE) / Sidebar navigation with List (EN)
- Detailansicht mit Formularen (DE) / Detail view with forms (EN)
- @Observable-Modelle (DE) / @Observable models (EN)
- Dark/Light Mode Support (DE) / Dark/Light mode support (EN)

## Verwendung / Usage
```bash
swift run
```

## Tech Stack
Swift 5.9+, SwiftUI, Observation, Codable
