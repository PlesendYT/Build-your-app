# RESTAPI

**Deutsch:** Eine vollständige REST-API mit Vapor 4 und Fluent ORM inkl.
PostgreSQL-Datenbankanbindung, Migrationen und Authentifizierung.

**English:** A complete REST API with Vapor 4 and Fluent ORM including
PostgreSQL database connectivity, migrations, and authentication.

## Features
- CRUD-Endpunkte für mehrere Ressourcen (DE) / CRUD endpoints for multiple resources (EN)
- Fluent ORM mit PostgreSQL (DE) / Fluent ORM with PostgreSQL (EN)
- JWT-Authentifizierung (DE) / JWT authentication (EN)
- Request-Validierung (DE) / Request validation (EN)
- Automatische Migrationen (DE) / Automatic migrations (EN)

## Verwendung / Usage
```bash
swift run
# API läuft auf http://localhost:8080
# Dokumentation: http://localhost:8080/swagger
```

## Tech Stack
Swift 5.9+, Vapor 4, Fluent 4, PostgreSQL, JWT, async/await
