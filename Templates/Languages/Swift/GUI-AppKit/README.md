# GUI-AppKit

**Deutsch:** Eine moderne macOS-Desktop-App mit AppKit und NSViewController.
Verwendet Storyboards und Cocoa-Bindings für eine saubere MVC-Architektur.

**English:** A modern macOS desktop app with AppKit and NSViewController.
Uses storyboards and Cocoa bindings for a clean MVC architecture.

## Features
- Dokumentenbasierte Oberfläche (DE) / Document-based interface (EN)
- NSTableView mit Sortierung (DE) / NSTableView with sorting (EN)
- Modernes async/await für Dateioperationen (DE) / Modern async/await for file operations (EN)

## Verwendung / Usage
```bash
swift build
swift run
```

## Tech Stack
Swift 5.9+, AppKit, Cocoa Bindings, Storyboards
