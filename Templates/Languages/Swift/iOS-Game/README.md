# iOS-Game

**Deutsch:** Ein iOS-Spiel mit SpriteKit. Enthält Spielersteuerung, Kollisions-
erkennung und Punktesystem. Ready für Game Center Integration.

**English:** An iOS game with SpriteKit. Includes player controls, collision
detection, and scoring system. Ready for Game Center integration.

## Features
- Touch-Steuerung (DE) / Touch controls (EN)
- Kollisionserkennung mit SKPhysics (DE) / Collision detection with SKPhysics (EN)
- Highscore-Speicherung (DE) / High score persistence (EN)
- Partikeleffekte (DE) / Particle effects (EN)

## Verwendung / Usage
Öffne `App/` in Xcode und starte auf einem iOS 17+ Simulator.
Open `App/` in Xcode and run on an iOS 17+ simulator.

## Tech Stack
Swift 5.9+, SpriteKit, GameplayKit, GKAccessPoint
