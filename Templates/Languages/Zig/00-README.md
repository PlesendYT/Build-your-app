# Zig-Vorlagen / Zig Templates

Willkommen bei den Zig-Projektvorlagen. Diese Vorlagen decken die häufigsten
Anwendungsfälle ab: CLI-Tools, Spiele, Systemwerkzeuge, Netzwerkanwendungen
und eingebettete Systeme. Jede Vorlage verwendet modernes Zig mit korrekten
Allokator-Patterns, comptime-Features und idiomatischem Code.

Welcome to the Zig project templates. These templates cover the most common
use cases: CLI tools, games, system tools, network applications, and embedded
systems. Each template uses modern Zig with proper allocator patterns,
comptime features, and idiomatic code.

## Verfügbare Vorlagen / Available Templates

- **CLI-Tool** – Kommandozeilenwerkzeug mit argv-Parsing
- **Game** – Konsolenspiel mit Raylib
- **SystemTool** – Systemüberwachungswerkzeug
- **Network** – Async-TCP-Server/Client
- **Embedded** – Eingebettetes System (Mikrocontroller)
