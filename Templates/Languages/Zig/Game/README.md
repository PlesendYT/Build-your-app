# Game

**Deutsch:** Ein 2D-Konsolenspiel in Zig mit Raylib. Enthält Spielerbewegung,
Kollisionserkennung und Rendering-Loop.

**English:** A 2D console game in Zig with Raylib. Includes player movement,
collision detection, and render loop.

## Features
- Raylib-Rendering (DE) / Raylib rendering (EN)
- Spieler-Steuerung mit Tastatur (DE) / Player controls with keyboard (EN)
- Kollisionserkennung (DE) / Collision detection (EN)
- FPS-Anzeige (DE) / FPS counter (EN)

## Verwendung / Usage
```bash
zig build run
```

## Tech Stack
Zig 0.13+, Raylib 5.0, std.math
