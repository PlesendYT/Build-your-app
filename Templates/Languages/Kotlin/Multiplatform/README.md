# Kotlin Multiplatform

🇩🇪 Kotlin Multiplatform-Projekt (KMP) mit gemeinsamer Logik, Android- und iOS-UI.

🇬🇧 Kotlin Multiplatform project (KMP) with shared logic, Android and iOS UI.

## Features
- Shared Code in commonMain
- Android-App mit Compose
- iOS-App mit SwiftUI-Bridge
- Erwartungs-/tatsächlich-Deklarationen
- Ktor-Client plattformübergreifend

## How to use
Android: In Android Studio öffnen und ausführen.
iOS: Xcode-Projekt in iosApp/ öffnen.

## Tech stack
- Kotlin 1.9 + KMP
- Compose Multiplatform
- Ktor Client
- Kotlinx Serialization
- Gradle Kotlin DSL
