# Android Compose Template

> Minimal-Android-App mit Jetpack Compose. / Minimal Android app with Jetpack Compose.

## Features
- MainActivity mit Compose-UI / MainActivity with Compose UI
- Material3 Theme / Material3 theme
- Beispiel-Screen mit Counter / Example screen with counter

## How to Use
1. Öffne den Ordner in Android Studio / Open the folder in Android Studio
2. Lasse Gradle synchronisieren / Let Gradle sync
3. Drücke Run / Press Run

## Tech Stack
- Kotlin 1.9+
- Jetpack Compose, Material3

## Extension Ideas
- Navigation-Compose / Navigation Compose
- Room-Datenbank / Room database
- Retrofit für HTTP / Retrofit for HTTP
