# Kotlin CLI-Tool

🇩🇪 Kommandozeilen-Tool mit Kotlin, Coroutines und Flow.

🇬🇧 Command-line tool with Kotlin, Coroutines, and Flow.

## Features
- Coroutine-basierte Async-Operationen
- Flow-Datenverarbeitung
- Kompakte DSL für Argument-Parsing
- Farbige Konsolenausgabe

## How to use
```bash
./gradlew run --args="greet --name Welt"
```

## Tech stack
- Kotlin 1.9
- Kotlinx Coroutines
- Gradle Kotlin DSL

## Extension ideas
- Add HTTP client with Ktor
- Add JSON parsing with kotlinx.serialization
- Add CLI completion scripts
