# Kotlin Android-App

🇩🇪 Native Android-App mit Jetpack Compose, Coroutines und Material 3.

🇬🇧 Native Android app with Jetpack Compose, Coroutines, and Material 3.

## Features
- Jetpack Compose UI
- Coroutine + Flow Architektur
- ViewModel + StateFlow
- Material Design 3
- Navigation Compose

## How to use
In Android Studio öffnen und auf Gerät/Emulator ausführen.

## Tech stack
- Kotlin 1.9
- Android SDK 34
- Jetpack Compose
- Kotlin Coroutines + Flow
- Gradle Kotlin DSL
