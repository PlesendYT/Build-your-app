# Kotlin Templates

🇩🇪 Diese Vorlagen enthalten moderne Kotlin-Projekte mit Coroutines, Flows und KMP (Kotlin Multiplatform). Ideal für die plattformübergreifende Entwicklung.

🇬🇧 These templates contain modern Kotlin projects with Coroutines, Flows, and KMP (Kotlin Multiplatform). Ideal for cross-platform development.

## Verfügbare Vorlagen / Available Templates

| Vorlage / Template | Beschreibung / Description |
|---|---|
| CLI-Tool | Kommandozeilen-Tool / Command-line tool |
| RESTAPI-Ktor | REST-API mit Ktor / REST API with Ktor |
| RESTAPI-Spring | REST-API mit Spring Boot / REST API with Spring Boot |
| Android-App | Android-App mit Jetpack / Android app with Jetpack |
| Android-Game | Android-Spiel mit Canvas / Android game with Canvas |
| Desktop-Compose | Desktop-App mit Compose / Desktop app with Compose |
| Multiplatform | KMP-Projekt / KMP project |
