# Kotlin Android-Game

🇩🇪 2D-Spiel für Android mit Kotlin, Coroutines und Canvas.

🇬🇧 2D game for Android with Kotlin, Coroutines, and Canvas.

## Features
- SurfaceView mit Game-Loop
- Coroutine-basierte Timing-Steuerung
- Touch-Steuerung
- Kollisionserkennung

## How to use
In Android Studio öffnen und auf Gerät/Emulator ausführen.

## Tech stack
- Kotlin 1.9
- Android SDK 34
- Coroutines
- Canvas API
