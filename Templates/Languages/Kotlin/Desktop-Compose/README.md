# Kotlin Desktop-Compose

🇩🇪 Desktop-Anwendung mit JetBrains Compose Multiplatform.

🇬🇧 Desktop application with JetBrains Compose Multiplatform.

## Features
- Compose Desktop UI
- Material Design 3
- State Management
- Datei-I/O per Coroutines

## How to use
```bash
./gradlew run
```

## Tech stack
- Kotlin 1.9
- Compose Multiplatform (Desktop)
- Kotlin Coroutines
- Gradle Kotlin DSL
