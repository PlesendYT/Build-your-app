# Kotlin RESTAPI-Spring

🇩🇪 REST-API mit Spring Boot 3, Kotlin, Coroutines und R2DBC.

🇬🇧 REST API with Spring Boot 3, Kotlin, Coroutines, and R2DBC.

## Features
- Reaktive REST-Endpunkte mit WebFlux
- R2DBC + PostgreSQL/H2
- Kotlin Coroutines in Controllern
- Data Classes und Null-Safety

## How to use
```bash
./gradlew bootRun
# http://localhost:8080/api/tasks
```

## Tech stack
- Kotlin 1.9
- Spring Boot 3.2
- WebFlux + Coroutines
- R2DBC + H2
- Gradle Kotlin DSL

## Extension ideas
- Add Spring Security with OAuth2
- Add Spring Cloud Gateway
