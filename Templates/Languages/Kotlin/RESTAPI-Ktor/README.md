# Kotlin RESTAPI-Ktor

🇩🇪 REST-API mit Ktor, Exposed ORM und kotlinx.serialization.

🇬🇧 REST API with Ktor, Exposed ORM, and kotlinx.serialization.

## Features
- Ktor-Server mit Content Negotiation
- Exposed ORM + H2-Datenbank
- Coroutine-basierte Requests
- JSON-Serialisierung

## How to use
```bash
./gradlew run
# http://localhost:8080/api/items
```

## Tech stack
- Kotlin 1.9
- Ktor 2.3
- Exposed ORM
- H2 Database
- Gradle Kotlin DSL
