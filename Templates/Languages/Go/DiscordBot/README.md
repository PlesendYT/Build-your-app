# Go DiscordBot

🇩🇪 Discord-Bot mit discordgo, Slash-Commands und Embed-Nachrichten.

🇬🇧 Discord bot with discordgo, slash commands, and embed messages.

## Features
- Slash-Commands
- Embed-Nachrichten
- Event-Handling
- Concurrent Command-Processing
- Konfiguration per JSON

## How to use
```bash
export BOT_TOKEN="dein_token"
go run .
```

## Tech stack
- Go 1.22
- discordgo v0.27
- Standard Library
