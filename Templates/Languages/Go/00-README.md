# Go Templates

🇩🇪 Diese Vorlagen bieten einsatzbereite Go-Projekte mit Goroutines, Channels und idiomatischen Go-Patterns. Fokus auf Einfachheit und Performance.

🇬🇧 These templates provide production-ready Go projects with Goroutines, Channels, and idiomatic Go patterns. Focus on simplicity and performance.
