# Go Game-Ebitengine

🇩🇪 2D-Spiel mit Ebitengine, einfacher Physik und Pixelgrafik.

🇬🇧 2D game with Ebitengine, simple physics, and pixel graphics.

## Features
- Ebitengine Game Loop
- Sprite-Rendering
- Kollisionserkennung
- Tastatur-Steuerung
- Einfache Physik

## How to use
```bash
go run .
# Fenster öffnet sich mit dem Spiel
```

## Tech stack
- Go 1.22
- Ebitengine v2
