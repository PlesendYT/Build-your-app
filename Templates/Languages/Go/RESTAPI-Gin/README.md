# Go RESTAPI-Gin

🇩🇪 REST-API mit Gin Framework, GORM und PostgreSQL.

🇬🇧 REST API with Gin framework, GORM, and PostgreSQL.

## Features
- Gin-Router mit Gruppen
- GORM-ORM
- CRUD-Endpunkte
- JSON-Validierung
- Middleware (Logging, Recovery)

## How to use
```bash
go run .
# http://localhost:8080/api/tasks
```

## Tech stack
- Go 1.22
- Gin
- GORM + SQLite
- Go Modules
