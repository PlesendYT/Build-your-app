# Go WebServer

🇩🇪 HTTP-Server mit Go Standard Library, Routing und Middleware.

🇬🇧 HTTP server with Go standard library, routing, and middleware.

## Features
- Standard-Library net/http
- Middleware-Chain (Logging, Recovery, CORS)
- Pfad-basiertes Routing
- JSON-API-Endpunkte
- Templates

## How to use
```bash
go run .
# http://localhost:8080
```

## Tech stack
- Go 1.22
- Standard Library
- html/template
