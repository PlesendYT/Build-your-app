# Go RESTAPI-Echo

🇩🇪 REST-API mit Echo Framework und MongoDB.

🇬🇧 REST API with Echo framework and MongoDB.

## Features
- Echo Router mit Middleware
- MongoDB mit mongo-go-driver
- Context-basierte Requests
- Validierung

## How to use
```bash
go run .
# http://localhost:8080/api/users
```

## Tech stack
- Go 1.22
- Echo v4
- MongoDB Driver
- Go Modules
