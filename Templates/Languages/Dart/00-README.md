# Dart Templates

🇩🇪 Diese Vorlagen enthalten Dart 3-Projekte mit Null-Safety, moderne Patterns und Flutter-Integration. Ideal für plattformübergreifende Apps.

🇬🇧 These templates contain Dart 3 projects with null safety, modern patterns, and Flutter integration. Ideal for cross-platform apps.

| Vorlage / Template | Beschreibung / Description |
|---|---|
| CLI-Tool | CLI-Tool mit args / CLI tool with args |
| WebServer-Shelf | HTTP-Server mit Shelf / HTTP server with Shelf |
| RESTAPI | REST-API mit Shelf + Router / REST API with Shelf + Router |
| Flutter-App | Flutter-Material-App / Flutter Material app |
| Flutter-Game | Flutter-Spiel mit Flame / Flutter game with Flame |
| Desktop-Compact | Desktop-App mit Dart / Desktop app with Dart |
