# Dart Flutter-App

🇩🇪 Flutter-Material-3-App mit State Management, Navigation und HTTP.

🇬🇧 Flutter Material 3 app with state management, navigation, and HTTP.

## Features
- Material Design 3
- Navigation 2.0 (GoRouter)
- State Management (Riverpod)
- HTTP-Client (Dio)
- Theming

## How to use
```bash
flutter run
```

## Tech stack
- Dart 3
- Flutter 3.x
- Riverpod
- GoRouter
- Dio
