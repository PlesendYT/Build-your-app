# Dart Flutter-Game

🇩🇪 2D-Spiel mit Flutter und Flame Game Engine.

🇬🇧 2D game with Flutter and Flame game engine.

## Features
- Flame Game Loop
- Sprite-Komponenten
- Kollisionserkennung
- Touch-/Tastatur-Steuerung
- Partikel-Effekte

## How to use
```bash
flutter run
```

## Tech stack
- Dart 3
- Flutter 3.x
- Flame 1.x
- Forge2D (optional)
