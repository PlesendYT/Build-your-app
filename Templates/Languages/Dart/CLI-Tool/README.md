# Dart CLI-Tool

🇩🇪 Kommandozeilen-Tool in Dart 3 mit Null Safety, Records und Pattern Matching.

🇬🇧 Command-line tool in Dart 3 with null safety, records, and pattern matching.

## Features
- Argument-Parsing (package:args)
- Records und Pattern Matching
- Async I/O
- Farbige Ausgabe (ANSI)

## How to use
```bash
dart run bin/cli.dart greet --name Welt
dart run bin/cli.dart calc add 5 3
```

## Tech stack
- Dart 3
- package:args
- pubspec.yaml
