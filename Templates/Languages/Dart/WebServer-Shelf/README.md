# Dart WebServer-Shelf

🇩🇪 HTTP-Server mit Shelf, Middleware und statischen Dateien.

🇬🇧 HTTP server with Shelf, middleware, and static files.

## Features
- Shelf Router
- Middleware (Logging, CORS)
- JSON-API
- Statische Dateien ausliefern

## How to use
```bash
dart run bin/server.dart
# http://localhost:8080
```

## Tech stack
- Dart 3
- shelf, shelf_router, shelf_static

## Extension ideas
- Add shelf_io for WebSocket
- Add PostgreSQL (postgresql-dart)
- Add JWT (shelf_auth)
