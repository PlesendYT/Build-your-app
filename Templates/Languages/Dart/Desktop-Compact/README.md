# Dart Desktop-Compact

🇩🇪 Desktop-App mit Dart, Flutter-Desktop oder Dart-only mit dcli.

🇬🇧 Desktop app with Dart, Flutter Desktop, or Dart-only with dcli.

## Features
- Konsolen-UI mit Dart
- Datei-Operationen
- System-Informationen
- Cross-Plattform (Windows, macOS, Linux)

## How to use
```bash
dart run bin/desktop.dart
```

## Tech stack
- Dart 3
- Dart IO
- dcli (optional)

## Extension ideas
- Add GUI with Flutter Desktop
- Add SQLite database
- Add SystemTray
- Add CLI with args
