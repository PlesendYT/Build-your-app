# C Network Examples Template

> Kleine Sammlung von BSD-Sockets-Beispielen in C. / Small collection of BSD sockets examples in C.

## Features
- TCP-Echo-Client / TCP echo client
- TCP-Echo-Server / TCP echo server
- Makefile-Build / Makefile build

## How to Use
```bash
cd C-Network-Examples
make
./server &
./client "Hello"
```

## Tech Stack
- C11, POSIX sockets

## Extension Ideas
- select/poll/epoll-Demos / select/poll/epoll demos
- UDP-Beispiel / UDP example
- TLS via OpenSSL / TLS via OpenSSL
