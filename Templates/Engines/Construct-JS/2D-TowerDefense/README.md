# 2D-TowerDefense (Construct JS)

## Beschreibung / Description

**DE:** Ein Turmverteidigungsspiel für Construct 3 mit Wegpunkt-System und verschiedenen Türmen.

**EN:** A tower defense game for Construct 3 with waypoint system and different towers.

## Features

- Wegpunkt-System / Waypoint system
- Verschiedene Türme / Different towers
- Gegner-Wellen / Enemy waves
- Gold/Ressourcen / Gold/resources
- Turm-Upgrades / Tower upgrades
