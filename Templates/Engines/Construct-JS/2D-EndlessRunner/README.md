# 2D-EndlessRunner (Construct JS)

## Beschreibung / Description

**DE:** Ein Endlosläufer in Construct 3 mit automatischem Scrollen, Hindernissen und Punktesystem.

**EN:** An endless runner in Construct 3 with auto-scrolling, obstacles, and scoring.

## Features

- Automatische Bewegung / Auto movement
- Springen und Rutschen / Jump and slide
- Zufällige Hindernisse / Random obstacles
- Parallax-Hintergrund / Parallax background
- Highscore / Leaderboard

## How to Use

1. Player, ObstacleLow, ObstacleHigh, Ground-Objekte erstellen
2. Skripte importieren

## Tech Stack

- Construct 3 JavaScript

- Power-Ups
- Skins
