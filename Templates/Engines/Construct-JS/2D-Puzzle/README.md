# 2D-Puzzle (Construct JS)

## Beschreibung / Description

**DE:** Ein 2D-Rätselspiel mit Schiebeblöcken, Hebeln und Druckplatten.

**EN:** A 2D puzzle game with pushable blocks, levers, and pressure plates.

## Features

- Schiebeblöcke / Pushable blocks
- Hebel-Mechanik / Lever mechanics
- Druckplatten / Pressure plates
- Türen / Doors
- Rücksetz-Funktion / Reset function
