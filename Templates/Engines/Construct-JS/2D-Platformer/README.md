# 2D-Platformer (Construct JS)

## Beschreibung / Description

**DE:** Ein Construct-3-Plattformer mit Spieler-Steuerung, Gegnern und Sammelobjekten.

**EN:** A Construct 3 platformer with player controls, enemies, and collectibles.

## Features

- Bewegung und Sprung / Movement and jump
- Plattform-Kollision / Platform collision
- Gegner-KI / Enemy AI
- Münzen-Sammeln / Coin collecting
- Level-Manager / Level manager

## How to Use

1. Construct-3-Projekt öffnen
2. Skript-Dateien im Script-Editor importieren
3. Objekte im Layout benennen: Player, Enemy, Coin, Ground

## Tech Stack

- Construct 3 JavaScript SDK
- `runtime.objects` für Objektzugriff
- ES-Module

## Extension Ideas

- Power-Ups
- Checkpoints
- Gleiten / Gliding
- Wasser-Level / Water levels
