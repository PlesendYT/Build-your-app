# 2D-ShootEmUp (Construct JS)

## Beschreibung / Description

**DE:** Ein 2D-Shoot-em-up für Construct 3 mit scrollendem Hintergrund und Gegnerwellen.

**EN:** A 2D shoot-em-up for Construct 3 with scrolling background and enemy waves.

## Features

- Spieler steuert mit Maus/ Touch / Mouse/touch player control
- Automatisches Feuern / Auto-fire
- Gegnerwellen / Enemy waves
- Power-Ups
- Punktesystem / Score system

## How to Use

1. PlayerShip, Enemy, Bullet, PowerUp-Objekte erstellen
2. Skripte importieren

## Tech Stack

- Construct 3 JavaScript

## Extension Ideas

- Boss-Gegner / Boss enemies
- Waffen-Upgrades
- Mehrspieler
- Shop
