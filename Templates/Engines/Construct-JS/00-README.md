# Construct JS Templates

Construct-3-Vorlagen für 2D-Spiele mit JavaScript-Skripting (Addon- und Skriptkonventionen).

Construct 3 templates for 2D games using JavaScript scripting (addon and script conventions).

## Vorlagen / Templates

| Genre | Beschreibung / Description |
|-------|--------------------------|
| 2D-Platformer | Klassisches Jump'n'Run / Classic platformer |
| 2D-TopDown | Top-Down-Abenteuer / Top-down adventure |
| 2D-Puzzle | Rätselspiel / Puzzle game |
| 2D-EndlessRunner | Endlosläufer / Endless runner |
| 2D-ShootEmUp | Schießspiel / Shooting game |
| 2D-TowerDefense | Turmverteidigung / Tower defense |
| 2D-CardGame | Kartenspiel / Card game |

## Verwendung / Usage

Jede Vorlage enthält JavaScript-Dateien für Construct 3 Skripting.
Die Skripte können im Script-Editor von Construct 3 importiert oder als Addon verpackt werden.

Each template contains JavaScript files for Construct 3 scripting.
The scripts can be imported in the Construct 3 Script Editor or packaged as addons.

## Konventionen / Conventions

- `import {} from` für ES-Module
- `globalThis` für globale Runtime-Objekte
- `g_runtime` für Runtime-Zugriff
- `runtime.objects` für Objektzugriff
- `runtime.callFunction` für Funktionsaufrufe
- Event-basierte Programmierung mit `addEventListener`
