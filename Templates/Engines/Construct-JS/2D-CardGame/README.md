# 2D-CardGame (Construct JS)

## Beschreibung / Description

**DE:** Ein Kartenspiel für Construct 3 mit Deck-Verwaltung, Ziehen und Ausspielen.

**EN:** A card game for Construct 3 with deck management, drawing, and playing cards.

## Features

- Kartendeck mischen / Shuffle deck
- Hand-Management / Hand management
- Spielen von Karten / Playing cards
- Energie-/Manasystem / Energy/mana system
- Gegner-KI / Enemy AI
