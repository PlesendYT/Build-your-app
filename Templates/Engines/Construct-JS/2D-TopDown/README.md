# 2D-TopDown (Construct JS)

## Beschreibung / Description

**DE:** Ein Top-Down-Spiel mit Bewegung in 4/8 Richtungen und Gegner-Verfolgung.

**EN:** A top-down game with 4/8 directional movement and enemy chasing.

## Features

- 8-Richtungs-Bewegung / 8-directional movement
- Kollision mit Wänden / Wall collision
- Gegner patrouillieren / Enemy patrolling
- Items einsammeln / Item collection
- Tür- und Schlüssel-Mechanik / Door and key mechanics

## How to Use

1. Layout mit Player, Enemy, Wall, Item, Door-Objekten
2. Skripte importieren

## Tech Stack

- Construct 3 JavaScript

## Extension Ideas

- Fernkampf / Ranged combat
- Minimap
