# 3D RPG Template

## Deutsch
Eine vollständige 3D-RPG-Vorlage mit Third-Person-Steuerung, Kampf, Quests und Inventar.

## English
A complete 3D RPG template with third-person controls, combat, quests, and inventory.

## Features / Funktionen
- Third-person camera / Third-Person-Kamera
- Movement and combat / Bewegung und Kampf
- Quest system / Questsystem
- Inventory / Inventar
- NPC interaction / NPC-Interaktion
- Leveling system / Stufenaufstieg
- Dialogue system / Dialogsystem

## Tech Stack / Technologie
- Godot 4 GDScript
- CharacterBody3D
- SpringArm3D for camera
- Area3D interactions

## Extension Ideas / Erweiterungsideen
- Mount system
- Crafting
- Faction system
- Fast travel
