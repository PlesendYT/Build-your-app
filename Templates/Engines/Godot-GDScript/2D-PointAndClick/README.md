# 2D Point & Click Template

## Deutsch
Eine vollständige Point-and-Click-Adventure-Vorlage mit Inventory, Rätseln und Dialogsystem.

## English
A complete point and click adventure template with inventory, puzzles, and dialogue system.

## Features / Funktionen
- Click-to-move movement / Klick-zum-Bewegen
- Inventory system / Inventarsystem
- Dialogue system / Dialogsystem
- Puzzle integration / Rätselintegration
- Hotspot interactions / Hotspot-Interaktionen
- Item combining / Gegenstandskombination
- Scene transitions / Szenenübergänge

## Tech Stack / Technologie
- Godot 4 GDScript
- Area2D hotspots
- Control node UI
- Dialogic-style dialogue

## Extension Ideas / Erweiterungsideen
- Multiple endings
- Voice acting
- Cutscene system
- Journal system
