# Godot GDScript Template Collection

## Deutsch
Diese Sammlung bietet vollständige GDScript-Projektvorlagen für Godot 4. Jede Vorlage enthält einsatzbereiten Code für ein bestimmtes Spielgenre, sodass du sofort mit der Entwicklung beginnen kannst.

## English
This collection provides complete GDScript project templates for Godot 4. Each template contains production-ready code for a specific game genre, allowing you to start development immediately.

## How to Use / Verwendung

1. Copy the template folder into your Godot project
2. Open Godot 4 and import the scenes
3. Review and customize the scripts
4. Build upon the template

## Requirements / Voraussetzungen
- Godot Engine 4.x
- GDScript (built-in)
