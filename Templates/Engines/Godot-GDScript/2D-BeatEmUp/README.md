# 2D Beat 'Em Up Template

## Deutsch
Eine vollständige Beat-'Em-Up-Vorlage mit Side-Scrolling-Kampf, Combos und Mehrfachgegnern.

## English
A complete beat 'em up template with side-scrolling combat, combos, and multiple enemies.

## Features / Funktionen
- Side-scrolling movement / Side-Scrolling-Bewegung
- Combo system / Combosystem
- Multiple enemy types / Mehrere Gegnertypen
- Health bars / Gesundheitsbalken
- Special moves / Spezialangriffe
- Score tracking / Punkteverfolgung
- Wave-based combat / Wellenbasierter Kampf

## Tech Stack / Technologie
- Godot 4 GDScript
- CharacterBody2D
- AnimationTree
- Area2D hitboxes

## Extension Ideas / Erweiterungsideen
- Co-op multiplayer
- Character unlock system
- Upgrade shop
- Boss rush mode
