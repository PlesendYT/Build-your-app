# 2D Rhythm Game Template

## Deutsch
Eine vollständige Rhythmusspiel-Vorlage mit fallenden Noten, Timing-Wertung und Song-Auswahl.

## English
A complete rhythm game template with falling notes, timing scoring, and song selection.

## Features / Funktionen
- Falling note system / Fallendes Notensystem
- Timing-based scoring / Zeitbasierte Wertung
- Multiple lanes / Mehrere Spuren
- Combo system / Combosystem
- Song integration / Song-Integration
- Visual feedback / Visuelles Feedback
- High score tracking

## Tech Stack / Technologie
- Godot 4 GDScript
- Timer and AudioStreamPlayer
- Input buffering
- Tween animations

## Extension Ideas / Erweiterungsideen
- Song editor
- Multiplayer versus
- Custom skins
- Online leaderboards
