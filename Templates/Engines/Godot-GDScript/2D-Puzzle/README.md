# 2D Puzzle Template

## Deutsch
Eine Vorlage für 2D-Puzzlespiele mit Drag-and-Drop, Verbindungsmechaniken und Level-Fortschritt.

## English
A template for 2D puzzle games with drag-and-drop, connection mechanics, and level progression.

## Features / Funktionen
- Drag-and-drop objects / Ziehen-und-Ablegen
- Snap-to-grid / Rasterausrichtung
- Connection puzzles / Verbindungspuzzles
- Level progression / Level-Fortschritt
- Hint system / Hinweissystem
- Timer and scoring / Timer und Punkte

## Tech Stack / Technologie
- Godot 4 GDScript
- Area2D with collision
- Control nodes for UI
- Tween for animations

## Extension Ideas / Erweiterungsideen
- Match-3 mode
- Jigsaw puzzles
- Sokoban levels
- Minigame collection
