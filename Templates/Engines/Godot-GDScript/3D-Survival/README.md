# 3D Survival Template

## Deutsch
Eine vollständige Survival-Spiel-Vorlage mit Ressourcensammeln, Crafting und Tag-Nacht-Zyklus.

## English
A complete survival game template with resource gathering, crafting, and day-night cycle.

## Features / Funktionen
- Resource gathering / Ressourcensammeln
- Crafting system / Crafting-System
- Hunger/thirst system
- Day/night cycle / Tag-Nacht-Zyklus
- Building system / Bausystem
- Wild animals / Wilde Tiere
- Temperature system

## Tech Stack / Technologie
- Godot 4 GDScript
- CharacterBody3D
- DirectionalLight3D for cycle
- WorldEnvironment

## Extension Ideas / Erweiterungsideen
- Multiplayer
- Base defense
- Farming
- Fishing
