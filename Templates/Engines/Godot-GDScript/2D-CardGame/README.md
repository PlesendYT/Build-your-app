# 2D Card Game Template

## Deutsch
Eine vollständige Kartenspiel-Vorlage mit Sammelkarten, Deck-Verwaltung und rundenbasierten Kämpfen.

## English
A complete card game template with collectible cards, deck management, and turn-based battles.

## Features / Funktionen
- Card collection / Kartensammlung
- Deck building / Deckbau
- Turn-based combat / Rundenbasierter Kampf
- Card effects / Karteneffekte
- Mana/energy system
- Draw and discard / Ziehen und Abwerfen
- Shop system / Shopsystem

## Tech Stack / Technologie
- Godot 4 GDScript
- Control nodes for UI
- Resource system for cards
- Signal-based game flow

## Extension Ideas / Erweiterungsideen
- Online multiplayer
- Card crafting
- Tournament mode
- Daily rewards
