# 3D Simulation Template

## Deutsch
Eine vollständige 3D-Simulationsspiel-Vorlage mit Objektplatzierung, Wirtschaft und Datenanzeige.

## English
A complete 3D simulation game template with object placement, economy, and data visualization.

## Features / Funktionen
- Object placement / Objektplatzierung
- Economy system / Wirtschaftssystem
- Data visualization / Datenvisualisierung
- Time speed control / Zeitgeschwindigkeit
- Grid-based building / Rasterbasiertes Bauen
- Population management
- Resource chains / Ressourcenketten

## Tech Stack / Technologie
- Godot 4 GDScript
- Camera3D with zoom
- GridMap for building
- Control node UI

## Extension Ideas / Erweiterungsideen
- Traffic simulation
- Weather effects
- Mod support
- Scenario editor
