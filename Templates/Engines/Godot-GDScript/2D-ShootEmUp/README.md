# 2D Shoot 'Em Up Template

## Deutsch
Eine vollständige Shoot-'Em-Up-Vorlage mit Scroll-Leveln, Power-Ups, Wellen von Gegnern und Bossen.

## English
A complete shoot 'em up template with scrolling levels, power-ups, enemy waves, and bosses.

## Features / Funktionen
- Auto-scrolling level / Automatisch scrollendes Level
- Player ship movement / Spielerschiff-Bewegung
- Bullet patterns / Geschossmuster
- Enemy waves / Gegnerwellen
- Power-ups / Power-Ups
- Boss fights / Bosskämpfe
- Score and combo system / Punkte- und Combosystem

## Tech Stack / Technologie
- Godot 4 GDScript
- CharacterBody2D
- Area2D bullets
- Timer-based spawning

## Extension Ideas / Erweiterungsideen
- Multiplayer co-op
- Weapon upgrades
- Leaderboard
- Different ship types
