# 2D Roguelike Template

## Deutsch
Eine vollständige Roguelike-Vorlage mit prozeduraler Generierung, Permadeath, Items und rundenbasierter Bewegung.

## English
A complete roguelike template with procedural generation, permadeath, items, and turn-based movement.

## Features / Funktionen
- Procedural dungeon generation / Prozedurale Dungeon-Generierung
- Turn-based movement / Rundenbasierte Bewegung
- Permadeath system
- Item and loot system / Gegenstands- und Beutesystem
- Enemy AI with vision / Gegner-KI mit Sicht
- Stats and leveling / Stats und Stufenaufstieg
- Fog of war / Nebel des Krieges

## Tech Stack / Technologie
- Godot 4 GDScript
- TileMap procedural generation
- Random number generation
- A* pathfinding

## Extension Ideas / Erweiterungsideen
- Multiple character classes
- Crafting system
- Boss rooms
- Shop between floors
