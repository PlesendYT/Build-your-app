# 2D Metroidvania Template

## Deutsch
Eine vollständige Metroidvania-Vorlage mit nicht-linearer Weltkarte, Fähigkeiten-Fortschritt und Gegnern.

## English
A complete Metroidvania template with non-linear world map, ability-gated progression, and enemies.

## Features / Funktionen
- Non-linear level design / Nicht-lineares Leveldesign
- Ability gates (double jump, dash, wall climb) / Fähigkeitstore
- Map system with rooms / Kartensystem mit Räumen
- Save stations / Speicherstationen
- Health and energy upgrades
- Boss enemies / Bossgegner
- Teleport system / Teleportsystem

## Tech Stack / Technologie
- Godot 4 GDScript
- CharacterBody2D
- Camera2D with limits
- TileMap layers

## Extension Ideas / Erweiterungsideen
- Fast travel
- Item crafting
- Secret rooms
- New game plus
