# 2D Visual Novel Template

## Deutsch
Eine vollständige Visual-Novel-Vorlage mit Dialogsystem, Charakter-Sprites, Entscheidungen und Verzweigungen.

## English
A complete visual novel template with dialogue system, character sprites, choices, and branching.

## Features / Funktionen
- Dialogue display / Dialoganzeige
- Character sprites / Charakter-Sprites
- Choice system / Entscheidungssystem
- Branching narrative / Verzweigte Erzählung
- Background transitions
- Save/load system / Speicher-/Ladesystem
- Text effects / Texteffekte

## Tech Stack / Technologie
- Godot 4 GDScript
- RichTextLabel
- Control nodes
- JSON-based dialogue

## Extension Ideas / Erweiterungsideen
- Character voice
- Gallery mode
- Music player
- Skip/auto mode
