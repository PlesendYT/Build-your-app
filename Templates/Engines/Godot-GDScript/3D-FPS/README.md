# 3D FPS Template

## Deutsch
Eine vollständige Ego-Shooter-Vorlage mit Waffen, Gegnern, Gesundheits- und Munitionssystem.

## English
A complete first-person shooter template with weapons, enemies, health, and ammo system.

## Features / Funktionen
- First-person camera / Ego-Perspektive
- Weapon system with recoil / Waffensystem mit Rückstoß
- Enemy AI with shooting / Gegner-KI mit Schießen
- Health and armor / Gesundheit und Rüstung
- Ammo management / Munitionsverwaltung
- Crosshair UI / Fadenkreuz-UI
- Damage feedback

## Tech Stack / Technologie
- Godot 4 GDScript
- CharacterBody3D
- RayCast3D for shooting
- AnimationPlayer for weapons

## Extension Ideas / Erweiterungsideen
- Different weapon types
- Multiplayer
- Grenade system
- Scope/zoom
