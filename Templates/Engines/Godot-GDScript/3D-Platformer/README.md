# 3D Platformer Template

## Deutsch
Eine vollständige 3D-Plattformer-Vorlage mit Springen, Sammelobjekten und Leveldesign.

## English
A complete 3D platformer template with jumping, collectibles, and level design.

## Features / Funktionen
- 3D movement with physics / 3D-Bewegung mit Physik
- Jump and double jump
- Collectible coins / Sammelbare Münzen
- Moving platforms / Bewegliche Plattformen
- Camera following / Kamera folgt
- Level timer / Level-Timer
- Checkpoint system

## Tech Stack / Technologie
- Godot 4 GDScript
- CharacterBody3D
- Camera3D with smoothing
- Area3D triggers

## Extension Ideas / Erweiterungsideen
- Wall running
- Grappling hook
- Time trial mode
- Secret areas
