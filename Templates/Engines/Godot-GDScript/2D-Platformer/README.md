# 2D Platformer Template

## Deutsch
Eine vollständige 2D-Plattformer-Vorlage mit Bewegung, Springen, doppeltem Sprung, Gegnern, Münzen und Level-Fortschritt.

## English
A complete 2D platformer template with movement, jumping, double jump, enemies, coins, and level progression.

## Features / Funktionen
- Character movement with acceleration / Charakterbewegung mit Beschleunigung
- Double jump / Doppelsprung
- Animated sprites / Animierte Sprites
- Enemy AI / Gegner-KI
- Coin collection / Münzsammlung
- Level transitions / Levelübergänge
- Camera following / Kamera folgt
- Health system / Gesundheitssystem

## How to Use / Verwendung
1. Open `PlatformerPlayer.tscn` as the main scene
2. Adjust gravity and speed in the Player script
3. Add more levels by extending the LevelManager
4. Customize enemy behavior in `Enemy.gd`

## Tech Stack / Technologie
- Godot 4 GDScript
- CharacterBody2D for player and enemies
- TileMap for level design
- AnimationPlayer for sprite animations
- Area2D for collectibles and triggers

## Extension Ideas / Erweiterungsideen
- Wall jumping / Wandspringen
- Dash ability / Dash-Fähigkeit
- Power-ups / Power-Ups
- Save system / Speichersystem
