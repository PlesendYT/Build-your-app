# 3D Fighting Template

## Deutsch
Eine vollständige 3D-Kampfspiel-Vorlage mit Combos, Spezialbewegungen und Gesundheitsbalken.

## English
A complete 3D fighting game template with combos, special moves, and health bars.

## Features / Funktionen
- 3D arena / 3D-Arena
- Combo system / Combosystem
- Special moves / Spezialbewegungen
- Health bars / Gesundheitsbalken
- Input buffering / Eingabepufferung
- Hit detection / Treffererkennung
- Round system / Rundensystem

## Tech Stack / Technologie
- Godot 4 GDScript
- CharacterBody3D
- AnimationTree
- Area3D hitboxes

## Extension Ideas / Erweiterungsideen
- Character roster
- Story mode
- Online versus
- Training mode
