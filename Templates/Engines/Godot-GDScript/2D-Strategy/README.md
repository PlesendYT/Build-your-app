# 2D Strategy Template

## Deutsch
Eine vollständige 2D-Strategiespiel-Vorlage mit rundenbasiertem Kampf, Ressourcenmanagement und KI.

## English
A complete 2D strategy game template with turn-based combat, resource management, and AI.

## Features / Funktionen
- Hex/tile grid / Hex-/Raster-Gitter
- Turn-based movement / Rundenbasierte Bewegung
- Resource management / Ressourcenverwaltung
- Unit production / Einheitenproduktion
- Combat system / Kampfsystem
- Fog of war / Nebel des Krieges
- AI opponent / KI-Gegner

## Tech Stack / Technologie
- Godot 4 GDScript
- TileMap with custom layers
- A* pathfinding
- State machine

## Extension Ideas / Erweiterungsideen
- Online multiplayer
- Tech tree
- Campaign mode
- Map editor
