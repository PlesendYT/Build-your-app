# 3D Open World Template

## Deutsch
Eine vollständige Open-World-Vorlage mit großer Karte, Fahrzeugen und dynamischen Ereignissen.

## English
A complete open world template with large map, vehicles, and dynamic events.

## Features / Funktionen
- Large terrain / Große Geländekarte
- Third-person controls
- Vehicle system / Fahrzeugsystem
- Fast travel / Schnellreise
- Dynamic events / Dynamische Ereignisse
- Minimap / Minimap
- Waypoint system / Wegpunktsystem

## Tech Stack / Technologie
- Godot 4 GDScript
- WorldEnvironment
- MultiMeshInstance for optimization
- NavigationRegion3D

## Extension Ideas / Erweiterungsideen
- Faction reputation
- Base building
- Weather system
- NPC settlements
