# 3D Racing Template

## Deutsch
Eine vollständige Rennspiel-Vorlage mit Fahrzeugphysik, Runden und KI-Gegnern.

## English
A complete racing game template with vehicle physics, laps, and AI opponents.

## Features / Funktionen
- Vehicle physics / Fahrzeugphysik
- Acceleration, braking, steering
- Lap system / Rundensystem
- AI opponents / KI-Gegner
- Speed boost / Geschwindigkeitsboost
- Minimap / Minimap
- Position tracking

## Tech Stack / Technologie
- Godot 4 GDScript
- RigidBody3D for vehicle
- Area3D for triggers
- Path3D for AI

## Extension Ideas / Erweiterungsideen
- Vehicle customization
- Different tracks
- Drift mechanic
- Multiplayer
