# 2D Top-Down Template

## Deutsch
Eine vollständige 2D-Top-Down-Vorlage mit Bewegung in vier Richtungen, Interaktionen, Gegnern und Inventar.

## English
A complete 2D top-down template with four-directional movement, interactions, enemies, and inventory.

## Features / Funktionen
- 4-directional movement / 4-Richtungen Bewegung
- Dash ability / Dash-Fähigkeit
- NPC interaction / NPC-Interaktion
- Inventory system / Inventarsystem
- Enemy patrol AI / Gegner-Patrouillen-KI
- Combat system / Kampfsystem
- Dialogue system / Dialogsystem

## Tech Stack / Technologie
- Godot 4 GDScript
- CharacterBody2D
- TileMap
- Area2D triggers

## Extension Ideas / Erweiterungsideen
- Quest system
- Day/night cycle
- Fast travel
- Skill trees
