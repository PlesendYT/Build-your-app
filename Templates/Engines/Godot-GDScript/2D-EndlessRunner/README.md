# 2D Endless Runner Template

## Deutsch
Eine vollständige Endless-Runner-Vorlage mit prozeduraler Generierung, Power-Ups und Highscore-System.

## English
A complete endless runner template with procedural generation, power-ups, and high score system.

## Features / Funktionen
- Auto-scrolling level / Automatisch scrollendes Level
- Procedural obstacle generation / Prozedurale Hindernisgenerierung
- Power-ups / Power-Ups
- High score system / Highscore-System
- Difficulty scaling / Schwierigkeitsanpassung
- Character animations

## Tech Stack / Technologie
- Godot 4 GDScript
- CharacterBody2D
- Timer-based spawning
- Parallax background

## Extension Ideas / Erweiterungsideen
- Character skins
- Daily challenges
- Achievement system
- Multiplayer racing
