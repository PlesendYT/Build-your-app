# 2D Tower Defense Template

## Deutsch
Eine vollständige Tower-Defense-Vorlage mit Platzierung von Türmen, Wellen von Gegnern und Upgrade-System.

## English
A complete tower defense template with tower placement, enemy waves, and upgrade system.

## Features / Funktionen
- Tower placement / Turmplatzierung
- Multiple tower types / Mehrere Turmtypen
- Enemy wave system / Gegnerwellen-System
- Upgrade system / Upgrade-System
- Pathfinding for enemies
- Resource management / Ressourcenverwaltung
- Score and lives system

## Tech Stack / Technologie
- Godot 4 GDScript
- Path2D for enemy routes
- Area2D for attack ranges
- Timer-based spawning

## Extension Ideas / Erweiterungsideen
- Elemental towers
- Tower combining
- Boss waves
- PvP mode
