# Mobile Simple Template

## Deutsch
Eine einfache mobile Spielvorlage mit Touch-Steuerung und für mobile Geräte optimierten Einstellungen.

## English
A simple mobile game template with touch controls and mobile-optimized settings.

## Features / Funktionen
- Touch input / Touch-Eingabe
- Tap to move / Tippen zum Bewegen
- Swipe detection / Wisch-Erkennung
- Responsive UI / Reaktionsfähige UI
- Performance optimized
- Landscape and portrait
- Mobile-safe pause

## Tech Stack / Technologie
- Godot 4 GDScript
- TouchScreenButton
- Control anchors
- Mobile-safe rendering

## Extension Ideas / Erweiterungsideen
- Leaderboard integration
- Ad implementation
- In-app purchases
- Cloud save
