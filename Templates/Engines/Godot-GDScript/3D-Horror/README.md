# 3D Horror Template

## Deutsch
Eine vollständige Horror-Spiel-Vorlage mit Taschenlampe, Verstecken und übernatürlichen Gegnern.

## English
A complete horror game template with flashlight, hiding mechanics, and supernatural enemies.

## Features / Funktionen
- First-person exploration
- Flashlight with battery / Taschenlampe mit Batterie
- Hiding spots / Verstecke
- Enemy AI detection / Gegner-KI-Erkennung
- Sanity system / Verstandsystem
- Atmospheric audio
- Jump scare system

## Tech Stack / Technologie
- Godot 4 GDScript
- CharacterBody3D
- Light3D for flashlight
- AudioStreamPlayer3D

## Extension Ideas / Erweiterungsideen
- Inventory items
- Puzzle integration
- Multiple endings
- Co-op mode
