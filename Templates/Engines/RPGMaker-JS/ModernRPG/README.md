# ModernRPG (RPGMaker JS)

## Beschreibung / Description

**DE:** Ein modernes RPG Plugin für zeitgenössische Settings mit Smartphone-UI und Jobs.

**EN:** A modern RPG plugin for contemporary settings with smartphone UI and jobs.

## Features

- Smartphone-Menü / Smartphone menu
- Job-System / Job system
- Beziehungs-System / Relationship system
- Tageszeiten / Time of day
- Social-Media-Integration (fiktiv) / Social media (fictional)

## How to Use

1. Plugin-Dateien importieren
2. Plugin-Befehle in Events nutzen

## Tech Stack

- RPGMaker MZ/MV JavaScript
- `Window_Base` für benutzerdefinierte Fenster
- `Scene_Base` für neue Szenen

## Extension Ideas

- Handy-Klingeltöne / Ringtone system
- SMS-Nachrichten / SMS messages
- Job-Aufstiege / Job promotions
- Apartment-Dekoration / Apartment decoration
