# FantasyRPG (RPGMaker JS)

## Beschreibung / Description

**DE:** Ein klassisches Fantasy-RPG Plugin mit Magie, Klassen und Quest-System für RPGMaker MZ/MV.

**EN:** A classic fantasy RPG plugin with magic, classes, and quest system for RPGMaker MZ/MV.

## Features

- Benutzerdefinierte Zauber-Effekte / Custom spell effects
- Klassen-System mit Bäumen / Class system with trees
- Quest-Log / Quest journal
- Tag-Nacht-Zyklus / Day-night cycle
- Zufallsbegegnungen / Random encounters

## How to Use

1. JS-Dateien in `js/plugins/` kopieren
2. Im Plugin-Manager aktivieren
3. Plugin-Befehle in Events nutzen

## Tech Stack

- RPGMaker MZ/MV JavaScript
- `Game_Interpreter.prototype.pluginCommand`
- `$gameParty`, `$gameSwitches`, `$gameVariables`

## Extension Ideas

- Handwerkssystem / Crafting system
- Fraktionen / Factions
- Reittiere / Mounts
- Errungenschaften / Achievements
