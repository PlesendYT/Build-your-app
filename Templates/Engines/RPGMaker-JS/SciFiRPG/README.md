# SciFiRPG (RPGMaker JS)

## Beschreibung / Description

**DE:** Ein Sci-Fi-RPG Plugin mit Raumschiffen, Aliens und futuristischer Technologie.

**EN:** A sci-fi RPG plugin with spaceships, aliens, and futuristic technology.

## Features

- Raumschiff-Kampf / Spaceship combat
- Alien-Rassen / Alien races
- Technologiebaum / Tech tree
- Planeten-Erkundung / Planet exploration
- Crew-Management / Crew management

## How to Use

1. Plugin importieren, Befehle in Events nutzen

## Tech Stack

- RPGMaker MZ/MV JavaScript
- Benutzerdefinierte Szenen

## Extension Ideas

- Hyperraum-Reisen / Hyperspace travel
- Fraktions-Ruf / Faction reputation
- Schiff-Upgrades / Ship upgrades
- Außerirdische Artefakte / Alien artifacts
