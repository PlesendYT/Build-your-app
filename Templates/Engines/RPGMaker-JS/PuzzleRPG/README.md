# PuzzleRPG (RPGMaker JS)

## Beschreibung / Description

**DE:** Ein Rätsel-RPG Plugin mit Schiebepuzzles, Logikrätseln und Code-Knacken.

**EN:** A puzzle RPG plugin with sliding puzzles, logic puzzles, and code breaking.

## Features

- Schiebepuzzle / Sliding puzzle
- Logikrätsel / Logic puzzles
- Code-Knacken / Code breaking
- Belohnungen für Rätsel / Puzzle rewards
- Schwierigkeits-Einstellungen / Difficulty settings

## How to Use

1. Plugin importieren, Puzzle-Befehle in Events nutzen

## Tech Stack

- RPGMaker MZ/MV JavaScript
- `Window_Base` für Puzzle-UI

## Extension Ideas

- Sudoku
- Kreuzworträtsel / Crossword puzzles
- Mathe-Rätsel / Math puzzles
- Escape-Room-Mechaniken
