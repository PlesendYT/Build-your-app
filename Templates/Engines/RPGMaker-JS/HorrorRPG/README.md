# HorrorRPG (RPGMaker JS)

## Beschreibung / Description

**DE:** Ein Horror-RPG Plugin mit psychologischem Horrorsystem und Überlebensmechaniken.

**EN:** A horror RPG plugin with psychological horror system and survival mechanics.

## Features

- Sanity/Verstand-System / Sanity system
- Taschenlampen-Mechanik / Flashlight mechanic
- Monster-Jagd / Monster stalking
- Versteck-Mechanik / Hiding mechanic
- Ressourcen-Knappheit / Resource scarcity

## How to Use

1. Plugin importieren, Horror-Events mit Befehlen steuern

## Tech Stack

- RPGMaker MZ/MV JavaScript
- Bildschirm-Effekte

## Extension Ideas

- Tagebuch-Seiten / Diary pages
- Kreaturen-Bestimmung / Creature identification
- Sound-basiertes Gameplay / Sound-based gameplay
- Permadeath-Option
