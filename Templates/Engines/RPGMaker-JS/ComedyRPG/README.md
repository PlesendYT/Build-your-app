# ComedyRPG (RPGMaker JS)

## Beschreibung / Description

**DE:** Ein Comedy-RPG Plugin mit humorvollen Events, übertriebenen Charakteren und Running Gags.

**EN:** A comedy RPG plugin with humorous events, exaggerated characters, and running gags.

## Features

- Witz-Dialoge / Joke dialogues
- Übertriebene Animationen / Exaggerated animations
- Running Gags
- Meta-Humor / Meta humor
- Spieler-Statistiken für Humor / Player humor stats

## How to Use

1. Plugin importieren, Comedy-Befehle in Events nutzen

## Tech Stack

- RPGMaker MZ/MV JavaScript

## Extension Ideas

- Lach-Ton-Spur / Laugh track
- Witze-Buch / Joke book
- Stand-up-Szenen / Stand-up scenes
- Komödiantische Fähigkeiten / Comedic abilities
