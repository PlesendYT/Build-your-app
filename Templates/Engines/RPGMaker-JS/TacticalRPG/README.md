# TacticalRPG (RPGMaker JS)

## Beschreibung / Description

**DE:** Ein taktisches RPG Plugin mit rundenbasierten Kämpfen auf einem Gitter.

**EN:** A tactical RPG plugin with turn-based grid combat.

## Features

- Gitterbasiertes Kampfsystem / Grid-based combat system
- Bewegungs- und Aktionspunkte / Movement and action points
- Zonenkontrolle / Zone control
- Deckungssystem / Cover system
- Klassen mit einzigartigen Fähigkeiten / Classes with unique abilities

## How to Use

1. Plugin importieren
2. Karten als 2D-Arrays definieren
3. Kampf-Events auslösen

## Tech Stack

- RPGMaker MZ/MV JavaScript
- 2D-Arrays für Karten
- `Scene_Base` für Kampf-Bildschirm

## Extension Ideas

- Höhenunterschiede / Elevation
- Wetter-Effekte / Weather effects
- Fallen / Traps
- Mehrspieler-Kämpfe / Multiplayer battles
