# Unity C# Templates

Diese Vorlagen bieten gebrauchsfertige C#-Codebasen für verschiedene Unity-Spielgenres. Jede Vorlage enthält wichtige Skripte, gut dokumentierten Code und eine README mit Erweiterungsmöglichkeiten.

---

These templates provide ready-to-use C# codebases for various Unity game genres. Each template includes essential scripts, well-documented code, and a README with extension ideas.
