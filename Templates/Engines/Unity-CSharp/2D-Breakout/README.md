# 2D-Breakout Template

## Beschreibung
Ein klassisches Breakout-Spiel mit physikbasiertem Ball, zerbrechlichen Blöcken und Power-Ups. Inspiriert von den Arcade-Klassikern.

## Description
A classic breakout game with physics-based ball, breakable blocks, and power-ups. Inspired by arcade classics.

## Features
- Physikball mit Abprallmechanik / Physics ball with bounce mechanics
- Paddle-Steuerung per Maus/Touch / Paddle control via mouse/touch
- Zerbrechliche Blöcke mit Punkten / Breakable blocks with points
- Power-Ups (Ballverbreiterung, Multi-Ball) / Power-ups (wide paddle, multi-ball)

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `BreakoutManager` to the game root
3. Attach `PaddleController` to the paddle GameObject
4. Attach `Block` to each block prefab
5. Attach `Ball` to the ball prefab

## Tech Stack
Unity 2022.3+, C#, 2D Physics, Physics2D Materials
