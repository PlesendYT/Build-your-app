# 2D-Cooking Template

## Beschreibung
Ein Kochspiel mit Rezeptverfolgung, Zutatenvorbereitung und Zeitmanagement. Der Spieler bereitet Gerichte nach Rezepten zu und serviert sie.

## Description
A cooking game with recipe tracking, ingredient preparation, and time management. The player prepares dishes following recipes and serves them.

## Features
- Rezeptsystem mit Zutaten / Recipe system with ingredients
- Kochstationen (Schneiden, Kochen, Backen) / Cooking stations (cutting, boiling, baking)
- Timer-Mechanik / Timer mechanics
- Punktesystem nach Qualität / Score system by quality

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `CookingManager` to the kitchen root
3. Attach `RecipeStation` to each cooking station
4. Attach `Ingredient` to ingredient prefabs
5. Attach `OrderUI` for customer orders

## Tech Stack
Unity 2022.3+, C#, 2D, Unity Input System, TextMeshPro

## Extension Ideas
- Mehrere Rezepte / Multiple recipes
- Küchen-Upgrades / Kitchen upgrades
- Zeitdruck-Modus / Time pressure mode
- Multiplayer-Küche / Multiplayer kitchen
