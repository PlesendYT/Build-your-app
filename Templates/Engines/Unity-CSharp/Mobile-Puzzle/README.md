# Mobile-Puzzle Template

## Beschreibung
Ein für mobile Geräte optimiertes Puzzlespiel mit Drag-and-Drop, Touch-Interaktionen und Level-System.

## Description
A mobile-optimized puzzle game with drag-and-drop, touch interactions, and level system.

## Features
- Touch-optimierte Steuerung / Touch-optimized controls
- Drag-and-Drop-Mechanik / Drag-and-drop mechanics
- Mehrere Puzzle-Typen / Multiple puzzle types
- Level-System / Level system
- Hinweis-System / Hint system
- Sternen-Bewertung / Star rating
- Leistungsoptimierung / Performance optimization

## How to Use
1. Attach `TouchInput` for touch handling
2. Attach `PuzzlePiece` to each piece
3. Attach `PuzzleManager` for puzzle logic
4. Attach `GameManager` for game state

## Tech Stack
Unity 2022.3+, C#, Mobile Input, TextMeshPro, UI Canvas, Object Pooling

## Extension Ideas
- Puzzle-Editor / Puzzle editor
- Tägliche Rätsel / Daily puzzles
- Multiplayer-Wettbewerb / Multiplayer competition
- Kategorie-Pakete / Category packs
- Cloud-Speicher / Cloud save
