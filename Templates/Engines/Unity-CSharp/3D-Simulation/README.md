# 3D-Simulation Template

## Beschreibung
Eine 3D-Simulation mit Zeit-Management, Entity-System, Ressourcen-Kreislauf und automatischen Abläufen.

## Description
A 3D simulation with time management, entity system, resource cycles, and automatic processes.

## Features
- Zeit-Steuerung (Pause, Beschleunigung) / Time control (pause, speed up)
- Entity-System mit Verhalten / Entity system with behavior
- Ressourcen-Kreislauf / Resource cycle
- Automatische Prozesse / Automatic processes
- Statistiken und Diagramme / Statistics and charts
- Bau- und Platzierungs-Modus / Build and placement mode

## How to Use
1. Attach `TimeManager` for time control
2. Attach `Entity` to simulation entities
3. Attach `ResourceManager` for resource tracking
4. Attach `GameManager` for game state

## Tech Stack
Unity 2022.3+, C#, 3D Physics, Unity Input System, TextMeshPro, UI Toolkit

## Extension Ideas
- Szenario-Editor / Scenario editor
- Modding-Unterstützung / Modding support
- KI-gesteuerte Entities / AI-driven entities
- Export-Funktionen / Export features
- Multiplayer / Multiplayer
