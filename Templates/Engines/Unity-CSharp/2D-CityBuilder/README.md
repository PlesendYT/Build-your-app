# 2D-CityBuilder Template

## Beschreibung
Ein City-Builder-Spiel mit Zonenplanung, Ressourcenmanagement und Bevölkerungsdynamik. Der Spieler erschafft und verwaltet eine wachsende Stadt.

## Description
A city builder game with zone planning, resource management, and population dynamics. The player creates and manages a growing city.

## Features
- Zonen-basierte Stadtplanung / Zone-based city planning
- Ressourcen-Management (Geld, Strom, Wasser) / Resource management (money, power, water)
- Bevölkerungs- und Zufriedenheitssystem / Population and happiness system
- Visuelles Stadtwachstum / Visual city growth

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `CityManager` to the city root
3. Attach `ZonePlot` to each zone tile
4. Attach `Building` to spawnable buildings

## Tech Stack
Unity 2022.3+, C#, 2D, Unity Input System, Tilemaps, TextMeshPro

## Extension Ideas
- Verkehrssimulation / Traffic simulation
- Katastrophen-Ereignisse / Disaster events
- Handelsrouten / Trade routes
- Mehrere Städte / Multiple cities
