# 2D-HiddenObject Template

## Beschreibung
Ein Hidden-Object-Spiel, in dem der Spieler versteckte Gegenstände in überladenen Szenen findet. Ideal für Point-and-Click-Rätselspiele.

## Description
A hidden object game where the player finds concealed items in cluttered scenes. Ideal for point-and-click puzzle games.

## Features
- Interaktive Szene mit versteckten Objekten / Interactive scene with hidden objects
- Suchliste mit Fortschrittsanzeige / Search list with progress tracking
- Hinweissystem mit Cooldown / Hint system with cooldown
- Belohnungsanimationen / Reward animations

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `HiddenObjectScene` to the scene root
3. Attach `HiddenItem` to each interactable object
4. Attach `GameManager` for UI and scoring

## Tech Stack
Unity 2022.3+, C#, 2D, Unity Input System, Animator

## Extension Ideas
- Mehrere Szenen / Multiple scenes
- Schwierigkeitsgrade / Difficulty levels
- Timer-bonus / Time bonus
- Story-Modus / Story mode
