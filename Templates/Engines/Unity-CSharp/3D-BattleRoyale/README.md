# 3D-BattleRoyale Template

## Beschreibung
Ein Battle-Royale-Spiel mit Fallschirm-Springen, Schrumpf-Zone, Waffen-Fundstücken und letztem Überlebenden.

## Description
A battle royale game with parachute jumping, shrinking zone, weapon loot, and last survivor.

## Features
- Fallschirm-Springen / Parachute jumping
- Schrumpfende Zone / Shrinking zone
- Waffen- und Item-Fundstücke / Weapon and item loot
- Spieler-Health und Rüstung / Player health and armor
- Kill-Feed / Kill feed
- MiniMap mit Zone / Minimap with zone

## How to Use
1. Attach `PlayerController` for FPS/TPS controls
2. Attach `WeaponSpawner` for loot generation
3. Attach `ZoneController` for shrinking zone
4. Attach `GameManager` for match state

## Tech Stack
Unity 2022.3+, C#, 3D Physics, Unity Input System, NavMesh, Cinemachine, TextMeshPro

## Extension Ideas
- Squad-Modus / Squad mode
- Fahrzeuge / Vehicles
- Wiederbelebungs-System / Revival system
- Events und Supply-Drops / Events and supply drops
- Battle-Pass / Battle pass
