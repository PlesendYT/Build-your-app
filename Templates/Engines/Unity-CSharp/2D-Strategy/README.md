# 2D-Strategy Template

## Beschreibung
Ein rundenbasiertes 2D-Strategiespiel mit Grid-Bewegung, Einheiten-Kampf und Ressourcen-Management.

## Description
A turn-based 2D strategy game with grid movement, unit combat, and resource management.

## Features
- Grid-basiertes Bewegungssystem / Grid-based movement system
- Runden-basiertes Gameplay / Turn-based gameplay
- Einheiten mit verschiedenen Typen / Units with different types
- Ressourcen-Management / Resource management
- KI-Gegner / AI opponent
- Minikarte / Minimap

## How to Use
1. Attach `GridManager` for tile management
2. Attach `GameManager` for turn logic
3. Attach `Unit` to unit prefabs
4. Attach `TurnManager` for turn order

## Tech Stack
Unity 2022.3+, C#, 2D Physics, Tilemaps, Unity Input System, TextMeshPro

## Extension Ideas
- Mehrere Fraktionen / Multiple factions
- Technologie-Baum / Technology tree
- Online-Multiplayer / Online multiplayer
- Karten-Editor / Map editor
- Kampagnen-Modus / Campaign mode
