# 3D-RPG Template

## Beschreibung
Ein 3D-Rollenspiel mit Inventar, Quests, Charakter-Level-System und NPC-Interaktionen.

## Description
A 3D role-playing game with inventory, quests, character leveling system, and NPC interactions.

## Features
- Charakter-Statistiken (Stärke, Geschick, etc.) / Character stats (strength, dexterity, etc.)
- Inventar-System / Inventory system
- Quest-Log / Quest log
- NPC-Dialoge / NPC dialogues
- Erfahrungs- und Level-System / Experience and leveling system
- Ausrüstungs-Slots / Equipment slots

## How to Use
1. Attach `PlayerController` for movement
2. Attach `Inventory` for item management
3. Attach `QuestManager` for quest tracking
4. Attach `GameManager` for game state

## Tech Stack
Unity 2022.3+, C#, 3D Physics, Unity Input System, Cinemachine, TextMeshPro

## Extension Ideas
- Skill-Baum / Skill tree
- Crafting-System / Crafting system
- Fraktionen / Factions
- Handels-System / Trading system
- Multiplayer / Multiplayer
