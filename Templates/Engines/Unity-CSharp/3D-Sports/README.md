# 3D-Sports Template

## Beschreibung
Ein Sport-Spiel mit Ballphysik, Spieler-Steuerung, Punktezählung und KI-Gegnern.

## Description
A sports game with ball physics, player control, scoring, and AI opponents.

## Features
- Ballphysik / Ball physics
- Spieler-Bewegung und Aktionen / Player movement and actions
- Punkte-Anzeige / Score display
- Timer-System / Timer system
- KI-Gegner / AI opponents
- Mehrere Sportarten-Grundlage / Multi-sport foundation

## How to Use
1. Attach `BallController` to ball GameObject
2. Attach `PlayerController` to player character
3. Attach `ScoreManager` for score tracking
4. Attach `GameManager` for match state

## Tech Stack
Unity 2022.3+, C#, 3D Physics, Unity Input System, Cinemachine

## Extension Ideas
- Mehrere Sportarten / Multiple sports
- Turnier-Modus / Tournament mode
- Charakter-Anpassung / Character customization
- Kommentator-Audio / Commentator audio
- Online-Multiplayer / Online multiplayer
