# AR-Basic Template

## Beschreibung
Ein Augmented-Reality-Grundgerüst mit Image-Tracking, Platzierung von 3D-Objekten und Touch-Interaktionen.

## Description
An augmented reality basic framework with image tracking, 3D object placement, and touch interactions.

## Features
- Image-Tracking / Image tracking
- 3D-Objekt-Platzierung / 3D object placement
- Touch-Interaktionen / Touch interactions
- AR-Kamera-Setup / AR camera setup
- Lichtschätzung / Light estimation
- Multi-Objekt-Tracking / Multi-object tracking

## How to Use
1. Requires AR Foundation and ARKit/ARCore packages
2. Attach `ARManager` to AR Session Origin
3. Attach `PlacementController` for object placement
4. Configure reference images in AR Reference Image Library

## Tech Stack
Unity 2022.3+, C#, AR Foundation, ARKit/ARCore, Unity Input System, TextMeshPro

## Extension Ideas
- Multi-User-AR / Multi-user AR
- AR-Messungen / AR measurements
- Gesichts-Tracking / Face tracking
- Marker-loses Tracking / Markerless tracking
- Cloud-Anchors / Cloud anchors
