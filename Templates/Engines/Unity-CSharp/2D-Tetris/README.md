# 2D-Tetris Template

## Beschreibung
Das klassische Tetris-Spiel mit fallenden Blöcken, Reiheneliminierung und Level-System. Ein zeitloser Puzzle-Klassiker.

## Description
The classic Tetris game with falling blocks, line clearing, and level system. A timeless puzzle classic.

## Features
- 7 Standard-Tetrominos / 7 standard tetrominoes
- Rotation und Vorausschau / Rotation and next-piece preview
- Reiheneliminierung mit Punkten / Line clearing with points
- Level-System mit steigender Geschwindigkeit / Level system with increasing speed

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `TetrisBoard` to the board GameObject
3. Attach `TetrominoController` to each tetromino prefab
4. Attach `GameManager` for scoring and levels

## Tech Stack
Unity 2022.3+, C#, 2D, Unity Input System, Coroutines
