# 2D-BeatEmUp Template

## Beschreibung
Ein Side-Scrolling-Prügelspiel mit Combos, mehreren Gegnertypen und Level-Fortschritt. Grundlage für Arcade-Kampfspiele.

## Description
A side-scrolling beat'em'up with combos, multiple enemy types, and level progression. Foundation for arcade fighting games.

## Features
- Nahkampf-Combo-System / Melee combo system
- Mehrere Gegnertypen / Multiple enemy types
- Gesundheits- und Energiebalken / Health and energy bars
- Level- und Wellen-System / Level and wave system
- Sammelbare Gegenstände / Collectible items
- Spezialfähigkeiten / Special abilities

## How to Use
1. Attach `PlayerCombat` to player with Animator
2. Attach `EnemyController` to enemy prefabs
3. Attach `HealthSystem` for health management
4. Attach `GameManager` for game state

## Tech Stack
Unity 2022.3+, C#, 2D Physics, Unity Input System, Animator

## Extension Ideas
- Spielbare Charaktere / Playable characters
- Koop-Multiplayer / Co-op multiplayer
- Waffen-Upgrades / Weapon upgrades
- Bosskämpfe / Boss fights
