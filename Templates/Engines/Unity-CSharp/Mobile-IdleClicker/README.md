# Mobile-IdleClicker Template

## Beschreibung
Ein für mobile Geräte optimierter Idle Clicker mit Touch-Tap, Offline-Einkommen und Performance-Optimierung.

## Description
A mobile-optimized idle clicker with touch tap, offline income, and performance optimization.

## Features
- Touch-Tap-Mechanik / Touch tap mechanic
- Offline-Einkommen / Offline income
- Mobile-optimierte UI / Mobile-optimized UI
- Generator-Upgrades / Generator upgrades
- Prestige-System / Prestige system
- Batterieschonender Modus / Battery-saving mode
- Push-Benachrichtigungen / Push notifications

## How to Use
1. Attach `TapManager` for touch handling
2. Attach `ResourceGenerator` for auto-generation
3. Attach `UpgradeManager` for upgrades
4. Attach `GameManager` for game state and saving

## Tech Stack
Unity 2022.3+, C#, Mobile Input, TextMeshPro, UI Canvas, PlayerPrefs

- Erfolge / Achievements
- Events und Saison-Inhalte / Events and seasonal content
- Multiplayer-Rangliste / Multiplayer leaderboard
- Werbe-Belohnungen / Ad rewards
