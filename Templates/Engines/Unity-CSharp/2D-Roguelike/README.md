# 2D-Roguelike Template

## Beschreibung
Ein Roguelike-Spiel mit prozeduraler Dungeon-Generierung, Permadeath, Gegenständen und rundenbasierter oder Echtzeit-Kampfmechanik.

## Description
A roguelike game with procedural dungeon generation, permadeath, items, and turn-based or real-time combat mechanics.

## Features
- Prozedurale Dungeon-Generierung / Procedural dungeon generation
- Permadeath-System / Permadeath system
- Gegenstände und Ausrüstung / Items and equipment
- Gegner-Raum-für-Raum / Enemy room-by-room system
- Sichtfeld (Fog of War) / Field of view (Fog of War)
- Charakter-Statistiken / Character statistics

## How to Use
1. Attach `DungeonGenerator` to generate levels
2. Attach `PlayerController` to player
3. Create item prefabs with appropriate components

## Tech Stack
Unity 2022.3+, C#, 2D Physics, Tilemaps, Unity Input System

## Extension Ideas
- Mehrere Stockwerke / Multiple floors
- Zauber und Fähigkeiten / Spells and skills
- Händler-Räume / Merchant rooms
- Boss-Räume / Boss rooms
- Charakter-Klassen / Character classes
