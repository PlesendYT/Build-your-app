# 2D-MatchThree Template

## Beschreibung
Ein klassisches Match-3-Puzzle-Spiel mit farbigen Edelsteinen auf einem Raster. Tausche benachbarte Steine, um Reihen von drei oder mehr zu bilden.

## Description
A classic match-3 puzzle game with colored gems on a grid. Swap adjacent tiles to form rows of three or more.

## Features
- Raster-basiertes Board / Grid-based board
- Drag-and-Swap-Steuerung / Drag and swap controls
- Kaskadierende Kettenreaktionen / Cascading chain reactions
- Punktesystem mit Combos / Score system with combos

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `BoardManager` to a Board GameObject
3. Attach `Tile` to each gem prefab
4. Attach `GameManager` for scoring and UI

## Tech Stack
Unity 2022.3+, C#, 2D Physics, Unity Input System

## Extension Ideas
- Zeitmodus / Timed mode
- Spezialsteine mit Effekten / Special gems with effects
- Level mit Zielvorgaben / Levels with objectives
- Spiel-Shop / In-game shop
