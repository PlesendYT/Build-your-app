# 3D-OpenWorld Template

## Beschreibung
Ein Open-World-Spiel mit freier Erkundung, dynamischen Events, Tag/Nacht-Zyklus und Welt-Management.

## Description
An open-world game with free exploration, dynamic events, day/night cycle, and world management.

## Features
- Große offene Welt / Large open world
- Dynamisches Wetter und Tag/Nacht / Dynamic weather and day/night
- Punkte von Interesse / Points of interest
- Fast-Travel-System / Fast travel system
- Dynamische Events / Dynamic events
- Welt-Karte / World map
- NPC-Bevölkerung / NPC population

## How to Use
1. Attach `WorldManager` for world state
2. Attach `PlayerController` for movement
3. Attach `QuestManager` for quest tracking
4. Attach `GameManager` for global state

## Tech Stack
Unity 2022.3+, C#, 3D Physics, Unity Input System, Terrain, Cinemachine, Post Processing

## Extension Ideas
- Flug-System / Flying system
- Reit-System / Mount system
- Fraktionen / Factions
- Handelsposten / Trading posts
- Multiplayer / Multiplayer
