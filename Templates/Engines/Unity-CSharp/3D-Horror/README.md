# 3D-Horror Template

## Beschreibung
Ein Horror-Spiel mit Taschenlampe, Spannungs-Aufbau, Jumpscares und Verfolgungs-KI.

## Description
A horror game with flashlight, tension building, jump scares, and pursuit AI.

## Features
- Taschenlampe mit Batterie / Flashlight with battery
- Spannungs-Musik-System / Tension music system
- Jumpscare-Trigger / Jump scare triggers
- Verfolgungs-KI / Pursuit AI
- Inventar-Rätsel / Inventory puzzles
- Atmosphärische Effekte / Atmospheric effects

## How to Use
1. Attach `PlayerController` with CharacterController
2. Attach `Flashlight` for light mechanics
3. Attach `EnemyAI` for horror enemy behavior
4. Attach `GameManager` for game state

## Tech Stack
Unity 2022.3+, C#, 3D Physics, Unity Input System, Audio Mixer, Post Processing

## Extension Ideas
- Notiz-System / Note system
- Versteck-Mechaniken / Hiding mechanics
- Mehrere Enden / Multiple endings
- Prozedurales Level-Design / Procedural level design
