# 2D-TopDown Template

## Beschreibung
Ein Top-Down-Spiel mit Bewegung in alle Richtungen, Gegnerverfolgung und sammelbaren Gegenständen. Grundlage für RPGs, Shootern und Adventures.

## Description
A top-down game with movement in all directions, enemy chasing, and collectible items. Foundation for RPGs, shooters, and adventures.

## Features
- 8-Richtungs-Bewegung / 8-direction movement
- Gegner mit Verfolgungs-KI / Enemies with chase AI
- Inventar-Gegenstände / Inventory items
- Kamerafolge / Camera following
- Health-System / Health system

## How to Use
1. Attach `PlayerController` to player with Rigidbody2D and Collider2D
2. Attach `EnemyController` to enemy GameObjects
3. Attach `GameManager` to a persistent GameObject

## Tech Stack
Unity 2022.3+, C#, 2D Physics, Unity Input System

## Extension Ideas
- Waffen und Projektil-System / Weapons and projectile system
- NPC-Dialoge / NPC dialogues
- MiniMap / Minimap
- Erfahrungspunkte und Levelaufstieg / Experience points and leveling
