# 2D-Farming Template

## Beschreibung
Ein Farming-Spiel mit Pflanzenanbau, Ernte, Bewässerung und Wirtschaftskreislauf. Der Spieler bewirtschaftet Felder und baut seine Farm aus.

## Description
A farming game with crop planting, harvesting, watering, and economy cycle. The player manages fields and expands their farm.

## Features
- Bodenbearbeitung und Bepflanzung / Tilling and planting
- Wachstumsphasen mit Bewässerung / Growth stages with watering
- Ernte und Verkauf von Feldfrüchten / Harvesting and selling crops
- Farm-Erweiterung / Farm expansion

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `FarmManager` to the farm root
3. Attach `FieldPlot` to each field tile
4. Attach `PlayerFarmer` to the player character

## Tech Stack
Unity 2022.3+, C#, 2D, Unity Input System, Tilemaps

## Extension Ideas
- Tiere und Tierprodukte / Animals and animal products
- Jahreszeiten-Wetter / Seasonal weather
- NPC-Dorfbewohner / NPC villagers
- Rezepte und Kochen / Recipes and cooking
