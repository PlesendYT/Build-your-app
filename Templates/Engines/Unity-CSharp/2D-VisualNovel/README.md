# 2D-VisualNovel Template

## Beschreibung
Ein Dialog-basiertes Visual-Novel-Spiel mit Charakteren, Entscheidungen, Verzweigungen und Speicher-System. Grundlage für Story-Spiele.

## Description
A dialogue-based visual novel game with characters, choices, branching paths, and save system. Foundation for story games.

## Features
- Dialog-System mit Charakter-Porträts / Dialogue system with character portraits
- Verzweigende Entscheidungen / Branching choices
- Speicher- und Ladesystem / Save and load system
- Charakter-Verwaltung / Character management
- Hintergrund-Szenen / Background scenes
- Text-Geschwindigkeitssteuerung / Text speed control
- Auto-Play-Modus / Auto-play mode

## How to Use
1. Attach `DialogueManager` to handle dialogue flow
2. Attach `GameManager` for game state
3. Create dialogue ScriptableObjects for story data

## Tech Stack
Unity 2022.3+, C#, TextMeshPro, UI Toolkit, ScriptableObjects

## Extension Ideas
- CG-Galerie / CG gallery
- Stimmschauspiel / Voice acting
- Animierte Charaktere / Animated characters
- Multiple Endings / Multiple endings
- Mini-Spiele / Mini-games
