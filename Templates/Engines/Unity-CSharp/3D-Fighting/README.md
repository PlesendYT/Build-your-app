# 3D-Fighting Template

## Beschreibung
Ein 3D-Kampfspiel mit Combos, Spezialbewegungen, Gesundheitsbalken und Runden-System.

## Description
A 3D fighting game with combos, special moves, health bars, and round system.

## Features
- Nahkampf-Combo-System / Melee combo system
- Spezialbewegungen / Special moves
- Gesundheits- und Energiebalken / Health and energy bars
- Runden-System / Round system
- Charakter-Auswahl / Character selection
- KI-Gegner / AI opponent

## How to Use
1. Attach `FighterController` to each fighter
2. Attach `HealthBar` for UI health display
3. Attach `ComboSystem` for combo handling
4. Attach `GameManager` for match state

## Tech Stack
Unity 2022.3+, C#, 3D Physics, Unity Input System, Animator, Cinemachine

## Extension Ideas
- Online-Multiplayer / Online multiplayer
- Charakter-Anpassung / Character customization
- Turnier-Modus / Tournament mode
- Trainings-Modus / Training mode
- Story-Modus / Story mode
