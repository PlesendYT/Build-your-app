# 2D-EscapeRoom Template

## Beschreibung
Ein Escape-Room-Spiel mit Rätseln, versteckten Hinweisen und inventarbasierter Interaktion. Der Spieler muss einen Raum durch Kombinieren von Gegenständen und Lösen von Rätseln verlassen.

## Description
An escape room game with puzzles, hidden clues, and inventory-based interaction. The player must escape a room by combining items and solving puzzles.

## Features
- Inventarsystem mit Kombination / Inventory system with combination
- Interaktive Objekte mit Zuständen / Interactive objects with states
- Rätsel-Logik mit Bedingungen / Puzzle logic with conditions
- Mehrere Ausgänge basierend auf Lösungen / Multiple exits based on solutions

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `EscapeRoomManager` to the room root
3. Attach `InteractableObject` to each clickable item
4. Attach `InventoryUI` to the canvas

## Tech Stack
Unity 2022.3+, C#, 2D, TextMeshPro, Unity Input System

## Extension Ideas
- Mehrere Räume / Multiple rooms
- Story-Zweige / Story branches
- Sound-Rätsel / Sound puzzles
- Koop-Modus / Co-op mode
