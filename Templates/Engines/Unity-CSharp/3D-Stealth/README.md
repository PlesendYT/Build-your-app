# 3D-Stealth Template

## Beschreibung
Ein Schleichspiel mit Wach-KI, Alarm-System, Versteck-Mechaniken und Tarnungs-Bewertung.

## Description
A stealth game with guard AI, alarm system, hiding mechanics, and stealth rating.

## Features
- Wach-KI mit Sicht- und Hörbereich / Guard AI with sight and hearing range
- Alarm-System / Alarm system
- Versteck-Mechaniken (Schatten, Verstecke) / Hiding mechanics (shadows, hiding spots)
- Tarnungs-Bewertung / Stealth rating
- Ablenkungs-Items / Distraction items
- Schleichen und Rennen / Crouch and sprint

## How to Use
1. Attach `PlayerController` for movement and stealth
2. Attach `GuardAI` to guard GameObjects
3. Attach `AlarmSystem` for alarm state
4. Attach `GameManager` for mission state

## Tech Stack
Unity 2022.3+, C#, 3D Physics, Unity Input System, NavMesh, Cinemachine

## Extension Ideas
- Hacking-Minispiel / Hacking minigame
- Tarn-Outfits / Disguise outfits
- Überwachungskameras / Security cameras
- Lasergitter / Laser grids
- Mehrere Missions-Ziele / Multiple mission objectives
