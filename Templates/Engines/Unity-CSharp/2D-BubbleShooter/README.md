# 2D-BubbleShooter Template

## Beschreibung
Ein Bubble-Shooter-Spiel mit physikbasierten Schüssen, Farbgruppen und Deckenmechanik. Der Spieler schießt farbige Blasen, um Gruppen von drei oder mehr zu bilden.

## Description
A bubble shooter game with physics-based shots, color groups, and ceiling mechanics. The player shoots colored bubbles to form groups of three or more.

## Features
- Physikbasierter Abschuss / Physics-based shooting
- Farbgruppen-Erkennung / Color group detection
- Deckenmechanik mit fallenden Blasen / Ceiling mechanics with falling bubbles
- Zufällige Farbauswahl / Random color selection

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `BubbleShooterManager` to the board root
3. Attach `Bubble` to each bubble prefab
4. Attach `Aimer` for aiming control

## Tech Stack
Unity 2022.3+, C#, 2D Physics, Unity Input System

## Extension Ideas

- Combos und Spezialeffekte / Combos and special effects
- Schwierigkeitssteigerung / Difficulty progression
