# 2D-MemoryGame Template

## Beschreibung
Ein klassisches Memory-Kartenspiel mit Kartenpaaren, Dreh-Animationen und Schwierigkeitsgraden. Trainiert das visuelle Gedächtnis.

## Description
A classic memory card game with card pairs, flip animations, and difficulty levels. Trains visual memory.

## Features
- Kartengitter mit zufälliger Anordnung / Card grid with random layout
- Dreh-Animation mit Smooth-Steps / Flip animation with smooth steps
- Paar-Erkennung und Punktesystem / Pair detection and scoring
- Schwierigkeitsgrade (4x4, 4x6, 6x6) / Difficulty levels (4x4, 4x6, 6x6)

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `MemoryBoard` to the board GameObject
3. Attach `Card` to each card prefab
4. Attach `GameManager` for scoring

## Tech Stack
Unity 2022.3+, C#, 2D, Animator, TextMeshPro

## Extension Ideas
- Multiplayer (abwechselnd) / Multiplayer (turn-based)
- Sound-Effekte / Sound effects
- Kartendesigns / Card themes
- Bestenliste / High scores
