# 3D-Platformer Template

## Beschreibung
Ein 3D-Plattformer mit Springen, beweglichen Plattformen, sammelbaren Gegenständen und Checkpoints.

## Description
A 3D platformer with jumping, moving platforms, collectibles, and checkpoints.

## Features
- 3D-Bewegung und Springen / 3D movement and jumping
- Bewegliche Plattformen / Moving platforms
- Sammelbare Gegenstände / Collectibles
- Checkpoint-System / Checkpoint system
- Kamera-Nachführung / Camera following
- Partikel-Effekte / Particle effects

## How to Use
1. Attach `PlayerController` to player with CharacterController or Rigidbody
2. Attach `MovingPlatform` to platform GameObjects
3. Attach `Collectible` to collectible GameObjects
4. Attach `GameManager` for game state

## Tech Stack
Unity 2022.3+, C#, 3D Physics, Unity Input System, Cinemachine

## Extension Ideas
- Power-Ups (Fliegen, Schwimmen) / Power-ups (flying, swimming)
- Geheimbereiche / Secret areas
- Boss-Level / Boss levels
- Zeitrennen-Modus / Time trial mode
