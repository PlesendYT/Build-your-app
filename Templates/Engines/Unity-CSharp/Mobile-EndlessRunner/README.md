# Mobile-EndlessRunner Template

## Beschreibung
Ein für mobile Geräte optimierter Endless Runner mit Swipe-Steuerung und Leistungsoptimierung.

## Description
A mobile-optimized endless runner with swipe controls and performance optimization.

## Features
- Swipe-Steuerung (Wischen, Tippen) / Swipe controls (swipe, tap)
- Performance-Optimierung / Performance optimization
- Mobile UI (Touch-freundlich) / Mobile UI (touch-friendly)
- Hindernis-System / Obstacle system
- Highscore mit Firebase / Highscore with Firebase
- Batterieschonender Modus / Battery-saving mode

## How to Use
1. Attach `SwipeController` for touch input
2. Attach `ObstacleSpawner` for obstacles
3. Attach `ScoreManager` for scoring
4. Attach `GameManager` for game state

## Tech Stack
Unity 2022.3+, C#, Mobile Input, TextMeshPro, Object Pooling, UI Canvas

## Extension Ideas
- Charakter-Skins / Character skins
- Tägliche Herausforderungen / Daily challenges
- Werbe-Integration / Ad integration
- In-App-Käufe / In-app purchases
- Online-Bestenliste / Online leaderboard
