# 3D-Strategy Template

## Beschreibung
Ein 3D-Echtzeitstrategie-Spiel mit Einheiten-Auswahl, Bewegungsbefehlen, Ressourcen und Basisbau.

## Description
A 3D real-time strategy game with unit selection, movement commands, resources, and base building.

## Features
- RTS-Kamera-Steuerung / RTS camera control
- Einheiten-Auswahl und -Bewegung / Unit selection and movement
- Ressourcen-Sammeln / Resource gathering
- Basisbau / Base building
- KI-Gegner / AI opponent
- Minimap / Minimap

## How to Use
1. Attach `CameraController` for RTS camera
2. Attach `Unit` to unit prefabs
3. Attach `Building` for constructions
4. Attach `GameManager` for game state

## Tech Stack
Unity 2022.3+, C#, 3D Physics, Unity Input System, NavMesh, Terrain, TextMeshPro

## Extension Ideas
- Technologie-Baum / Technology tree
- Mehrspieler / Multiplayer
- Luft- und Bodeneinheiten / Air and ground units
- Kampagnen-Modus / Campaign mode
