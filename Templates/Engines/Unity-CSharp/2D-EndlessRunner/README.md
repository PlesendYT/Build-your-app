# 2D-EndlessRunner Template

## Beschreibung
Ein Endless-Runner-Spiel mit automatisch laufendem Spieler, Hindernissen, Power-Ups und prozeduraler Level-Generierung.

## Description
An endless runner game with auto-running player, obstacles, power-ups, and procedural level generation.

## Features
- Automatisches Laufen / Auto-running
- Hindernis-Spawning / Obstacle spawning
- Power-Ups (Schild, Magnet) / Power-ups (shield, magnet)
- Prozedurale Level-Generierung / Procedural level generation
- Highscore-System / Highscore system
- Scrollender Hintergrund / Scrolling background

## How to Use
1. Attach `PlayerController` to player with Rigidbody2D
2. Attach `ObstacleSpawner` for obstacle generation
3. Attach `ScrollingBackground` for parallax effect
4. Attach `GameManager` for game state and scoring

## Tech Stack
Unity 2022.3+, C#, 2D Physics, Unity Input System

## Extension Ideas
- Charakter-Skins / Character skins
- Missionen und Erfolge / Missions and achievements
- Verschiedene Umgebungen / Different environments
- Online-Bestenliste / Online leaderboard
