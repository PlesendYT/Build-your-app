# 2D-Tycoon Template

## Beschreibung
Ein Tycoon-Management-Spiel mit Wirtschaftssimulation, Ressourcenmanagement und Expansionsmechaniken. Der Spieler baut ein Geschäftsimperium auf.

## Description
A tycoon management game with economy simulation, resource management, and expansion mechanics. The player builds a business empire.

## Features
- Wirtschaftskreislauf mit Angebot/Nachfrage / Economy cycle with supply/demand
- Mehrere veränderbare Variablen / Multiple upgradeable variables
- Automatische Einnahmen / Automatic income generation
- Visuelle Expansion des Geländes / Visual expansion of premises

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `TycoonManager` to the game root
3. Attach `Upgradeable` to purchasable items
4. Attach `CustomerSpawner` for NPC flow

## Tech Stack
Unity 2022.3+, C#, 2D, Unity Input System, Object Pooling

## Extension Ideas
- Verschiedene Geschäftstypen / Different business types
- Mitarbeiter-Management / Employee management
- Wettbewerber-KI / Competitor AI
- Markt-Fluktuationen / Market fluctuations
