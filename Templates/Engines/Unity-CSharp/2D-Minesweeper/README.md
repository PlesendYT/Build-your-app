# 2D-Minesweeper Template

## Beschreibung
Das klassische Minesweeper-Spiel mit aufdeckbarem Raster, Minenzählung und Flaggenmarkierung. Ein Strategiespiel für Logikliebhaber.

## Description
The classic minesweeper game with revealable grid, mine counting, and flag marking. A strategy game for logic lovers.

## Features
- Aufdeckbares Raster mit Zahlen / Revealable grid with numbers
- Minenplatzierung nach erstem Klick / Mine placement after first click
- Flaggen- und Fragezeichen-Modus / Flag and question mark mode
- Automatische Aufdeckung bei leeren Feldern / Auto-reveal for empty cells

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `MinesweeperBoard` to the board GameObject
3. Attach `Cell` to each cell prefab
4. Attach `GameManager` for UI

## Tech Stack
Unity 2022.3+, C#, 2D, TextMeshPro, Unity Input System

- Timer / Timer
