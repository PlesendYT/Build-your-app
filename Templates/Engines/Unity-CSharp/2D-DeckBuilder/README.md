# 2D-DeckBuilder Template

## Beschreibung
Ein Deckbau-Kartenspiel mit Karten-Sammlung, Deck-Verwaltung und rundenbasierten Kämpfen. Der Spieler baut ein Kartendeck und besiegt Gegner.

## Description
A deck-building card game with card collection, deck management, and turn-based combat. The player builds a card deck and defeats enemies.

## Features
- Kartendeck mit Mischen und Ziehen / Card deck with shuffling and drawing
- Rundenbasierte Kämpfe / Turn-based combat
- Karten-Sammelsystem / Card collection system
- Gegner mit unterschiedlichen Decks / Enemies with different decks

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `DeckManager` to the game root
3. Attach `Card` to each card prefab
4. Attach `BattleManager` for combat logic
5. Attach `HandUI` for card display

## Tech Stack
Unity 2022.3+, C#, 2D, TextMeshPro, Unity Input System
