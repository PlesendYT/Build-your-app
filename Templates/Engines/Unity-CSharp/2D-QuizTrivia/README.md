# 2D-QuizTrivia Template

## Beschreibung
Ein Quiz- und Trivia-Spiel mit Multiple-Choice-Fragen, Kategorien und Punktesystem. Ideal für Lern- und Wissensspiele.

## Description
A quiz and trivia game with multiple-choice questions, categories, and scoring system. Ideal for educational and knowledge games.

## Features
- Multiple-Choice-Fragen / Multiple-choice questions
- Kategorien und Schwierigkeitsgrade / Categories and difficulty levels
- Highscore und Statistiken / Highscore and statistics
- Timer pro Frage / Timer per question

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `QuizManager` to a GameObject
3. Attach `QuestionDisplay` to the UI canvas
4. Configure questions in QuizManager

## Tech Stack
Unity 2022.3+, C#, 2D, TextMeshPro, Unity Input System
