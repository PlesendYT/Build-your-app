# 2D-WordGame Template

## Beschreibung
Ein Wortspiel mit Buchstaben-Raster, Worterkennung und Punktesystem. Der Spieler findet und markiert Wörter in einem Buchstabengitter.

## Description
A word game with letter grids, word recognition, and scoring system. The player finds and marks words in a letter grid.

## Features
- Buchstaben-Gitter mit zufälliger Füllung / Letter grid with random filling
- Wortliste mit verschiedenen Längen / Word list with various lengths
- Drag-to-Select Markierung / Drag-to-select highlighting
- Punkte nach Wortlänge / Score by word length

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `WordGrid` to the board GameObject
3. Attach `LetterCell` to each cell prefab
4. Configure word list in WordGrid inspector

## Tech Stack
Unity 2022.3+, C#, 2D, TextMeshPro, Unity Input System
