# VR-Basic Template

## Beschreibung
Ein Virtual-Reality-Grundgerüst mit Bewegungssteuerung, Teleportation, Greifen und Interaktionen.

## Description
A virtual reality basic framework with motion controls, teleportation, grabbing, and interactions.

## Features
- VR-Bewegung (Teleportation, kontinuierlich) / VR movement (teleport, continuous)
- Greif-Mechanik / Grab mechanics
- Objekt-Interaktion / Object interaction
- UI-Interaktion in VR / UI interaction in VR
- Raum-Skalierung / Room-scale
- Controller-Input / Controller input

## How to Use
1. Requires XR Interaction Toolkit package
2. Attach `VRInput` to XR Origin
3. Attach `TeleportController` for teleportation
4. Attach `GrabController` for object grabbing

## Tech Stack
Unity 2022.3+, C#, XR Interaction Toolkit, XR Plugin Management, TextMeshPro

## Extension Ideas
- Hand-Tracking / Hand tracking
- Mehrspieler-VR / Multiplayer VR
- VR-UI-Menüs / VR UI menus
- Physik-Interaktionen / Physics interactions
- Raum-Einrichtung / Room setup
