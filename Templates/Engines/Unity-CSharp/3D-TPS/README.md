# 3D-TPS Template

## Beschreibung
Ein Third-Person-Shooter mit über-der-Schulter Kamera, Ausweichen und Deckungssystem.

## Description
A third-person shooter with over-the-shoulder camera, dodging, and cover system.

## Features
- Third-Person-Kamera / Third-person camera
- Zielen und Schießen / Aiming and shooting
- Ausweich-Rolle / Dodge roll
- Deckungssystem / Cover system
- Gegner-KI / Enemy AI
- Waffen-Upgrades / Weapon upgrades

## How to Use
1. Attach `PlayerController` to player with Rigidbody
2. Attach `CameraController` for third-person camera
3. Attach `Weapon` to weapon GameObject
4. Attach `EnemyController` to enemy prefabs

## Tech Stack
Unity 2022.3+, C#, 3D Physics, Unity Input System, Cinemachine, Animator

## Extension Ideas
- Skill-Baum / Skill tree
- Koop-Multiplayer / Co-op multiplayer
- Fahrzeuge / Vehicles
- Missions-System / Mission system
