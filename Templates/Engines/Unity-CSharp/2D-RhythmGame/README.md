# 2D-RhythmGame Template

## Beschreibung
Ein Rhythmus-Spiel mit fallenden Noten, mehreren Spuren und Punkte-Bewertung. Grundlage für Musik- und Tanzspiele.

## Description
A rhythm game with falling notes, multiple lanes, and score grading. Foundation for music and dance games.

## Features
- Fallende Noten auf Spuren / Falling notes on lanes
- Mehrere Schwierigkeitsgrade / Multiple difficulty levels
- Punktesystem mit Bewertung / Scoring system with grading
- Combo-System / Combo system
- Song-Auswahl / Song selection
- Audio-Synchronisation / Audio synchronization

## How to Use
1. Attach `NoteSpawner` for spawning notes
2. Attach `Note` to note prefabs
3. Attach `ScoreManager` for scoring
4. Attach `GameManager` for game state

## Tech Stack
Unity 2022.3+, C#, Unity Input System, Audio System, TextMeshPro

- Song-Editor / Song editor
