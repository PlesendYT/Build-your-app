# 2D-IdleClicker Template

## Beschreibung
Ein Idle-Clicker-Spiel mit Klick-Mechaniken, automatischen Ressourcengeneratoren, Upgrades und Prestige-System.

## Description
An idle clicker game with click mechanics, automatic resource generators, upgrades, and prestige system.

## Features
- Klick-Mechanik zur Ressourcengewinnung / Click mechanic for resource gain
- Automatische Generatoren / Automatic generators
- Upgrade-System / Upgrade system
- Prestige-System / Prestige system
- Statistiken und Meilensteine / Statistics and milestones
- Offline-Einkommen / Offline income

## How to Use
1. Attach `ClickManager` for click handling
2. Attach `ResourceGenerator` for auto-generation
3. Attach `Upgrade` to upgrade button GameObjects
4. Attach `GameManager` for game state and persistence

## Tech Stack
Unity 2022.3+, C#, Unity Input System, TextMeshPro, UI Toolkit

## Extension Ideas
- Erfolge / Achievements
- Events und Saison-Inhalte / Events and seasonal content
- Mehrere Ressourcen-Typen / Multiple resource types
- Mini-Spiele / Mini-games
