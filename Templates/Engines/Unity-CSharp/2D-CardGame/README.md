# 2D-CardGame Template

## Beschreibung
Ein rundenbasiertes Kartenspiel mit Deck-Verwaltung, Spielzügen und Effekten. Grundlage für Sammelkarten- oder Deckbau-Spiele.

## Description
A turn-based card game with deck management, gameplay turns, and effects. Foundation for collectible card or deck-building games.

## Features
- Kartensystem (Effekte, Kosten, Typen) / Card system (effects, costs, types)
- Deck-Verwaltung / Deck management
- Runden-basiertes Spiel / Turn-based gameplay
- Handkarten-Verwaltung / Hand card management
- Spieler- und Gegner-Health / Player and enemy health
- Animierte Karten-Effekte / Animated card effects

## How to Use
1. Attach `GameManager` for turn logic
2. Attach `Deck` for card management
3. Attach `PlayerHand` for hand display
4. Create card ScriptableObjects for card data

## Tech Stack
Unity 2022.3+, C#, TextMeshPro, UI Toolkit, ScriptableObjects

## Extension Ideas
- Online-Multiplayer / Online multiplayer
- Karten-Crafting / Card crafting
- Story-Kampagne / Story campaign
- Turnier-Modus / Tournament mode
