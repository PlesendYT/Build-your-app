# 2D-DungeonCrawler Template

## Beschreibung
Ein Dungeon-Crawler-Spiel mit rundenbasierter Bewegung, Kämpfen und Schatzkammern. Der Spieler erkundet prozedural generierte Verliese.

## Description
A dungeon crawler game with turn-based movement, combat, and treasure rooms. The player explores procedurally generated dungeons.

## Features
- Rundenbasierte Bewegung auf einem Raster / Turn-based movement on a grid
- Nah- und Fernkampfangriffe / Melee and ranged attacks
- Gegner mit KI-Verhalten / Enemies with AI behavior
- Schätze und Fallen / Treasures and traps

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `DungeonGenerator` to generate the level
3. Attach `PlayerCrawler` to the player character
4. Attach `EnemyCrawler` to enemy prefabs
5. Attach `GameManager` for game state

## Tech Stack
Unity 2022.3+, C#, 2D, Unity Input System, Procedural Generation

## Extension Ideas
- Mehrere Dungeon-Etagen / Multiple dungeon floors
- Charakterentwicklung / Character progression
- Zauber und Fertigkeiten / Spells and skills
- Boss-Räume / Boss rooms
