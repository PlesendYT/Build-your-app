# 2D-Pinball Template

## Beschreibung
Ein physikbasiertes Pinball-Spiel mit Flipperarmen, Federmechanik und Punktesystem. Basiert auf Unity Physics 2D.

## Description
A physics-based pinball game with flippers, plunger mechanics, and scoring system. Based on Unity Physics 2D.

## Features
- Physikbasierte Flipperarme / Physics-based flippers
- Feder-Mechanik mit variabler Kraft / Plunger mechanics with variable power
- Bumper und Scoring-Elemente / Bumpers and scoring elements
- Multi-Ball-Modus / Multi-ball mode

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `PinballManager` to the table root
3. Attach `FlipperController` to left/right flippers
4. Attach `PlungerController` to the plunger
5. Attach `Bumper` to bumper GameObjects

## Tech Stack
Unity 2022.3+, C#, 2D Physics, Unity Input System, Joints 2D

## Extension Ideas
- Rampen und Loops / Ramps and loops
- Digitale Anzeige / Digital display
- Tisch-Mechaniken / Table mechanics
- Highscore-Tabelle / Highscore table
