# 3D-Survival Template

## Beschreibung
Ein Überlebensspiel mit Crafting, Ressourcen-Sammeln, Hungersystem und Basisbau.

## Description
A survival game with crafting, resource gathering, hunger system, and base building.

## Features
- Ressourcen-Sammeln (Holz, Stein, etc.) / Resource gathering (wood, stone, etc.)
- Crafting-System / Crafting system
- Hunger-/Durst-Mechaniken / Hunger/thirst mechanics
- Inventar-System / Inventory system
- Basisbau / Base building
- Tag/Nacht-Zyklus / Day/night cycle

## How to Use
1. Attach `PlayerController` for movement and actions
2. Attach `Inventory` for item management
3. Attach `CraftingSystem` for recipes
4. Attach `ResourceNode` to resource GameObjects

## Tech Stack
Unity 2022.3+, C#, 3D Physics, Unity Input System, Terrain, Post Processing

## Extension Ideas
- NPC-Dorfbewohner / NPC villagers
- Fahrzeuge / Vehicles
- Wetter-Jahreszeiten / Weather seasons
- Feinde bei Nacht / Night enemies
- Multiplayer / Multiplayer
