# 2D-ArtDrawing Template

## Beschreibung
Ein Kunst- und Zeichenspiel mit Farbpalette, Pinselgrößen und Leinwand. Der Spieler kann frei malen oder Vorlagen ausmalen.

## Description
An art and drawing game with color palette, brush sizes, and canvas. The player can free-draw or color templates.

## Features
- Freihand-Zeichenwerkzeug / Freehand drawing tool
- Farbpalette mit Farbauswahl / Color palette with picker
- Pinselgrößen / Brush sizes
- Rückgängig/Wiederherstellen / Undo/Redo

## How to Use
1. Import into Unity 2022.3+ LTS
2. Attach `DrawingCanvas` to the canvas GameObject
3. Attach `ToolbarUI` to the UI canvas
4. Configure colors and brush sizes

## Tech Stack
Unity 2022.3+, C#, 2D, Texture2D, Unity Input System, TextMeshPro
