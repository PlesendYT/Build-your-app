# 2D-Puzzle (Solar2D Lua)

## Beschreibung / Description

**DE:** Ein 2D-Rätselspiel in Solar2D mit Schiebeblöcken und Druckplatten.

**EN:** A 2D puzzle game in Solar2D with pushable blocks and pressure plates.

## Features

- Schiebeblöcke / Pushable blocks
- Druckplatten / Pressure plates
- Türen / Doors
- Level-Manager / Level manager
- Rücksetz-Funktion / Reset function
