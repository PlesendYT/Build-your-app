# 2D-CardGame (Solar2D Lua)

## Beschreibung / Description

**DE:** Ein Kartenspiel in Solar2D mit Deck, Hand und rundenbasiertem Kampf.

**EN:** A card game in Solar2D with deck, hand, and turn-based combat.

## Features

- Kartendeck / Card deck
- Mischen / Shuffling
- Karten ausspielen / Playing cards
- Mana-/Energiesystem / Mana/energy system
- Gegner-KI / Enemy AI
