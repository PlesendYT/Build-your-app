# 2D-ShootEmUp (Solar2D Lua)

## Beschreibung / Description

**DE:** Ein klassisches Shoot-em-up in Solar2D mit scrollendem Sternenhimmel und Gegnerwellen.

**EN:** A classic shoot-em-up in Solar2D with scrolling starfield and enemy waves.

## Features

- Spieler-Steuerung / Player controls
- Automatisches Feuern / Auto-fire
- Gegnerwellen / Enemy waves
- Power-Ups
- Punktesystem / Score system
