# 2D-TopDown (Solar2D Lua)

## Beschreibung / Description

**DE:** Ein Top-Down-Abenteuer in Solar2D mit 4-Richtungs-Bewegung und Gegnern.

**EN:** A top-down adventure in Solar2D with 4-directional movement and enemies.

## Features

- 4-Richtungs-Bewegung / 4-directional movement
- Kollision mit Wänden / Wall collision
- Gegner-Jagd / Enemy chase
- Item-Inventar / Item inventory
- Tür-Mechanik / Door mechanics
