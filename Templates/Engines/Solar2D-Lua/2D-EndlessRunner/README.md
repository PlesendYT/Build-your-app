# 2D-EndlessRunner (Solar2D Lua)

## Beschreibung / Description

**DE:** Ein Endlosläufer in Solar2D mit automatischem Scrollen und Hindernissen.

**EN:** An endless runner in Solar2D with auto-scrolling and obstacles.

## Features

- Automatische Bewegung / Auto movement
- Springen und Rutschen / Jump and slide
- Zufällige Hindernisse / Random obstacles
- Parallax-Hintergrund / Parallax background
- Highscore / Highscore
