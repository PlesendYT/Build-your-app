# 2D-Puzzle (Defold Lua)

## Beschreibung / Description

**DE:** Ein 2D-Rätselspiel in Defold mit Schiebeblöcken, Hebeln und Druckplatten.

**EN:** A 2D puzzle game in Defold with pushable blocks, levers, and pressure plates.

## Features

- Schiebeblöcke / Pushable blocks
- Hebel-Mechanik / Lever mechanics
- Druckplatten / Pressure plates
- Türen / Doors
- Level-Manager / Level manager
