# 2D-CardGame (Defold Lua)

## Beschreibung / Description

**DE:** Ein Kartenspiel in Defold mit Deck-Verwaltung, Karten-Hand und Rundenkampf.

**EN:** A card game in Defold with deck management, card hand, and turn-based combat.

## Features

- Kartendeck / Card deck
- Mischen / Shuffling
- Hand-Management / Hand management
- Karten ausspielen / Playing cards
- Energie-/Manasystem / Energy/mana system
- Rundenbasiert / Turn-based
