# 2D-TowerDefense (Defold Lua)

## Beschreibung / Description

**DE:** Ein Turmverteidigungsspiel in Defold mit Wegpunkten, Türmen und Wellen.

**EN:** A tower defense game in Defold with waypoints, towers, and waves.

## Features

- Wegpunkt-System / Waypoint system
- Verschiedene Türme / Different towers
- Gegner-Wellen / Enemy waves
- Gold/ Wirtschaft / Gold/economy
- Turm-Upgrades / Tower upgrades
