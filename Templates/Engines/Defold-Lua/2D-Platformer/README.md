# 2D-Platformer (Defold Lua)

## Beschreibung / Description

**DE:** Ein Defold-Plattformer mit Spieler, Gegner-Patrouille und Münzen.

**EN:** A Defold platformer with player, enemy patrols, and coins.

## Features

- Bewegung und Sprung / Movement and jump
- Kollision mit Kacheln / Tile collision
- Gegner-KI / Enemy AI
- Münzen-Sammeln / Coin collecting
- Partikeleffekte / Particle effects

## How to Use

1. Defold-Projekt erstellen
2. `.script`-Dateien an Game Objects anhängen
3. Tilesource und Collision-Objekte einrichten

## Tech Stack

- Defold Engine 1.6+
- `go.property()`, `msg.post()`, `vmath.vector3()`
- Factory-Komponenten

## Extension Ideas

- Power-Ups
- Moving Platforms
- Checkpoints
- Bosskampf
