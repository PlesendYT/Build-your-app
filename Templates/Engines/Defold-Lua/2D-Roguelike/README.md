# 2D-Roguelike (Defold Lua)

## Beschreibung / Description

**DE:** Ein Roguelike in Defold mit prozeduraler Dungeon-Generierung und rundenbasiertem Kampf.

**EN:** A roguelike in Defold with procedural dungeon generation and turn-based combat.

## Features

- Prozedurale Dungeon-Generierung / Procedural dungeon generation
- Rundenbasierte Bewegung / Turn-based movement
- Gegner-KI / Enemy AI
- Items und Waffen / Items and weapons
- Fog of War / Nebel des Krieges
