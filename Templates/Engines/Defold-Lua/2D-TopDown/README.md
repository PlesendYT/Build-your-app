# 2D-TopDown (Defold Lua)

## Beschreibung / Description

**DE:** Ein Top-Down-Abenteuer in Defold mit 8-Richtungs-Bewegung und Gegner-Jagd.

**EN:** A top-down adventure in Defold with 8-directional movement and enemy chasing.

## Features

- 8-Richtungs-Bewegung / 8-directional movement
- Wandkollision / Wall collision
- Gegner mit Verfolgungs-KI / Enemy chase AI
- Item-Aufnahme / Item pickup
- Tür-Mechanik / Door mechanics
