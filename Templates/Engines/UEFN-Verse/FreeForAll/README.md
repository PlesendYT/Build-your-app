# FreeForAll – UEFN Verse Template

**Deutsch:** Ein Jeder-gegen-Jeden-Spielmodus mit Score-System, Respawn-Timer und Kill-Streak-Belohnungen.

**English:** A free-for-all game mode with scoring system, respawn timer, and kill streak rewards.

## Features

- Punkte pro Kill mit Leaderboard | Points per kill with leaderboard
- Respawn-Timer mit Checkpoint-Spawn | Respawn timer with checkpoint spawn
- Kill-Streak-Belohnungen (2x, 3x, 5x) | Kill streak rewards (2x, 3x, 5x)
- Zeitlimit oder Score-Limit | Time limit or score limit
- MVP-Auszeichnung am Ende | MVP award at end

## Tech Stack

- UEFN, Verse, Creative Devices

## Extension Ideas

- Waffen-Pickups auf der Karte | Weapon pickups on map
- Schwere Waffen mit Abklingzeit | Heavy weapons with cooldown
- Ranglisten-Punkte-System | Ranked points system
