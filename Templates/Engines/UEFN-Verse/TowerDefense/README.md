# TowerDefense – UEFN Verse Template

**Deutsch:** Ein Turmverteidigungs-Modus mit Wellen, verschiedenen Turm-Typen, Wegpunkten und Upgrade-System.

**English:** A tower defense mode with waves, different tower types, waypoints, and upgrade system.

## Features

- Feind-Wellen mit steigender Stärke | Enemy waves with increasing strength
- Verschiedene Turm-Typen (Geschütz, Eis, Feuer) | Different tower types (cannon, ice, fire)
- Wegpunkt-System für Feind-Pfade | Waypoint system for enemy paths
- Turm-Upgrade mit 3 Stufen | Tower upgrade with 3 levels
- Gold-System für Kills | Gold system for kills

## Tech Stack

- UEFN, Verse, Creative Devices, AIDirector

## Extension Ideas

- Spezial-Fähigkeiten pro Turm | Special abilities per tower
- Labyrinth-Bau durch Spieler | Maze building by players
- Boss-Wellen mit einzigartigen Gegnern | Boss waves with unique enemies
