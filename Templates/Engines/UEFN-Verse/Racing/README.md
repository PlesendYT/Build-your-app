# Racing – UEFN Verse Template

**Deutsch:** Ein Rennspiel-Modus mit Runden, Checkpoints, Platzierungen und Boost-Mechanik für UEFN.

**English:** A racing mode with laps, checkpoints, placements, and boost mechanic for UEFN.

## Features

- Rundensystem mit Start/Ziel-Erkennung | Lap system with start/finish detection
- Checkpoint-Reihenfolge-Validierung | Checkpoint order validation
- Platzierungs-Tracking für alle Fahrer | Placement tracking for all racers
- Boost-Pads mit Geschwindigkeitserhöhung | Boost pads with speed increase
- Leaderboard mit Bestzeiten | Leaderboard with best times

## Tech Stack

- UEFN, Verse, Creative Devices, FortniteChars

## Extension Ideas

- Fahrzeug-Ausrüstung und Anpassung | Vehicle equipment and customization
- Item-Boxen (Rocket, Banane) | Item boxes (rocket, banana)
- Eliminierungs-Modus | Elimination mode
