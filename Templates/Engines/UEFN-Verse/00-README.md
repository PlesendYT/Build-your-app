A comprehensive collection of UEFN (Unreal Editor for Fortnite) Verse templates for various game modes. Each template includes real Verse code with UEFN conventions (creative_device, Concurrency, Transient, game flow logic).

## Verwendung | Usage

Jedes Template-Verzeichnis enthält:
- **README.md** – Dokumentation auf Deutsch und Englisch
- **Verse-Dateien** (.verse) – einsatzbereiter UEFN-Code

Each template directory contains:
- **README.md** – Documentation in German and English
- **Verse files** (.verse) – ready-to-use UEFN code

### Schnellstart | Quick Start

1. Erstelle ein neues UEFN-Projekt in verse
2. Kopiere die `.verse`-Dateien in dein Projektverzeichnis
3. Weise die Geräte im UEFN-Editor zu
4. Starte den Verse Compiler

1. Create a new UEFN project in Verse
2. Copy the `.verse` files into your project directory
3. Assign the devices in the UEFN Editor
4. Start the Verse Compiler
