# HideAndSeek – UEFN Verse Template

**Deutsch:** Ein Verstecken-Spielmodus mit Suchern, Versteckern, Versteck-Orten und Runden-System.

**English:** A hide-and-seek game mode with seekers, hiders, hiding spots, and a round system.

## Features

- Sucher-Team mit Zeitlimit zum Finden | Seeker team with time limit to find
- Verstecker-Team mit Versteck-Orten | Hider team with hiding spots
- Große Karte mit vielen Versteckmöglichkeiten | Large map with many hiding options
- Sound- und Bewegungs-Detektion | Sound and movement detection
- Runden-Wechsel mit Rollen-Tausch | Round switching with role swap

## Tech Stack

- UEFN, Verse, Creative Devices, TeamDevice

## Extension Ideas

- Tarnungs-Items (Tarnanzug, Rauchbombe) | Camouflage items (cloak, smoke bomb)
- Fallen für Sucher | Traps for seekers
- Mehrere Runden mit Punkte-System | Multiple rounds with scoring system
