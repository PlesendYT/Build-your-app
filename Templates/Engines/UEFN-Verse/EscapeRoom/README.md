# EscapeRoom – UEFN Verse Template

**Deutsch:** Ein Escape-Room-Modus mit Rätseln, Schlüsseln, versteckten Hinweisen und Exit-Tür.

**English:** An escape room mode with puzzles, keys, hidden clues, and exit door.

## Features

- Versteckte Hinweise und Notizen | Hidden clues and notes
- Schlüssel-Objekt zum Öffnen von Türen | Key object for opening doors
- Kombinations-Rätsel mit Zahlencodes | Combination puzzles with number codes
- Timer mit Countdown-Anzeige | Timer with countdown display
- Exit-Tür, die alle Rätsel erfordert | Exit door requiring all puzzles

## Tech Stack

- UEFN, Verse, Creative Devices, UI

## Extension Ideas

- Mehrere Escape-Räume nacheinander | Multiple escape rooms in sequence
- Koop-Rätsel mit Teamwork | Co-op puzzles with teamwork
- Schwierigkeitsgrade durch variablen Timer | Difficulty levels via variable timer
