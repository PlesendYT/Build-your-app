# Survival – UEFN Verse Template

**Deutsch:** Ein Überlebensmodus mit Ressourcen-Sammeln, Crafting, Bauen und Nacht-Zyklus.

**English:** A survival mode with resource gathering, crafting, building, and night cycle.

## Features

- Ressourcen-Sammeln (Holz, Stein, Metall) | Resource gathering (wood, stone, metal)
- Crafting-System mit Rezepten | Crafting system with recipes
- Basis-Bau mit Plätzen | Base building with placement
- Tag/Nacht-Zyklus mit Monster-Spawns | Day/night cycle with monster spawns
- Hunger/Durst-System | Hunger/thirst system

## Tech Stack

- UEFN, Verse, Creative Devices, AIDirector

## Extension Ideas

- Teams mit kooperativem Bauen | Teams with cooperative building
- Wetter-System mit Stürmen | Weather system with storms
- Erkundungs-Belohnungen | Exploration rewards
