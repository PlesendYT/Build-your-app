# PropHunt – UEFN Verse Template

**Deutsch:** Ein Verstecken-als-Objekt-Spielmodus mit Formwandlung, Jägern und Runden-Zeitlimit.

**English:** A hide-as-object game mode with shape-shifting, hunters, and round time limit.

## Features

- Objekt-Verwandlung (Tische, Pflanzen, Fässer) | Object transformation (tables, plants, barrels)
- Jäger-Team mit Waffen | Hunter team with weapons
- Verstecker-Team mit Tarnungs-Bonus | Hider team with camouflage bonus
- Runden-basiert mit Rollenwechsel | Round-based with role switching
- Täuschungs-Mechanik (Hupen, Bewegung) | Deception mechanics (honking, movement)

## Tech Stack

- UEFN, Verse, Creative Devices, TeamDevice

## Extension Ideas

- Mehr Objekt-Typen mit Animationen | More object types with animations
- Power-Ups für Verstecker | Power-ups for hiders
- Spektator-Modus für besiegte Spieler | Spectator mode for eliminated players
