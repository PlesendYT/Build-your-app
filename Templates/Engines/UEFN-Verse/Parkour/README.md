# Parkour – UEFN Verse Template

**Deutsch:** Ein Parkour-Parcours-Modus mit Checkpoints, Sprungmechaniken, Bestzeit und Hindernissen.

**English:** A parkour course mode with checkpoints, jump mechanics, best time, and obstacles.

## Features

- Checkpoint-System mit Fortschrittsanzeige | Checkpoint system with progress display
- Stoppuhr mit Bestzeit-Speicherung | Stopwatch with best time saving
- Sprung- und Kletter-Mechaniken | Jump and climb mechanics
- Hindernisse (Lava, Fallen, Wände) | Obstacles (lava, traps, walls)
- Zielbereich mit Sieg-Bildschirm | Finish zone with victory screen

## Tech Stack

- UEFN, Verse, Creative Devices, UI

## Extension Ideas

- Mehrere Parcours mit Schwierigkeitsgraden | Multiple courses with difficulty levels
- Multiplayer-Rennen gleichzeitig | Multiplayer races simultaneously
- Trick-System mit Punkten | Trick system with points
