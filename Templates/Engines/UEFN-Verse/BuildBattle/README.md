# BuildBattle – UEFN Verse Template

**Deutsch:** Ein Bau-Wettbewerbs-Modus mit Themen, Bewertung, Timer und kreativen Baublöcken.

**English:** A building competition mode with themes, voting, timer, and creative building blocks.

## Features

- Zufällige Bau-Themen (Haus, Burg, Tier) | Random building themes (house, castle, animal)
- Bau-Timer mit Countdown | Building timer with countdown
- Bewertungs-System (1-5 Sterne) | Voting system (1-5 stars)
- Kreativ-Inventar mit allen Blöcken | Creative inventory with all blocks
- Beste-Bau-Auszeichnung | Best-build award

## Tech Stack

- UEFN, Verse, Creative Devices, UI

## Extension Ideas

- Team-Bau-Modus | Team build mode
- Bau-Herausforderungen mit Limitierungen | Build challenges with limitations
- Galerie der vergangenen Gewinner | Gallery of past winners
