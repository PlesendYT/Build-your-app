# CaptureTheFlag – UEFN Verse Template

**Deutsch:** Ein Capture-the-Flag-Spielmodus mit Flaggenraub, Basen, Punktesystem und Team-Strategie.

**English:** A capture-the-flag game mode with flag stealing, bases, scoring system, and team strategy.

## Features

- Flaggen-Objekte an beiden Basen | Flag objects at both bases
- Flaggen-Tragen und -Zurückbringen | Flag carrying and returning
- Punkte für erfolgreiche Flaggen-Erfassung | Points for successful flag capture
- Flaggen-Respawn nach Drop oder Capture | Flag respawn after drop or capture
- Team-Farben für visuelle Unterscheidung | Team colors for visual distinction

## Tech Stack

- UEFN, Verse, Creative Devices, TeamDevice

## Extension Ideas

- Mehrere Flaggen auf einer Karte | Multiple flags on one map
- Power-Ups für Flaggenträger | Power-ups for flag carriers
- CTF-Turnier-Modus | CTF tournament mode
