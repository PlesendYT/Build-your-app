# TeamDeathmatch – UEFN Verse Template

**Deutsch:** Ein Team-Deathmatch-Spielmodus mit blauen/roten Teams, Punkteanzeige und Respawn-Wellen.

**English:** A team deathmatch game mode with blue/red teams, score display, and respawn waves.

## Features

- Team-Zuteilung (Blau/Rot) mit Balancierung | Team assignment (blue/red) with balancing
- Team-Punkte und individuelles Scoreboard | Team scores and individual scoreboard
- Wave-Respawn alle 10 Sekunden | Wave respawn every 10 seconds
- Kill-Assist-Erkennung | Kill assist detection
- Sieg-Bedingung: erstes Team auf Score-Limit | Win condition: first to score limit

## Tech Stack

- UEFN, Verse, Creative Devices

## Extension Ideas

- Klassen-System (Medic, Heavy, Scout) | Class system (medic, heavy, scout)
- Capture-the-Flag integriert | Capture-the-flag integrated
- Power-Up-Spawner | Power-up spawners
