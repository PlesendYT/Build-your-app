# Tycoon – UEFN Verse Template

**Deutsch:** Ein Tycoon-Spielmodus mit Ressourcen-Generatoren, Verkaufsautomaten, Upgrades und Geld-Management.

**English:** A tycoon game mode with resource generators, vending machines, upgrades, and money management.

## Features

- Automatische Ressourcen-Generatoren | Automatic resource generators
- Verkaufsautomaten für passives Einkommen | Vending machines for passive income
- Upgrade-System für Generatoren | Upgrade system for generators
- Geld-Anzeige und Transaktions-Log | Money display and transaction log
- Wettbewerb mit anderen Spielern um beste Wirtschaft | Competition with other players for best economy

## Tech Stack

- UEFN, Verse, Creative Devices, UI

## Extension Ideas

- Mitarbeiter-Einstellung und Management | Employee hiring and management
- Aktienmarkt-Simulation | Stock market simulation
- Multiplayer-Wirtschaft mit Handel | Multiplayer economy with trading
