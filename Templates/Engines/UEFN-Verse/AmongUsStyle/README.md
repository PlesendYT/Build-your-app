# AmongUsStyle – Social Deduction Template (UEFN Verse)

**Deutsch:** Ein Social-Deduction-Spielmodus ähnlich "Among Us" mit Crewmates, Impostor, Aufgaben und Notfall-Meetings.

**English:** A social deduction game mode similar to "Among Us" with crewmates, impostor, tasks, and emergency meetings.

## Features

- Crewmates (Aufgaben erledigen) und Impostor (sabotieren) | Crewmates (do tasks) and Impostor (sabotage)
- Aufgaben-System (Flicken, Reinigen, Verbinden) | Task system (fix, clean, connect)
- Notfall-Meetings mit Abstimmung | Emergency meetings with voting
- Sabotage-Aktionen (Lichter, Türen, Sauerstoff) | Sabotage actions (lights, doors, oxygen)
- Besprechungsraum mit Timer | Meeting room with timer

## Tech Stack

- UEFN, Verse, Creative Devices, UI/Gadgets

## Extension Ideas

- Mehrere Impostoren | Multiple impostors
- Aufgaben-Visualisierung auf Karte | Task visualization on map
- Tarnungs-Mechanik für Impostor | Camouflage mechanic for impostor
