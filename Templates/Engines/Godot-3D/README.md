# Godot 4 3D Template

> Minimal-3D-Projekt mit Godot 4. / Minimal 3D project with Godot 4.

## Features
- Player-Szene mit CharacterBody3D / Player scene with CharacterBody3D
- Spinbarer Cube / Spinnable cube
- Input map (ui_left/ui_right) / Input map

## How to Use
1. Öffne Godot 4 und klicke "Import" / Open Godot 4 and click "Import"
2. Wähle `project.godot` / Select `project.godot`

## Tech Stack
- Godot 4.x
- GDScript

## Extension Ideas
- Rigidbody-Physik / Rigidbody physics
- AnimationTree / AnimationTree
- Export-Presets für HTML5/Windows/Linux / Export presets for HTML5/Windows/Linux
