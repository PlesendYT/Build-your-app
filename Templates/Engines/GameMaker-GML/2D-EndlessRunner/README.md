# 2D-EndlessRunner (GameMaker GML)

## Beschreibung / Description

**DE:** Ein Endlosläufer mit automatisch scrollendem Level, Hindernissen und Punktesystem.

**EN:** An endless runner with auto-scrolling level, obstacles, and scoring system.

## Features

- Automatische Bewegung / Automatic movement
- Springen und Rutschen / Jump and slide
- Zufällige Hindernisse / Random obstacles
- Parallax-Scrolling-Hintergrund / Parallax scrolling background
- Highscore (lokale Speicherung) / Highscore (local save)

## How to Use

1. obj_player, obj_obstacle, obj_ground, obj_bg_scroller
2. Sprites, Tastatur-Steuerung (Leertaste springen)

## Tech Stack

- GameMaker LTS 2024 / GML
- alarm für Spawn-Timer
- draw_sprite_ext für Parallax
- ini_open für Highscore

## Extension Ideas

- Power-Ups (Schild, Magnet) / Power-ups (shield, magnet)
- Charakter-Skins
- Verschiedene Biome
- Tägliche Herausforderungen / Daily challenges
