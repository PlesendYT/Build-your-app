# 2D-TowerDefense (GameMaker GML)

## Beschreibung / Description

**DE:** Ein Turmverteidigungsspiel mit Wellen von Gegnern, verschiedenen Turmtypen und einem Wirtschaftssystem.

**EN:** A tower defense game with waves of enemies, different tower types, and an economy system.

## Features

- Weg-Punkt-System für Gegner / Waypoint system for enemies
- Mehrere Turmtypen (Geschütz, Frost, Feuer) / Multiple tower types (cannon, frost, fire)
- Gegner mit verschiedenen Eigenschaften / Enemies with different properties
- Geld- und Gesundheits-System / Gold and health system
- Wellen-Manager / Wave manager
- Turm-Upgrades / Tower upgrades

## How to Use

1. Objekte: obj_tower, obj_enemy, obj_projectile, obj_waypoint
2. Wegpunkte im Raum platzieren
3. Controller für Wellen

## Tech Stack

- GameMaker LTS 2024 / GML
- mp_potential_step für Gegner-Pfadfindung
- ds_priority oder Arrays für Zielauswahl

## Extension Ideas

- Element-Türme (Blitz, Gift) / Elemental towers (lightning, poison)
- Spezialfähigkeiten / Special abilities
- Labyrinth-Bau / Maze building
- Mehrere Karten / Multiple maps
