# 2D-Puzzle (GameMaker GML)

## Beschreibung / Description

**DE:** Ein 2D-Rätselspiel mit verschiebbaren Blöcken, Druckplatten und Zielmechaniken.

**EN:** A 2D puzzle game with pushable blocks, pressure plates, and goal mechanics.

## Features

- Schiebeblöcke / Pushable blocks
- Druckplatten-Schalter / Pressure plate switches
- Türen, die auf Schalter reagieren / Doors reacting to switches
- Levels mit Zielposition / Levels with goal position
- Rückgängig-Funktion / Undo functionality

## How to Use

1. Objekte: obj_player, obj_block, obj_plate, obj_door, obj_goal
2. Kollisionsmasken für Schiebe-Mechanik
3. Level-Array für Leveldaten

## Tech Stack

- GameMaker LTS 2024 / GML
- 2D-Arrays für Leveldaten
- instance_position() / place_meeting()

## Extension Ideas

- Timer
- Bewegliche Plattformen / Moving platforms
- Spiegel-Rätsel / Mirror puzzles
- Teleporter
