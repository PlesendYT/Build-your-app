# 2D-ShootEmUp (GameMaker GML)

## Beschreibung / Description

**DE:** Ein klassisches 2D-Shoot-'em-up mit Sternenhintergrund, Gegnerwellen und Power-Ups.

**EN:** A classic 2D shoot-'em-up with scrolling starfield, enemy waves, and power-ups.

## Features

- Spieler bewegt sich mit Maus/Tastatur / Mouse/keyboard player movement
- Automatisches oder manuelles Schießen / Auto or manual shooting
- Mehrere Gegnertypen / Multiple enemy types
- Power-Ups (Speed, Spread, Shield) / Power-ups (speed, spread, shield)
- Wellen-System / Wave system
- Highscore

## How to Use

1. Objekte: obj_player, obj_bullet, obj_enemy, obj_enemy_bullet, obj_powerup
2. Sprites zuweisen
3. Code einfügen

## Tech Stack

- GameMaker LTS 2024 / GML
- instance_create_layer() für Projektile
- alarm[] für Timer
- draw_sprite_ext() für Effekte

## Extension Ideas

- Boss-Gegner / Boss enemies
- Verschiedene Waffentypen / Different weapon types
- Mehrspieler / Multiplayer
- Shop zwischen Wellen / Shop between waves
