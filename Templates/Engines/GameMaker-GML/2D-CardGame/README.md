# 2D-CardGame (GameMaker GML)

## Beschreibung / Description

**DE:** Ein strategisches Kartenspiel mit Sammelkarten, Deck-Verwaltung und Rundenkampf.

**EN:** A strategic card game with collectible cards, deck management, and turn-based combat.

## Features

- Kartendeck mit Mischen und Ziehen / Deck with shuffle and draw
- Hand-Management / Hand management
- Rundenbasiertes Kampfsystem / Turn-based combat system
- Verschiedene Kartentypen (Angriff, Verteidigung, Zauber) / Card types (attack, defense, spell)
- Energie-/Manasystem / Energy/mana system
- Spieler- und Gegner-Leben / Player and enemy HP

## How to Use

1. obj_card, obj_deck_manager, obj_card_game, obj_card_slot
2. Karten als JSON/DS-Map definieren
3. UI-Elemente für Hand und Tisch

## Tech Stack

- GameMaker LTS 2024 / GML
- Structs für Kartendaten
- ds_list / Arrays für Deck und Hand
- draw_sprite_ext für Karten-Grafik

## Extension Ideas

- Verschiedene Heldenklassen / Different hero classes
- Karten-Kombinationen / Card combos
- Shop und Booster-Packs
- Online-Multiplayer
