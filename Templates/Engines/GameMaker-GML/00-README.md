# GameMaker GML Templates

GameMaker-Vorlagen für 2D-Spiele mit der GameMaker Language (GML). Kompatibel mit GameMaker LTS 2024 und neuer.

GameMaker templates for 2D games using the GameMaker Language (GML). Compatible with GameMaker LTS 2024 and newer.

## Vorlagen / Templates

| Genre | Beschreibung / Description |
|-------|--------------------------|
| 2D-Platformer | Klassisches Jump'n'Run / Classic platformer |
| 2D-TopDown | Top-Down-Abenteuer / Top-down adventure |
| 2D-Puzzle | Rätselspiel / Puzzle game |
| 2D-ShootEmUp | Schießspiel / Shooting game |
| 2D-Roguelike | Roguelike mit prozeduralen Levels / Roguelike with procedural levels |
| 2D-TowerDefense | Turmverteidigung / Tower defense |
| 2D-EndlessRunner | Endlosläufer / Endless runner |
| 2D-CardGame | Kartenspiel / Card game |
| 2D-BeatEmUp | Prügelspiel / Beat 'em up |
| 2D-RhythmGame | Rhythmusspiel / Rhythm game |
| 2D-Fighting | Kampfspiel / Fighting game |

## Verwendung / Usage

Jede Vorlage enthält eine README.md mit Anleitung und 2–4 GML-Quellcodedateien.
Jede Vorlage kann als Ausgangspunkt für ein neues GameMaker-Projekt verwendet werden.

Each template includes a README.md with instructions and 2–4 GML source code files.
Each template can be used as a starting point for a new GameMaker project.

## Konventionen / Conventions

- GML-Code verwendet `function`-Definitionen (GML LTS 2024+)
- `instance_create_layer()` für Objekterstellung
- Objektvariablen mit `var` und Instanzvariablen
- Strukturierte Datentypen mit `struct{}`
- Built-in-Variablen wie `x`, `y`, `speed`, `direction`, `hp`, `mp`
