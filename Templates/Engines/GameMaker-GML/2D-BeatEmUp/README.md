# 2D-BeatEmUp (GameMaker GML)

## Beschreibung / Description

**DE:** Ein klassisches 2D-Prügelspiel mit Kombos, mehreren Gegnern und Gesundheitsbalken.

**EN:** A classic 2D beat 'em up with combos, multiple enemies, and health bars.

## Features

- Bewegung und Sprung / Movement and jump
- Angriffs-Kombos (3-Schlag-Combo) / Attack combos (3-hit combo)
- Spezialangriff / Special attack
- Mehrere Gegnertypen / Multiple enemy types
- Gesundheits- und Combo-Anzeige / Health and combo display
- Gegner-Wellen / Enemy waves

## How to Use

1. obj_player, obj_enemy_grunt, obj_enemy_brute, obj_hitbox
2. Sprites für jede Animation
3. Alarm-basierte Combo-Timer

## Tech Stack

- GameMaker LTS 2024 / GML
- image_speed / image_index für Animation
- mask_index für Trefferboxen
- alarm[] für Combo-Fenster

## Extension Ideas

- Spielbare Charaktere / Playable characters
- Waffen-Upgrades / Weapon upgrades
- Bosskämpfe / Boss fights
- Koop-Modus / Co-op mode
