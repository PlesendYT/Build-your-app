# 2D-Fighting (GameMaker GML)

## Beschreibung / Description

**DE:** Ein 2D-Kampfspiel mit zwei Kämpfern, Spezialbewegungen und Gesundheitsbalken.

**EN:** A 2D fighting game with two fighters, special moves, and health bars.

## Features

- Zwei Spieler (lokal) / Two players (local)
- Bewegung, Sprung und Angriffe / Movement, jump and attacks
- Spezialbewegungen (Tastenkombos) / Special moves (button combos)
- Gesundheits- und Energiebalken / Health and energy bars
- Runden-System / Round system
- Treffer-Bestätigung / Hit confirmation

## How to Use

1. obj_fighter (für P1 und P2)
2. obj_fight_manager für Rundenlogik
3. Sprites: stehen, gehen, springen, schlagen, treten

## Tech Stack

- GameMaker LTS 2024 / GML
- draw_sprite_ext für Charaktere
- alarm[] für Animations-Timing
- keyboard_check für Steuerung

## Extension Ideas

- Charakterauswahl / Character select
- Supers und Ultimates
- Combos-System (Bewegungsliste)
- KI-Gegner / AI opponent
- Online-Multiplayer
