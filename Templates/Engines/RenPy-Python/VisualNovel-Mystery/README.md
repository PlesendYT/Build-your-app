# VisualNovel-Mystery (RenPy)

## Beschreibung / Description

**DE:** Ein mysteriöser visueller Roman, in dem der Spieler Hinweise sammelt und Rätsel löst.

**EN:** A mystery visual novel where the player gathers clues and solves puzzles.

## Features

- Detektiv-Notizbuch / Detective notebook
- Hinweis-System / Clue system
- Verdächtige mit Motiven / Suspects with motives
- Deduktions-Mechanik / Deduction mechanics
- Mehrere Auflösungen / Multiple resolutions

## How to Use

1. `script.rpy`, `screens.rpy`, `characters.rpy` ins Spielverzeichnis kopieren
2. Hintergrund- und Charakterbilder bereitstellen

## Tech Stack

- RenPy 8+
- Python-Listen für Hinweise
- Bedingte Verzweigungen

## Extension Ideas

- Karte des Tatorts / Crime scene map
- Verhör-System / Interrogation system
- Zeitlimit / Time limit
- Zufällige Elemente / Random elements
