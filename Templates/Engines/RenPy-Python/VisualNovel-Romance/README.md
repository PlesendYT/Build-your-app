# VisualNovel-Romance (RenPy)

## Beschreibung / Description

**DE:** Eine romantische Liebesgeschichte mit Tiefgang, Entscheidungen und mehreren Romanzen.

**EN:** A deep romantic love story with choices and multiple romance paths.

## Features

- Detaillierte Charaktere mit Hintergrundgeschichten / Detailed characters with backstories
- Romantische Entscheidungen / Romantic choices
- Beziehungs-Meilensteine / Relationship milestones
- Emotionale Handlung / Emotional storyline
- Unterschiedliche Enden / Different endings

## How to Use

1. Dateien ins Spielverzeichnis kopieren
2. Charakterbilder und CG-Szenen bereitstellen

## Tech Stack

- RenPy 8+
- Zungeneffekt-Variablen für Beziehungen

## Extension Ideas

- Geschenk-System / Gift system
- Datum-Ideen / Date ideas
- WhatsApp-Style Nachrichten / Text messages
- Jahreszeiten / Seasons
