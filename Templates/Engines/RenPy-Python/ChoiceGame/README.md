# ChoiceGame (RenPy)

## Beschreibung / Description

**DE:** Ein entscheidungsbasiertes Spiel, in dem jede Wahl Konsequenzen hat. Ein interaktives Erlebnis mit mehreren Pfaden.

**EN:** A choice-based game where every decision has consequences. An interactive experience with multiple paths.

## Features

- Bedeutungsvolle Entscheidungen / Meaningful choices
- Konsequenz-System / Consequence system
- Mehrere Pfade / Multiple paths
- Wiederspielbarkeit / Replayability
- Stat-Tracking / Stat tracking

## How to Use

1. Dateien ins Spielverzeichnis kopieren
2. Nach Bedarf erweitern

## Tech Stack

- RenPy 8+
- Flags und Variablen für Entscheidungen
- Bedingte Verzweigungen

## Extension Ideas

- Achievements
- Punkte-System / Points system
- Charakter-Editor
- Zufallsereignisse / Random events
