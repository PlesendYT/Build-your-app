# KineticNovel (RenPy)

## Beschreibung / Description

**DE:** Ein kinetischer Roman ohne Entscheidungen – eine lineare Geschichte zum Durchlesen.

**EN:** A kinetic novel with no choices – a linear story to read through.

## Features

- Keine Entscheidungen / No choices
- Fokussierte Erzählung / Focused narrative
- Automatischer Vorspann / Auto-forward option
- Kapitelweise Struktur / Chapter-based structure
- Emotionale Handlung / Emotional storyline

## How to Use

1. Dateien ins Spielverzeichnis kopieren
2. Bilder für jede Szene bereitstellen
3. Mit `renpy.block_rollback()` für optimales Leseerlebnis

## Tech Stack

- RenPy 8+
- `nvl`-Modus für langen Text
- `config.auto_forward_time` für Auto-Weiter

## Extension Ideas

- Voice-Over / Voice acting
- Animierte Zwischensequenzen / Animated cutscenes
- Musik-Empfehlungen / Music recommendations
- Kapitelauswahl / Chapter select
