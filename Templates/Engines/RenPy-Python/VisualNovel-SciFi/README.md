# VisualNovel-SciFi (RenPy)

## Beschreibung / Description

**DE:** Ein Sci-Fi-Visual-Novel über die Erkundung des Weltraums und die Begegnung mit außerirdischen Zivilisationen.

**EN:** A sci-fi visual novel about space exploration and encounters with alien civilizations.

## Features

- Raumschiff-Verwaltung / Spaceship management
- Alien-Diplomatie / Alien diplomacy
- Crew-Beziehungen / Crew relationships
- Technologiebaum / Tech tree
- Moralische Entscheidungen / Moral choices

## How to Use

1. Dateien ins Spielverzeichnis kopieren
2. Sci-Fi-Hintergründe bereitstellen

## Tech Stack

- RenPy 8+
- Python für Schiffstatus
- Bedingte Kapitel

## Extension Ideas

- Ressourcen-Management / Resource management
- Kampfsimulation / Combat simulation
- Mehrere Crewmitglieder / Multiple crew members
- Unbekannte Planeten / Unknown planets
