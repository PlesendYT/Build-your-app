# VisualNovel-Fantasy (RenPy)

## Beschreibung / Description

**DE:** Ein Fantasy-Visual-Novel mit Magie, Drachen und epischen Entscheidungen.

**EN:** A fantasy visual novel with magic, dragons, and epic choices.

## Features

- Magiesystem / Magic system
- Begleiter mit Fähigkeiten / Companions with abilities
- Kämpfe (wahlbasiert) / Combat (choice-based)
- Verzweigte Handlung / Branching story
- Charakterentwicklung / Character progression

## How to Use

1. Dateien ins Spielverzeichnis kopieren
2. Bilder in `game/images/` ablegen

## Tech Stack

- RenPy 8+
- Python-Dictionaries für Charakterstatus
- `menu` für Entscheidungen

## Extension Ideas

- Inventar / Inventory
- Zauber-lernen / Learn spells
- Fraktionssystem / Faction system
- Romance-Optionen
