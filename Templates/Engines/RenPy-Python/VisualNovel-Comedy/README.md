# VisualNovel-Comedy (RenPy)

## Beschreibung / Description

**DE:** Eine lustige Comedy-Visual-Novel voller absurder Situationen und witziger Dialoge.

**EN:** A funny comedy visual novel full of absurd situations and witty dialogue.

## Features

- Humorvolle Dialoge / Humorous dialogue
- Absurde Entscheidungen / Absurd choices
- Komödiantisches Timing / Comedic timing
- Übertriebene Charaktere / Exaggerated characters
- Running Gags

## How to Use

1. Dateien ins Spielverzeichnis kopieren
2. Bunte, lustige Hintergründe verwenden

## Tech Stack

- RenPy 8+
- `jump` für Gags und Slapstick

## Extension Ideas

- Lach-Party-Mechanik / Laugh track mechanic
- Verrückte Minispiele / Crazy minigames
- Charakter-Witze-Battle / Character roast battle
