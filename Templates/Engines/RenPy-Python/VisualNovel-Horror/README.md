# VisualNovel-Horror (RenPy)

## Beschreibung / Description

**DE:** Ein Horror-Visual-Novel mit psychologischem Terror, Jump-Scares und Überlebensmechaniken.

**EN:** A horror visual novel with psychological terror, jump scares, and survival mechanics.

## Features

- Sanity/Verstand-System / Sanity system
- Entscheidungen unter Druck / Choices under pressure
- Versteck-Mechanik / Hiding mechanics
- Überlebensressourcen / Survival resources
- Mehrere Enden / Multiple endings

## How to Use

1. Dateien ins Spielverzeichnis kopieren
2. Dunkle, atmosphärische Hintergründe verwenden

## Tech Stack

- RenPy 8+
- Python für Sanity-Wert
- `renpy.pause` für Timing

## Extension Ideas

- Inventar (Taschenlampe, Batterien) / Inventory (flashlight, batteries)
- Monster-Begegnungen / Monster encounters
- Tagebuch-Seiten / Diary pages
- Sound-Design für Atmosphäre
