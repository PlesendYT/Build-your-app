# VisualNovel-Dating (RenPy)

## Beschreibung / Description

**DE:** Eine Datingsimulation, in der der Spieler Romanzen mit verschiedenen Charakteren aufbauen kann.

**EN:** A dating simulation where the player can build relationships with various characters.

## Features

- Mehrere romanztierbare Charaktere / Multiple romanceable characters
- Beziehungsstatistiken / Relationship stats
- Entscheidungen beeinflussen den Beziehungsverlauf / Choices affect relationship paths
- Tagesstruktur mit Ortswahl / Day structure with location choice
- Mehrere Enden / Multiple endings

## How to Use

1. Neues RenPy-Projekt erstellen
2. `script.rpy`, `screens.rpy`, `characters.rpy` ins Spielverzeichnis kopieren
3. Bilder für Hintergründe und Charaktere bereitstellen
4. Spiel starten

## Tech Stack

- RenPy 8+ / Python 3
- `define` für Charaktere
- `screen` für UI
- `$` für Python-Ausdrücke

## Extension Ideas

- Telefon / Phone system
- Kalender / Calendar
- Geschenke / Gift-giving
- Nebencharaktere / Side characters
