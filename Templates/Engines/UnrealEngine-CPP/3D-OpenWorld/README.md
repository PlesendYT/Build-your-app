# 3D-OpenWorld – Open-World Template (UE5)

**Deutsch:** Ein Open-World-Grundgerüst mit Questsystem, Minimap, dynamischen Wetter, Tageszeiten und Save/Load-Funktion.

**English:** An open-world skeleton with quest system, minimap, dynamic weather, day/night cycle, and save/load functionality.

## Features

- Welt-Koordinaten-basiertes Questsystem mit Markern | World coordinate quest system with markers
- Minimap mit Entdeckungssystem | Minimap with discovery system
- Dynamisches Wetter (Regen, Nebel, Sonne) | Dynamic weather (rain, fog, sun)
- Tag/Nacht-Zyklus mit einstellbarer Geschwindigkeit | Day/night cycle with adjustable speed
- SaveGame-System mit Aktor-Zuständen | SaveGame system with actor states

## Tech Stack

- UE5.4+, C++17, EnhancedInput, UMG, SaveGame

## Extension Ideas

- Fliegendes Reittier oder Fahrzeug | Flying mount or vehicle
- Fraktionen mit Ruf-System | Factions with reputation system
- Nachkommen-generierte Welt | Procedurally generated world
