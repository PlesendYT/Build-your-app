# 3D-Stealth – Schleichspiel Template (UE5)

**Deutsch:** Ein Schleichspiel-Grundgerüst mit KI-Wachen, Sichtkegeln, Tarnung, Geräuschsystem und Alarmstatus.

**English:** A stealth game skeleton with AI guards, vision cones, camouflage, noise system, and alert status.

## Features

- KI-Wachen mit Sicht- und Hörsinn | AI guards with sight and hearing senses
- Sichtkegel (Cone-of-Vision) für Wachen | Vision cones for guards
- Tarnungs-Meter basierend auf Licht und Deckung | Stealth meter based on light and cover
- Geräuschsystem (Schritte, Ablenkungen) | Noise system (footsteps, distractions)
- Alarm- und Suchstatus-Leiste | Alarm and search status bar

## Tech Stack

- UE5.4+, C++17, AIPerception, BehaviorTree, EQS

## Extension Ideas

- Multiple Schwierigkeitsstufen | Multiple difficulty levels
- Hacking-Minispiel für Sicherheitssysteme | Hacking minigame for security systems
- Versteck-Mechaniken (Schränke, Lüftungen) | Hiding mechanics (lockers, vents)
