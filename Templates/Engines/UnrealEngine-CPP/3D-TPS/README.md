# 3D-TPS – Third-Person-Shooter Template (UE5)

**Deutsch:** Ein Third-Person-Shooter-Grundgerüst mit Deckungssystem, Zielhilfe und Waffenverwaltung. Ideal für actionreiche Spiele mit über der Schulter Kameraperspektive.

**English:** A third-person shooter skeleton with cover system, aim assist, and weapon management. Ideal for action games with over-the-shoulder camera perspective.

## Features

- Third-Person-Kamera mit Spring Arm und Zielzoom | Third-person camera with spring arm and aim zoom
- Deckungssystem mit automatischem Anlehnen | Cover system with automatic leaning
- Waffensystem mit Wechsel und Zielhilfe | Weapon system with switching and aim assist
- Gesundheits- und Rüstungsverwaltung | Health and armor management
- EnhancedInput für flüssige Steuerung | EnhancedInput for smooth controls

## How to Use

1. Add files to project `Source/` folder.
2. Set `ATPSGameMode` as default game mode.
3. Assign Enhanced Input actions in Blueprint.
4. Configure spring arm and camera in Blueprint child.

## Tech Stack

- UE5.4+, C++17, EnhancedInput, UMG

## Extension Ideas

- Verschiedene Waffentypen und Aufsätze | Different weapon types and attachments
- Mehrspieler-Netzwerkcode | Multiplayer networking
- KI-Gegner mit Deckungslogik | AI enemies with cover logic
