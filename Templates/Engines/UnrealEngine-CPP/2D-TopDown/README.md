# 2D-TopDown – Top-Down-Abenteuer Template (UE5)

**Deutsch:** Ein 2D-Top-Down-Spiel-Grundgerüst mit Projektilwaffen, Gegner-KI, Dungeon-Räumen und Schatzsystem.

**English:** A 2D top-down game skeleton with projectile weapons, enemy AI, dungeon rooms, and treasure system.

## Features

- Top-Down-Kamera mit Charakter-Steuerung | Top-down camera with character control
- Projektil-Waffen (Pfeile, Feuerbälle) | Projectile weapons (arrows, fireballs)
- Gegner-KI mit Patrol- und Chase-Verhalten | Enemy AI with patrol and chase behavior
- Dungeon-Räume mit Tür-Übergängen | Dungeon rooms with door transitions
- Schatz- und Beute-System | Treasure and loot system

## Tech Stack

- UE5.4+, C++17, Paper2D, AIPerception, EnhancedInput

## Extension Ideas

- Inventar mit Ausrüstungsgegenständen | Inventory with equipment items
- Händler-NPCs mit Handelssystem | Merchant NPCs with trading system
- Zufallsgenerierte Dungeons | Procedurally generated dungeons
