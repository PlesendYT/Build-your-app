# 3D-Simulation – Simulationsspiel Template (UE5)

**Deutsch:** Ein Simulationsspiel-Grundgerüst mit interaktiven Objekten, Zustandsautomaten, UI-Bedienelementen und Daten-Logging.

**English:** A simulation game skeleton with interactive objects, state machines, UI controls, and data logging.

## Features

- Interaktive Objekte mit Zustandsautomaten | Interactive objects with state machines
- UI-basierte Bedienelemente mit Slidern und Knöpfen | UI-based controls with sliders and buttons
- Simulations-Geschwindigkeitsregler | Simulation speed control
- Daten-Export und -Logging | Data export and logging
- Visuelle Feedback-Systeme (Farbe, Größe, Position) | Visual feedback systems (color, size, position)

## Tech Stack

- UE5.4+, C++17, UMG, Slate

## Extension Ideas

- Partikel-System-Simulation | Particle system simulation
- Wirtschafts-Simulation mit Angebot/Nachfrage | Economic simulation with supply/demand
- Wetter- und Ökosystem-Simulation | Weather and ecosystem simulation
