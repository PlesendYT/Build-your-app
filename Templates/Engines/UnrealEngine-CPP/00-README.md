A comprehensive collection of Unreal Engine 5 C++ templates for various game genres. Each template includes production-ready C++ code with modern UE5 conventions.

## Verwendung | Usage

Jedes Template-Verzeichnis enthält:
- **README.md** – Dokumentation auf Deutsch und Englisch
- **Source-Dateien** (.h/.cpp) – einsatzbereite UE5-C++-Klassen

Each template directory contains:
- **README.md** – Documentation in German and English
- **Source files** (.h/.cpp) – ready-to-use UE5 C++ classes

### Schnellstart | Quick Start

1. Kopiere die Dateien in das `Source/`-Verzeichnis deines UE5-Projekts
2. Generiere die Visual Studio-Projektdateien (Rechtsklick `.uproject` → "Generate Visual Studio project files")
3. Kompiliere das Projekt
4. Weise die GameMode-Klasse im World Settings zu

1. Copy the files into your UE5 project's `Source/` directory
2. Generate Visual Studio project files (right-click `.uproject` → "Generate Visual Studio project files")
3. Compile the project
4. Assign the GameMode class in World Settings
