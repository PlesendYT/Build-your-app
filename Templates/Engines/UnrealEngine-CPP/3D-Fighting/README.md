# 3D-Fighting – Kampfspiel Template (UE5)

**Deutsch:** Ein Kampfspiel-Grundgerüst mit Combo-System, Lebensbalken, Spezialangriffen, Rundenlogik und Charakterauswahl.

**English:** A fighting game skeleton with combo system, health bars, special attacks, round logic, and character selection.

## Features

- Combo-System mit Tasten-Fenster-Timing | Combo system with timing windows
- Lebens- und Spezialbalken | Health and special meter bars
- Animations-basierte Angriffe mit Treffererkennung | Animation-based attacks with hit detection
- Runden-System mit Timer | Round system with timer
- Charakterauswahl-Bildschirm | Character selection screen

## Tech Stack

- UE5.4+, C++17, EnhancedInput, UMG, AnimationBP

## Extension Ideas

- Online-Multiplayer mit Rollback-Netcode | Online multiplayer with rollback netcode
- Trainingsmodus mit Frame-Daten | Training mode with frame data
- Charakter-Klassensystem | Character class system
