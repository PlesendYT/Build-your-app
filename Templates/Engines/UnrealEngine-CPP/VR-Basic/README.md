# VR-Basic – Virtual Reality Template (UE5)

**Deutsch:** Ein VR-Grundgerüst für Unreal Engine 5 mit Motion-Controller-Unterstützung, Teleportation, Greifmechanik und Interaktionssystem.

**English:** A VR skeleton for Unreal Engine 5 with motion controller support, teleportation, grabbing mechanics, and interaction system.

## Features

- Motion-Controller (Links/Rechts) mit HMD-Tracking | Motion controllers (left/right) with HMD tracking
- Teleportations-Bewegung mit Zielanzeige | Teleportation movement with target indicator
- Greif-Mechanik mit Physics-Handling | Grab mechanic with physics handling
- Interaktionssystem mit UI-Bedienung | Interaction system with UI operation
- Room-Scale-Bewegung mit Kollision | Room-scale movement with collision

## Tech Stack

- UE5.4+, C++17, OpenXR, SteamVR, MotionController

## Extension Ideas

- Waffen und Werkzeuge für VR | Weapons and tools for VR
- Benutzerdefinierte Avatar-Hände | Custom avatar hands
- Mehrspieler-VR-Erfahrung | Multiplayer VR experience
