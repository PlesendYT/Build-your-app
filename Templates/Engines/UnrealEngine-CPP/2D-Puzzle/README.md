# 2D-Puzzle – 2D-Puzzlespiel Template (UE5)

**Deutsch:** Ein 2D-Puzzlespiel-Grundgerüst mit Raster-Logik, Kachel-Manipulation, Verbindungs-System und Level-Fortschritt.

**English:** A 2D puzzle game skeleton with grid logic, tile manipulation, matching system, and level progression.

## Features

- Raster-basiertes Kachel-System | Grid-based tile system
- Klick- und Drag-Interaktion | Click and drag interaction
- Verbindungs- und Paarungs-Erkennung | Matching and pair detection
- Level-Fortschritt mit Sterne-Bewertung | Level progression with star rating
- Animierte Kachel-Übergänge | Animated tile transitions

## Tech Stack

- UE5.4+, C++17, Paper2D, UMG

## Extension Ideas

- Power-Ups und Spezial-Kacheln | Power-ups and special tiles
- Zeit-basierte Herausforderungen | Time-based challenges
- Online-Bestenlisten | Online leaderboards
