# 2D Roguelike C# Template

## Deutsch
Eine vollständige 2D-Roguelike-Vorlage in C# mit Dungeon-Generierung und rundenbasiertem Kampf.

## English
A complete 2D roguelike template in C# with dungeon generation and turn-based combat.

## Features / Funktionen
- Procedural dungeon / Prozeduraler Dungeon
- Turn-based movement / Rundenbasierte Bewegung
- Enemy AI / Gegner-KI
- Leveling system / Stufenaufstieg

## Tech Stack / Technologie
- Godot 4 C# (.NET)
- TileMap
- A* pathfinding

## Extension Ideas / Erweiterungsideen
- Items, shops, bosses
