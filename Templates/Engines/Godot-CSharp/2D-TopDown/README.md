# 2D Top-Down C# Template

## Deutsch
Eine vollständige 2D-Top-Down-Vorlage in C# mit Bewegung, Gegnern und Interaktionen.

## English
A complete 2D top-down template in C# with movement, enemies, and interactions.

## Features / Funktionen
- 4-directional movement / 4-Richtungen Bewegung
- Dash ability / Dash-Fähigkeit
- NPC interaction / NPC-Interaktion
- Patrol enemies / Patrouillen-Gegner

## Tech Stack / Technologie
- Godot 4 C# (.NET)
- CharacterBody2D
- RayCast2D

## Extension Ideas / Erweiterungsideen
- Inventory, dialogue, quests
