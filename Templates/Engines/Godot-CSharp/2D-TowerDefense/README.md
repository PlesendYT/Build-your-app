# 2D Tower Defense C# Template

## Deutsch
Eine vollständige Tower-Defense-Vorlage in C# mit Turmplatzierung und Gegnerwellen.

## English
A complete tower defense template in C# with tower placement and enemy waves.

## Features / Funktionen
- Tower placement / Turmplatzierung
- Multiple tower types
- Wave system / Wellensystem
- Upgrade system / Upgrade-System
- Resource management

## Tech Stack / Technologie
- Godot 4 C# (.NET)
- Path2D
- Area2D
- Timer spawning

## Extension Ideas / Erweiterungsideen
- Boss waves, element towers
