# 3D FPS C# Template

## Deutsch
Eine vollständige Ego-Shooter-Vorlage in C# mit Waffen, Gegnern und Gesundheits-/Munitionssystem.

## English
A complete first-person shooter template in C# with weapons, enemies, health, and ammo.

## Features / Funktionen
- First-person camera / Ego-Perspektive
- Weapon system / Waffensystem
- Enemy AI / Gegner-KI
- Health and armor
- Ammo management / Munitionsverwaltung

## Tech Stack / Technologie
- Godot 4 C# (.NET)
- CharacterBody3D
- RayCast3D
- AnimationPlayer

## Extension Ideas / Erweiterungsideen
- Multiple weapons, multiplayer, grenades
