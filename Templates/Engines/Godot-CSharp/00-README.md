# Godot C# Template Collection

## Deutsch
Diese Sammlung bietet vollständige C#-Projektvorlagen für Godot 4 (.NET). Jede Vorlage enthält einsatzbereiten Code für ein bestimmtes Spielgenre.

## English
This collection provides complete C# project templates for Godot 4 (.NET). Each template contains production-ready code for a specific game genre.

## Templates Overview / Übersicht

| Template | Genre | Type |
|---|---|---|
| 2D-Platformer | Platformer | 2D |
| 2D-TopDown | Top-Down Adventure | 2D |
| 2D-Puzzle | Puzzle Game | 2D |
| 2D-Roguelike | Roguelike | 2D |
| 2D-TowerDefense | Tower Defense | 2D |
| 2D-CardGame | Card Game | 2D |
| 3D-FPS | First-Person Shooter | 3D |
| 3D-RPG | Role-Playing Game | 3D |
| 3D-Platformer | 3D Platformer | 3D |
| 3D-Racing | Racing Game | 3D |

## How to Use / Verwendung

1. Open the template in Godot 4 (.NET)
2. Build the project (Ctrl+B)
3. Run and customize

## Requirements / Voraussetzungen
- Godot Engine 4.x (.NET)
- .NET SDK 6.0+
- C# knowledge
