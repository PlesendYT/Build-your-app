# 3D Platformer C# Template

## Deutsch
Eine vollständige 3D-Plattformer-Vorlage in C# mit Springen und Sammelobjekten.

## English
A complete 3D platformer template in C# with jumping and collectibles.

## Features / Funktionen
- 3D movement with physics
- Jump and double jump
- Collectibles / Sammelobjekte
- Moving platforms / Bewegliche Plattformen
- Checkpoint system

## Tech Stack / Technologie
- Godot 4 C# (.NET)
- CharacterBody3D
- Camera3D
- Area3D triggers

## Extension Ideas / Erweiterungsideen
- Wall running, grappling hook
