# 2D Card Game C# Template

## Deutsch
Eine vollständige Kartenspiel-Vorlage in C# mit Deck-Verwaltung und rundenbasierten Kämpfen.

## English
A complete card game template in C# with deck management and turn-based battles.

## Features / Funktionen
- Card collection / Kartensammlung
- Deck building / Deckbau
- Turn-based combat
- Mana/energy system
- Draw and discard

## Tech Stack / Technologie
- Godot 4 C# (.NET)
- Resource system
- Control nodes
- Signals

## Extension Ideas / Erweiterungsideen
- Online multiplayer
- Card crafting
- Shop system
