# 3D RPG C# Template

## Deutsch
Eine vollständige 3D-RPG-Vorlage in C# mit Third-Person-Steuerung, Kampf und Quests.

## English
A complete 3D RPG template in C# with third-person controls, combat, and quests.

## Features / Funktionen
- Third-person camera
- Movement and combat / Bewegung und Kampf
- Quest system / Questsystem
- Inventory / Inventar
- NPC interaction / NPC-Interaktion

## Tech Stack / Technologie
- Godot 4 C# (.NET)
- CharacterBody3D
- SpringArm3D
- Area3D

## Extension Ideas / Erweiterungsideen
- Crafting, mounts, fast travel
