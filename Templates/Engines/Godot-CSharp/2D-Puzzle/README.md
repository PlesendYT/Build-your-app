# 2D Puzzle C# Template

## Deutsch
Eine vollständige 2D-Puzzle-Vorlage in C# mit Drag-and-Drop und Level-Fortschritt.

## English
A complete 2D puzzle template in C# with drag-and-drop and level progression.

## Features / Funktionen
- Drag-and-drop mechanics
- Snap-to-grid / Rasterausrichtung
- Level completion / Levelabschluss
- Hint system / Hinweissystem

## Tech Stack / Technologie
- Godot 4 C# (.NET)
- Area2D
- Tween animations

## Extension Ideas / Erweiterungsideen
- Match-3, jigsaw, Sokoban
