# 2D Platformer C# Template

## Deutsch
Eine vollständige 2D-Plattformer-Vorlage in C# mit Bewegung, Springen, Gegnern und Münzen.

## English
A complete 2D platformer template in C# with movement, jumping, enemies, and coins.

## Features / Funktionen
- Character movement / Charakterbewegung
- Double jump / Doppelsprung
- Enemy AI / Gegner-KI
- Coin collection / Münzsammlung
- Health system / Gesundheitssystem

## How to Use / Verwendung
1. Build the project (Ctrl+B)
2. Run the scene
3. Customize Player.cs values

## Tech Stack / Technologie
- Godot 4 C# (.NET)
- CharacterBody2D
- Area2D

## Extension Ideas / Erweiterungsideen
- Wall jumping, dash, power-ups
