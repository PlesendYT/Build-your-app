# 3D Racing C# Template

## Deutsch
Eine vollständige Rennspiel-Vorlage in C# mit Fahrzeugphysik und Runden.

## English
A complete racing game template in C# with vehicle physics and laps.

## Features / Funktionen
- Vehicle physics / Fahrzeugphysik
- Acceleration, braking, steering
- Lap system / Rundensystem
- Speed boost / Geschwindigkeitsboost
- Position tracking

## Tech Stack / Technologie
- Godot 4 C# (.NET)
- RigidBody3D
- Area3D checkpoints

## Extension Ideas / Erweiterungsideen
- Vehicle customization
- Multiplayer
- Drift mechanic
