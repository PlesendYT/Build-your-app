# 3D FPS (Bevy Rust)

## Deutsch
Eine 3D-Ego-Shooter-Vorlage mit Bevy ECS in Rust. First-Person-Kamera, Schießen und Gegner.

## English
A 3D first-person shooter template using Bevy ECS in Rust. First-person camera, shooting, and enemies.

## Features / Funktionen
- First-person camera / Ego-Perspektive
- Mouse look / Maussteuerung
- Shooting with raycasting
- Enemy AI / Gegner-KI
- Health system / Gesundheitssystem

## Tech Stack / Technologie
- Rust + Bevy 0.13
- Bevy 3D
- Raycasting

## Extension Ideas / Erweiterungsideen
- Multiple weapons, multiplayer, grenades
