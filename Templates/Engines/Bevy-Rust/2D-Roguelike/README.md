# 2D Roguelike (Bevy Rust)

## Deutsch
Eine 2D-Roguelike-Vorlage mit Bevy ECS in Rust. Dungeon-Generierung und rundenbasierter Kampf.

## English
A 2D roguelike template using Bevy ECS in Rust. Dungeon generation and turn-based combat.

## Features / Funktionen
- Procedural dungeon / Prozeduraler Dungeon
- Turn-based movement / Rundenbasierte Bewegung
- Enemy AI / Gegner-KI
- Stats and leveling / Stats und Stufenaufstieg

## Tech Stack / Technologie
- Rust + Bevy 0.13
- Bevy ECS
- Tile-based rendering

## Extension Ideas / Erweiterungsideen
- Items, shops, bosses, crafting
