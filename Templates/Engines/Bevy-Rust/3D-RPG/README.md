# 3D RPG (Bevy Rust)

## Deutsch
Eine 3D-RPG-Vorlage mit Bevy ECS in Rust. Third-Person-Steuerung und Kampf.

## English
A 3D RPG template using Bevy ECS in Rust. Third-person controls and combat.

## Features / Funktionen
- Third-person camera
- Movement and combat / Bewegung und Kampf
- Enemy AI / Gegner-KI
- Health system / Gesundheitssystem

## Tech Stack / Technologie
- Rust + Bevy 0.13
- Bevy 3D
- Animation

## Extension Ideas / Erweiterungsideen
- Inventory, quests, NPCs, crafting
