# Bevy Rust Template Collection

## Deutsch
Diese Sammlung bietet vollständige Rust-Projektvorlagen mit der Bevy Engine. Jede Vorlage enthält einsatzbereiten ECS-Code für ein bestimmtes Spielgenre.

## English
This collection provides complete Rust project templates using the Bevy Engine. Each template contains production-ready ECS code for a specific game genre.

## Templates Overview / Übersicht

| Template | Genre | Type |
|---|---|---|
| 2D-Platformer | Platformer | 2D |
| 2D-TopDown | Top-Down Adventure | 2D |
| 2D-Puzzle | Puzzle Game | 2D |
| 2D-Roguelike | Roguelike | 2D |
| 3D-FPS | First-Person Shooter | 3D |
| 3D-RPG | Role-Playing Game | 3D |

## How to Use / Verwendung

1. Copy template into a new Cargo project
2. Add dependencies in Cargo.toml
3. Run with `cargo run`

## Requirements / Voraussetzungen
- Rust 1.70+
- Bevy 0.13+
- Cargo package manager
