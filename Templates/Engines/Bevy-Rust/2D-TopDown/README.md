# 2D Top-Down (Bevy Rust)

## Deutsch
Eine vollständige 2D-Top-Down-Vorlage mit Bevy ECS in Rust. Bewegung, Dash und Gegner-Patrouille.

## English
A complete 2D top-down template using Bevy ECS in Rust. Movement, dash, and enemy patrol.

## Features / Funktionen
- 4-directional movement / 4-Richtungen Bewegung
- Dash ability / Dash-Fähigkeit
- Enemy patrol AI / Gegner-Patrouillen-KI
- Tile-based movement / Rasterbasierte Bewegung

## Tech Stack / Technologie
- Rust + Bevy 0.13
- Bevy ECS
- 2D rendering

## Extension Ideas / Erweiterungsideen
- Inventory, dialogue, quest system
