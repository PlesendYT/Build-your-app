# 2D Platformer (Bevy Rust)

## Deutsch
Eine vollständige 2D-Plattformer-Vorlage mit Bevy ECS in Rust. Enthält Bewegung, Springen, Gegner und Münzen.

## English
A complete 2D platformer template using Bevy ECS in Rust. Includes movement, jumping, enemies, and coins.

## Features / Funktionen
- Player movement / Spielerbewegung
- Jumping and double jump / Springen und Doppelsprung
- Enemy patrol AI / Gegner-Patrouillen-KI
- Coin collection / Münzsammlung
- Bevy ECS architecture

## How to Use / Verwendung
1. Create a new Cargo project
2. Add Bevy 0.13 as dependency
3. Copy these files into `src/`
4. Run with `cargo run`

## Tech Stack / Technologie
- Rust 1.70+
- Bevy 0.13 ECS
- SpriteSheet animation

## Extension Ideas / Erweiterungsideen
- Wall jumping, dash, power-ups, save system
