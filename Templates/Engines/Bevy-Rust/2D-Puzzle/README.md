# 2D Puzzle (Bevy Rust)

## Deutsch
Eine 2D-Puzzle-Vorlage mit Bevy ECS in Rust. Drag-and-Drop-Puzzleteile.

## English
A 2D puzzle template using Bevy ECS in Rust. Drag-and-drop puzzle pieces.

## Features / Funktionen
- Drag-and-drop / Ziehen und Ablegen
- Snap-to-grid / Rasterausrichtung
- Puzzle validation / Puzzle-Validierung
- Level completion / Levelabschluss

## Tech Stack / Technologie
- Rust + Bevy 0.13
- Bevy ECS
- 2D rendering

## Extension Ideas / Erweiterungsideen
- Match-3, jigsaw, timer mode
