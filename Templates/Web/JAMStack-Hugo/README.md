# Hugo JAMStack Template

> Statische Site mit Hugo. / Static site with Hugo.

## Features
- Inhalte in Markdown / Markdown content
- Taxonomien und Listen / Taxonomies and lists
- Schneller Build / Fast build

## How to Use
1. Installiere Hugo (`brew install hugo` oder [Download](https://gohugo.io/installation/)) / Install Hugo
2. Initialisiere eine neue Site mit diesem Layout, oder kopiere `content/` in eine vorhandene Site / Initialize a new site with this layout, or copy `content/` into an existing site

## Tech Stack
- Hugo (Go)

## Extension Ideas
- Theme wie PaperMod oder Ananke / Theme such as PaperMod or Ananke
- Hugo-Pipes für SCSS/JS / Hugo Pipes for SCSS/JS
- Mehrsprachigkeit / Multilingual
