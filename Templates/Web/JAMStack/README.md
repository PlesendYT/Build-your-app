# JAMStack Template

## 🇩🇪 Deutsch
Moderne JAMStack-Website (JavaScript, APIs, Markup) mit 11ty (Eleventy) als statischem Site-Generator.

**Features:**
- 11ty (Eleventy) Static Site Generator
- Nunjucks Templates
- Markdown-Inhalte
- Automatischer Build
- Netlify-ready

**Tech Stack:** 11ty/Eleventy, Nunjucks, Markdown, HTML5, CSS3

**Erweiterungsideen:**
- Headless CMS (Sanity, Strapi)
- Tailwind CSS Integration
- RSS-Feed + Sitemap

## 🇬🇧 English
Modern JAMStack website (JavaScript, APIs, Markup) with 11ty (Eleventy) as static site generator.

**Features:**
- 11ty (Eleventy) Static Site Generator
- Nunjucks templates
- Markdown content
- Automatic build
- Netlify-ready

**Tech Stack:** 11ty/Eleventy, Nunjucks, Markdown, HTML5, CSS3

**Extension Ideas:**
- Headless CMS (Sanity, Strapi)
- Tailwind CSS integration
- RSS feed + sitemap

## How to use / Verwendung
```bash
npm install
npx @11ty/eleventy --serve
# Opens at http://localhost:8080
```
