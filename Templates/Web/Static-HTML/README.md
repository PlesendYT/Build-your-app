# Static HTML Template

## 🇩🇪 Deutsch
Reine HTML5/CSS3/JS-Website ohne Build-Tools. Ideal für einfache Landing Pages oder kleine Websites.

**Features:**
- Semantisches HTML5
- Modernes CSS3 (Flexbox, Grid, Custom Properties)
- Vanilla JavaScript (ES6+)
- Responsive Design
- Keine Abhängigkeiten

**Tech Stack:** HTML5, CSS3, JavaScript (ES6+)

**Erweiterungsideen:**
- CSS-Präprozessor (SASS/SCSS)
- Alpine.js für Interaktivität
- Formular mit Formspree/Netlify Forms

## 🇬🇧 English
Pure HTML5/CSS3/JS website without build tools. Ideal for simple landing pages or small websites.

**Features:**
- Semantic HTML5
- Modern CSS3 (Flexbox, Grid, Custom properties)
- Vanilla JavaScript (ES6+)
- Responsive design
- Zero dependencies

**Tech Stack:** HTML5, CSS3, JavaScript (ES6+)

**Extension Ideas:**
- CSS preprocessor (SASS/SCSS)
- Alpine.js for interactivity
- Form with Formspree/Netlify Forms

## How to use / Verwendung
```bash
# Open index.html directly in a browser
# Or serve with any static server:
npx serve .
```
