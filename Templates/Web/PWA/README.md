# PWA Template (Progressive Web App)

## 🇩🇪 Deutsch
Progressive Web App mit Offline-Support, installierbar auf dem Homescreen. Enthält einen einfachen Notiz-Manager.

**Features:**
- Service Worker für Offline-Caching
- Web App Manifest für Installation
- IndexedDB für lokale Speicherung
- Install Prompt
- Vollständig offline-fähig

**Tech Stack:** HTML5, CSS3, JavaScript (ES6+), Service Worker API, IndexedDB

**Erweiterungsideen:**
- Push-Benachrichtigungen
- Background Sync
- Workbox für Service Worker Management
- React/Vue/Svelte Frontend

## 🇬🇧 English
Progressive Web App with offline support, installable on the home screen. Includes a simple note manager.

**Features:**
- Service Worker for offline caching
- Web App Manifest for installation
- IndexedDB for local storage
- Install prompt
- Fully offline-capable

**Tech Stack:** HTML5, CSS3, JavaScript (ES6+), Service Worker API, IndexedDB

**Extension Ideas:**
- Push notifications
- Background Sync
- Workbox for Service Worker management
- React/Vue/Svelte frontend

## How to use / Verwendung
```bash
# Serve with HTTPS or localhost:
npx serve .
# Open in browser, the app will prompt for installation
```
