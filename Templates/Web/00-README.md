# 🌐 Web Templates – Build Your App

Willkommen zur Web-Template-Sammlung! Hier findest du moderne Vorlagen für Webentwicklung.

Welcome to the Web template collection! Find modern starter templates for web development.

## Enthaltene Templates / Included Templates

| Verzeichnis | Beschreibung |
|---|---|
| Static-HTML/ | Reines HTML5/CSS3/JS – keine Build-Tools |
| CSS-Framework/ | Responsive Seite mit Tailwind / Bootstrap |
| JAMStack/ | JavaScript, APIs, Markup – statischer Site-Generator |
| PWA/ | Progressive Web App mit Service Worker |

## Verwendung / Usage

Jeder Template-Ordner enthält:
- Eine **README.md** mit Beschreibung (DE + EN)
- **Quellcode-Dateien** zum sofortigen Starten
- **Build-Konfigurationen** (package.json, etc.)

Wähle ein Template, kopiere den Ordner und beginne mit der Entwicklung!

Pick a template, copy the folder, and start building!
