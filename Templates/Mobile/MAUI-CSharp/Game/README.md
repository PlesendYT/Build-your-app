# MAUI Game 2D

## 🇩🇪 Deutsch
Einfaches 2D-Spiel in .NET MAUI mit GraphicsView und Touch-Steuerung.

**Features:**
- GraphicsView + IDrawable für 2D-Rendering
- Touch-Steuerung (PanGestureRecognizer)
- Game Loop mit IDispatcherTimer
- Kollisionserkennung

**Tech Stack:** C#, .NET MAUI, GraphicsView

**Erweiterungsideen:**
- Sound-Effekte
- Highscore mit Preferences
- Level-System

## 🇬🇧 English
Simple 2D game in .NET MAUI with GraphicsView and touch controls.

**Features:**
- GraphicsView + IDrawable for 2D rendering
- Touch controls (PanGestureRecognizer)
- Game loop with IDispatcherTimer
- Collision detection

**Tech Stack:** C#, .NET MAUI, GraphicsView

**Extension Ideas:**
- Sound effects
- Highscore with Preferences
- Level system
