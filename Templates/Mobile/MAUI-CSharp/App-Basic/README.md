# MAUI App Basic

## 🇩🇪 Deutsch
Einfache .NET MAUI App mit einer Seite, die "Hello World" anzeigt. Minimaler Einstieg.

**Features:**
- Single-Page XAML
- Code-Behind Logik
- .NET MAUI Shell Navigation

**Tech Stack:** C#, .NET MAUI, XAML

**Erweiterungsideen:**
- Navigation mit Shell
- MVVM mit CommunityToolkit.Mvvm
- Plattformspezifische Features

## 🇬🇧 English

**Features:**

- .NET MAUI Shell navigation

**Tech Stack:** C#, .NET MAUI, XAML

**Extension Ideas:**
