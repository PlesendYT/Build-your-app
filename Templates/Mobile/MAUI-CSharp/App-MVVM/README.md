# MAUI App MVVM

## 🇩🇪 Deutsch
.NET MAUI App mit MVVM-Architektur und CommunityToolkit.Mvvm.

**Features:**
- CommunityToolkit.Mvvm (ObservableObject, RelayCommand)
- ViewModel + Model + View Trennung
- Datenbindung in XAML
- Dependency Injection

**Tech Stack:** C#, .NET MAUI, CommunityToolkit.Mvvm, XAML

**Erweiterungsideen:**
- Entity Framework Core für SQLite
- HTTP-Client für API-Aufrufe
- Unit Tests
