# 📱 Mobile App Templates – Build Your App

Willkommen zur Mobile-Template-Sammlung! Hier findest du sofort einsatzbereite Vorlagen für die wichtigsten mobilen Plattformen.

Welcome to the Mobile template collection! Find ready-to-use starter templates for all major mobile platforms.

## Enthaltene Frameworks / Included Frameworks

|---|---|---|
| Android-Kotlin/ | Kotlin | Android (Jetpack Compose) |

## Verwendung / Usage

Jeder Template-Ordner enthält:
- Eine **README.md** mit Beschreibung (DE + EN)
- **Quellcode-Dateien** zum sofortigen Starten
- **Build-Konfigurationen** (build.gradle.kts, Package.swift, pubspec.yaml, package.json, .csproj)

Wähle ein Framework, kopiere den gewünschten Template-Ordner und beginne mit der Entwicklung!

Pick a framework, copy the template folder you need, and start building!
