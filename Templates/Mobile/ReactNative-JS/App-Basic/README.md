# React Native App Basic

## 🇩🇪 Deutsch
Einfache React Native App mit Expo. Minimaler Einstieg in die plattformübergreifende Entwicklung.

**Features:**
- Expo Managed Workflow
- React Native Core Components
- State mit useState
- StyleSheet

**Tech Stack:** JavaScript/TypeScript, React Native, Expo

**Erweiterungsideen:**
- React Navigation hinzufügen
- Expo Vector Icons
- Dark Mode mit Context
