# React Native Game

## 🇩🇪 Deutsch
Einfaches 2D-Spiel in React Native mit react-native-game-engine und Touch-Steuerung.

**Features:**
- react-native-game-engine Game Loop
- Touch-Steuerung (PanResponder)
- Kollisionserkennung
- Canvas-artiges Rendering mit Views

**Tech Stack:** JavaScript/TypeScript, React Native, Expo, react-native-game-engine

**Erweiterungsideen:**
- Matter.js für Physik
- Sound-Effekte mit expo-av
- Highscore mit AsyncStorage

## 🇬🇧 English
Simple 2D game in React Native with react-native-game-engine and touch controls.

**Features:**
- react-native-game-engine game loop
- Touch controls (PanResponder)
- Collision detection
- Canvas-like rendering with Views

**Tech Stack:** JavaScript/TypeScript, React Native, Expo, react-native-game-engine

**Extension Ideas:**
- Matter.js for physics
- Sound effects with expo-av
- Highscore with AsyncStorage
