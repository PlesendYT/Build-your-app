# React Native App State Management

## 🇩🇪 Deutsch
React Native App mit Redux Toolkit für globales State-Management.

**Features:**
- Redux Toolkit (createSlice, configureStore)
- Provider + useSelector/useDispatch
- Async Thunks für API-Aufrufe
- DevTools-kompatibel

**Tech Stack:** JavaScript/TypeScript, React Native, Expo, Redux Toolkit

**Erweiterungsideen:**
- RTK Query für API-Caching
- Redux Persist
- Middleware für Logging

## 🇬🇧 English
React Native app with Redux Toolkit for global state management.

**Features:**
- Redux Toolkit (createSlice, configureStore)
- Provider + useSelector/useDispatch
- Async thunks for API calls
- DevTools-compatible

**Tech Stack:** JavaScript/TypeScript, React Native, Expo, Redux Toolkit

**Extension Ideas:**
- RTK Query for API caching
- Redux Persist
- Middleware for logging
