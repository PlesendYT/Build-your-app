# React Native App Navigation

## 🇩🇪 Deutsch
Multi-Screen React Native App mit React Navigation (Stack + Tab Navigator).

**Features:**
- @react-navigation/native + stack + tabs
- Navigation zwischen Screens
- Parameter-Übergabe
- Header-Konfiguration

**Tech Stack:** JavaScript/TypeScript, React Native, Expo, React Navigation

**Erweiterungsideen:**
- Drawer Navigator
- Deep Linking
- Authentifizierungs-Flow
