# Flutter App Basic

## 🇩🇪 Deutsch
Einfache Flutter-App mit Counter-Beispiel. Minimaler Einstieg in Flutter und Widget-Tree.

**Features:**
- MaterialApp + Scaffold
- StatefulWidget mit setState
- Plattformübergreifend (iOS, Android, Web)

**Tech Stack:** Dart, Flutter, Material Design

**Erweiterungsideen:**
- Navigation zu zweitem Screen
- HTTP-Requests mit http-Paket
- State-Management mit Provider

## 🇬🇧 English

**Tech Stack:** Dart, Flutter, Material Design
