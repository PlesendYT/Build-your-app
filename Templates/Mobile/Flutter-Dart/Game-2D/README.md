# Flutter Game 2D

## 🇩🇪 Deutsch
2D-Spiel in Flutter mit CustomPainter und Game Loop. Steuere einen Kreis per Touch und sammle Münzen.

**Features:**
- CustomPainter für 2D-Rendering
- Ticker-basierte Game Loop
- Touch-Steuerung
- Kollisionserkennung

**Tech Stack:** Dart, Flutter, CustomPainter, Ticker

**Erweiterungsideen:**
- Animationen mit AnimationController
- Sound-Effekte
- Highscore mit SharedPreferences

## 🇬🇧 English
2D game in Flutter with CustomPainter and game loop. Control a circle via touch and collect coins.

**Features:**
- CustomPainter for 2D rendering
- Ticker-based game loop
- Touch controls
- Collision detection

**Tech Stack:** Dart, Flutter, CustomPainter, Ticker

**Extension Ideas:**
- Animations with AnimationController
- Sound effects
- Highscore with SharedPreferences
