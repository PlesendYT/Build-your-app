# Flutter Game Flame

## 🇩🇪 Deutsch
2D-Spiel mit der Flame Engine. Zeige einen Spieler, sammle Items und weiche Hindernissen aus.

**Features:**
- Flame Game Widget + Game Loop
- Sprite-Komponenten (SpriteComponent)
- Kollisionserkennung (HasCollisionDetection)
- Tastatur-/Touch-Steuerung

**Tech Stack:** Dart, Flutter, Flame Engine, Flame Forge2D

**Erweiterungsideen:**
- Flame Audio für Sound
- Tiled-Levels mit Flame Tiled
- Particle-Effekte

## 🇬🇧 English
2D game using the Flame Engine. Display a player, collect items, and avoid obstacles.

**Features:**
- Flame Game Widget + game loop
- Sprite components (SpriteComponent)
- Collision detection (HasCollisionDetection)
- Keyboard/touch controls

**Tech Stack:** Dart, Flutter, Flame Engine, Flame Forge2D

**Extension Ideas:**
- Flame Audio for sound
- Tiled levels with Flame Tiled
- Particle effects
