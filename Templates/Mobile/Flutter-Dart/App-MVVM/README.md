# Flutter App MVVM

## 🇩🇪 Deutsch
Flutter-App mit MVVM-Architektur und Riverpod für State-Management.

**Features:**
- Riverpod (StateNotifierProvider)
- Repository Pattern
- Dienste (Services) Schicht
- Asynchrone Datenverarbeitung

**Tech Stack:** Dart, Flutter, Riverpod, freezed

**Erweiterungsideen:**
- Dio für HTTP-Requests
- GoRouter für Navigation
- Hive/Isar für lokale Speicherung

## 🇬🇧 English
Flutter app with MVVM architecture and Riverpod for state management.

**Features:**
- Riverpod (StateNotifierProvider)
- Repository pattern
- Services layer
- Async data handling

**Tech Stack:** Dart, Flutter, Riverpod, freezed

**Extension Ideas:**
- Dio for HTTP requests
- GoRouter for navigation
- Hive/Isar for local storage
