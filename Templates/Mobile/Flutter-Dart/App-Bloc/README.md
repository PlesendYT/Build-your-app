# Flutter App Bloc

## 🇩🇪 Deutsch
Flutter-App mit Bloc/Cubit State-Management. Ideal für komplexe Anwendungen mit klar getrennten Concerns.

**Features:**
- Bloc/Cubit Architektur
- Events, States, Blocs
- Repository-Schicht
- BlocBuilder, BlocListener

**Tech Stack:** Dart, Flutter, flutter_bloc, equatable

**Erweiterungsideen:**
- Hydrated Bloc für Persistenz
- BlocObserver für Logging
- Integration Tests
