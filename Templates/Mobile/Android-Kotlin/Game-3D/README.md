# Android Game 3D

## 🇩🇪 Deutsch
Einfache 3D-Szene mit OpenGL ES 2.0. Zeigt rotierende 3D-Objekte mit Beleuchtung.

**Features:**
- OpenGL ES 2.0 Renderer
- 3D-Objekte (Würfel, Kugel)
- Beleuchtung und Schattierung
- Kamerasteuerung per Touch

**Tech Stack:** Kotlin, OpenGL ES 2.0, GLSurfaceView

**Erweiterungsideen:**
- Texturmapping
- 3D-Modelle (.obj) importieren
- Particle-System

## 🇬🇧 English
Simple 3D scene with OpenGL ES 2.0. Displays rotating 3D objects with lighting.

**Features:**
- OpenGL ES 2.0 renderer
- 3D objects (cube, sphere)
- Lighting and shading
- Camera control via touch

**Tech Stack:** Kotlin, OpenGL ES 2.0, GLSurfaceView
