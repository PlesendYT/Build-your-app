# Android-Kotlin Templates

Kotlin-basierte Android-Vorlagen mit Jetpack Compose, MVVM und moderner Android-Architektur.

Kotlin-based Android templates with Jetpack Compose, MVVM, and modern Android architecture.

## Templates

| Verzeichnis | Beschreibung |
|---|---|
| App-Basic/ | Einfache Activity mit Compose – minimaler Einstieg |
| App-MVVM/ | MVVM + Repository + ViewModel + Room |
| App-Compose/ | Fortgeschrittene Compose-UI mit Navigation, Themes, Animationen |
| Game-2D/ | 2D-Spiel mit Canvas & Game-Loop |
| Game-3D/ | 3D-Szene mit OpenGL ES / Rajawali |
