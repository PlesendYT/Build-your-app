# Android App MVVM

## 🇩🇪 Deutsch
Android-App mit MVVM-Architektur, Repository-Pattern und lokaler Datenhaltung mit Room.

**Features:**
- ViewModel + Repository + Room-Datenbank
- LiveData / Flow für reaktive Updates
- Dependency Injection (manuell / Hilt-vorbereitet)
- Coroutines für asynchrone Operationen

**Tech Stack:** Kotlin, Jetpack Compose, ViewModel, Room, Coroutines, Hilt

**Erweiterungsideen:**
- Retrofit für Remote-API hinzufügen
- Navigation mit NavHost
- Tests mit JUnit + MockK
