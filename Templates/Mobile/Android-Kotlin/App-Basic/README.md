# Android App Basic

## 🇩🇪 Deutsch
Einfache Android-App mit einer einzigen Activity, die "Hello World" in Jetpack Compose anzeigt. Ideal für absolute Einsteiger.

**Features:**
- Single-Activity-Architektur
- Jetpack Compose UI
- Material 3 Design
- Dunkles/Helles Theme

**Tech Stack:** Kotlin, Jetpack Compose, Material 3, Gradle KTS

**Erweiterungsideen:**
- Navigation mit NavHost hinzufügen
- ViewModel für State-Management
- Retrofit für API-Aufrufe

## 🇬🇧 English
Simple Android app with a single Activity displaying "Hello World" in Jetpack Compose. Perfect for absolute beginners.

**Features:**
- Single-Activity architecture
- Jetpack Compose UI
- Material 3 Design
- Dark/Light theme

**Tech Stack:** Kotlin, Jetpack Compose, Material 3, Gradle KTS

**Extension Ideas:**
- Add navigation with NavHost
- Add ViewModel for state management
- Add Retrofit for API calls

## How to use / Verwendung
```bash
# Open in Android Studio
# Sync Gradle and run on emulator/device
```
