# Android Game 2D

## 🇩🇪 Deutsch
Einfaches 2D-Spiel mit Canvas-API und Game-Loop. Steuere eine Spielfigur per Touch.

**Features:**
- Game-Loop mit fps-Management
- Touch-Steuerung
- Kollisionserkennung
- Canvas-Rendering

**Tech Stack:** Kotlin, Canvas API, SurfaceView

**Erweiterungsideen:**
- Sound-Effekte mit SoundPool
- Highscore mit Room
- Level-System

## 🇬🇧 English
Simple 2D game with Canvas API and game loop. Control a character via touch.

**Features:**
- Game loop with FPS management
- Touch controls
- Collision detection
- Canvas rendering

**Tech Stack:** Kotlin, Canvas API, SurfaceView
