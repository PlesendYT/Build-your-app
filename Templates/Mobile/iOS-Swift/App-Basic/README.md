# iOS App Basic

## 🇩🇪 Deutsch
Einfache iOS-App mit SwiftUI, die "Hello World" anzeigt. Minimaler Einstieg in die iOS-Entwicklung.

**Features:**
- SwiftUI App Lifecycle
- Text- und Button-Komponenten
- State mit @State

**Tech Stack:** Swift, SwiftUI, Xcode

**Erweiterungsideen:**
- NavigationView hinzufügen
- @StateObject für komplexeren State
- MVVM-Architektur

## 🇬🇧 English
Simple iOS app with SwiftUI displaying "Hello World". Minimal entry point for iOS development.

**Features:**
- SwiftUI App Lifecycle
- Text and Button components
- State with @State

**Tech Stack:** Swift, SwiftUI, Xcode

**Extension Ideas:**
- Add NavigationView
- @StateObject for complex state
- MVVM architecture
