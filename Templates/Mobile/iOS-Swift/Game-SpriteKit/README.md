# iOS Game SpriteKit 2D

## 🇩🇪 Deutsch
2D-Spiel mit SpriteKit. Steuere einen Spieler per Touch und sammle Punkte, während du Hindernissen ausweichst.

**Features:**
- SpriteKit SKSpriteNode + SKPhysicsBody
- Kollisionserkennung
- Touch-Steuerung
- Punktestand und Game Over

**Tech Stack:** Swift, SpriteKit, GameplayKit

**Erweiterungsideen:**
- SKAction für Animationen
- Particle-Emitter (SKEmitterNode)
- Sound mit SKAction.playSoundFileNamed

## 🇬🇧 English
2D game with SpriteKit. Control a player via touch, collect points, and avoid obstacles.

**Features:**
- SpriteKit SKSpriteNode + SKPhysicsBody
- Collision detection
- Touch controls
- Score and Game Over

**Tech Stack:** Swift, SpriteKit, GameplayKit

**Extension Ideas:**
- SKAction for animations
- Particle emitter (SKEmitterNode)
- Sound with SKAction.playSoundFileNamed
