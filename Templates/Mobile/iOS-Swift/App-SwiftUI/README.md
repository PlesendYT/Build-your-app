# iOS App SwiftUI Advanced

## 🇩🇪 Deutsch
Fortgeschrittene SwiftUI-App mit Navigation, Animationen, Charts und modernem iOS-Design.

**Features:**
- NavigationStack + NavigationSplitView
- LazyVGrid für Collection-Layouts
- .matchedGeometryEffect Animationen
- Charts Framework (iOS 16+)
- Dark/Light Mode Support

**Tech Stack:** Swift, SwiftUI, Charts, Navigation

**Erweiterungsideen:**
- WidgetKit Extension
- CoreData + CloudKit Sync
- Swift Concurrency (async/await)

## 🇬🇧 English
Advanced SwiftUI app with navigation, animations, charts, and modern iOS design.

**Features:**
