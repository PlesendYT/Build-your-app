# iOS App MVVM

## 🇩🇪 Deutsch
iOS-App mit MVVM-Architektur, Combine und URLSession für API-Aufrufe.

**Features:**
- MVVM mit ObservableObject
- Combine für reaktive Bindungen
- URLSession für Netzwerkanfragen
- Async/Await Support

**Tech Stack:** Swift, SwiftUI, Combine, URLSession

**Erweiterungsideen:**
- CoreData für Persistenz
- Dependency Injection
- Unit Tests mit XCTest

## 🇬🇧 English
iOS app with MVVM architecture, Combine, and URLSession for API calls.

**Features:**
- MVVM with ObservableObject
- Combine for reactive bindings
- URLSession for network requests
- Async/Await support

**Tech Stack:** Swift, SwiftUI, Combine, URLSession

**Extension Ideas:**
- CoreData for persistence
- Dependency Injection
- Unit Tests with XCTest
