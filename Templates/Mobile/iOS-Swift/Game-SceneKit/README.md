# iOS Game SceneKit 3D

## 🇩🇪 Deutsch
3D-Szene mit SceneKit. Zeigt rotierende 3D-Objekte mit Beleuchtung und Kamerasteuerung.

**Features:**
- SceneKit SCNScene + SCNNode
- 3D-Geometrien (SCNBox, SCNSphere)
- Beleuchtung (SCNLight)
- Kamerasteuerung per Tap

**Tech Stack:** Swift, SceneKit

**Erweiterungsideen:**
- 3D-Modelle (.scn, .obj) importieren
- SCNPhysicsBody für Kollisionen
- ARKit-Integration

## 🇬🇧 English
3D scene with SceneKit. Displays rotating 3D objects with lighting and camera control.

**Features:**
- SceneKit SCNScene + SCNNode
- 3D geometries (SCNBox, SCNSphere)
- Lighting (SCNLight)
- Camera control via tap

**Tech Stack:** Swift, SceneKit

**Extension Ideas:**
- Import 3D models (.scn, .obj)
- SCNPhysicsBody for collisions
- ARKit integration
