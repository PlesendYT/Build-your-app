# Ruby on Rails RESTAPI Template

## Beschreibung

REST-API mit Rails API Mode und JWT-Authentifizierung.

## Features

- Rails API Mode
- JWT Auth
- Serializer (Active Model Serializers)
- CORS
- Rate Limiting

## Verwendung

```bash
bundle install
rails db:migrate
rails server
```

## Tech Stack

- Rails 7+ API Mode
- JWT (devise-jwt)
- PostgreSQL
- Rack CORS

## Erweiterungsmöglichkeiten

- API Versionierung
- Swagger-Dokumentation
- Paginierung
