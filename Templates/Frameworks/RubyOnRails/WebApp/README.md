# Ruby on Rails WebApp Template

## Beschreibung

Vollständige Rails-Webanwendung mit Hotwire (Turbo + Stimulus).

## Features

- Rails 7+ mit Hotwire
- Turbo Streams
- Stimulus JS
- ActiveRecord ORM
- Action Cable

## Verwendung

```bash
bundle install
rails db:migrate
rails server
```

## Tech Stack

- Rails 7+
- Hotwire (Turbo + Stimulus)
- PostgreSQL
- Importmap

## Erweiterungsmöglichkeiten

- Action Text
- Active Storage
- API-Modus
