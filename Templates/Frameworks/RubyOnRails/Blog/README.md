# Ruby on Rails Blog Template

## Beschreibung

Blog-Plattform mit Rails, Action Text und Admin-Bereich.

## Features

- Blog-Posts
- Action Text (Rich Text)
- Kommentare
- Kategorien
- Admin-Dashboard

## Verwendung

```bash
bundle install
rails db:migrate
rails server
```

## Tech Stack

- Rails 7+
- Action Text
- Hotwire
- PostgreSQL

## Erweiterungsmöglichkeiten

- Newsletter
- Social Sharing
- SEO
