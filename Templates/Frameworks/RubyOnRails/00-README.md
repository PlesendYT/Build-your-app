# Ruby on Rails Templates

Übersicht aller Rails-Template-Vorlagen für die Build-Your-App Plattform.

## Verfügbare Templates

| Template | Beschreibung |
|----------|-------------|
| **WebApp** | Vollständige Webanwendung mit Hotwire |
| **RESTAPI** | REST-API mit Rails API Mode |
| **Blog** | Blog-Plattform mit Action Text |
| **ECommerce** | E-Commerce mit Stimulus Reflex |

## Gemeinsame Technologien

- Rails 7+ mit Hotwire (Turbo + Stimulus)
- ActiveRecord ORM
- Action Cable für WebSockets
- PostgreSQL-Datenbank
- Importmap / ESBuild

# Ruby on Rails Templates

Overview of all Rails template presets for the Build-Your-App platform.

## Available Templates

| Template | Description |
|----------|-------------|
| **WebApp** | Full web application with Hotwire |
| **RESTAPI** | REST API with Rails API Mode |
| **Blog** | Blog platform with Action Text |
| **ECommerce** | E-commerce with Stimulus Reflex |

## Shared Technologies

- Rails 7+ with Hotwire (Turbo + Stimulus)
- ActiveRecord ORM
- Action Cable for WebSockets
- PostgreSQL database
- Importmap / ESBuild
