# Ruby on Rails ECommerce Template

## Beschreibung

E-Commerce-Plattform mit Rails, Stimulus Reflex und Warenkorb.

## Features

- Produktkatalog
- Warenkorb (Session)
- Stimulus Reflex
- Bestellverwaltung
- Admin-Bereich

## Verwendung

```bash
bundle install
rails db:migrate
rails server
```

## Tech Stack

- Rails 7+
- Stimulus Reflex
- Hotwire
- PostgreSQL

## Erweiterungsmöglichkeiten

- Stripe/PayPal
- Bewertungen
- Rabattcodes
