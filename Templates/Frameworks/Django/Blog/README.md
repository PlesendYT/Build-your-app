# Django Blog Template

## Beschreibung

Blog-Plattform mit Django, Kategorien, Tags und Kommentaren.

## Features

- Blog-Posts mit Kategorien und Tags
- Kommentarsystem
- Suchfunktion
- RSS-Feed
- Django Admin-Integration
- Markdown-Unterstützung

## Verwendung

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

## Tech Stack

- Django 5
- Class-Based Views
- Django Templates
- SQLite

## Erweiterungsmöglichkeiten

- Newsletter
- Social-Media-Integration
- Bilder-Galerie
