# Django WebApp Template

## Beschreibung

Vollständige Django-Webanwendung mit Class-Based Views und Admin-Interface.

## Features

- Class-Based Views (ListView, DetailView, CreateView)
- Django Admin konfiguriert
- SQLite/PostgreSQL
- Responsive Templates
- Formularverarbeitung

## Verwendung

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

## Tech Stack

- Django 5
- Class-Based Views
- Django Templates
- SQLite

## Erweiterungsmöglichkeiten

- REST-API mit DRF
- Benutzer-Authentifizierung
- Celery für Hintergrundaufgaben
