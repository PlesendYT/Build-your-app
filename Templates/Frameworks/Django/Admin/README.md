# Django Admin Template

## Beschreibung

Erweitertes Django-Admin-Panel mit benutzerdefinierten Ansichten und Dashboard.

## Features

- Custom Admin Dashboard
- Benutzerdefinierte Admin-Aktionen
- Datenvisualisierung
- Erweiterte Filter und Suche
- Export-Funktionen (CSV/Excel)
- Dashboard-Widgets

## Verwendung

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

## Tech Stack

- Django 5
- Django Admin Customization
- django-import-export
- SimpleUI / Grappelli

## Erweiterungsmöglichkeiten

- Chart-Integration
- Benachrichtigungen
- Audit-Log
