# Django RESTAPI Template

## Beschreibung

REST-API mit Django REST Framework, Serializern und ViewSets.

## Features

- Django REST Framework
- ViewSets und Routers
- Serializer mit Validierung
- API-Authentifizierung
- Swagger-Dokumentation
- CORS-Unterstützung

## Verwendung

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

## Tech Stack

- Django 5
- Django REST Framework
- DRF-Spectacular (Swagger)
- PostgreSQL

## Erweiterungsmöglichkeiten

- OAuth2/JWT Auth
- Rate Limiting
- Versionierung
