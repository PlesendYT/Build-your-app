# Django ECommerce Template

## Beschreibung

E-Commerce-Plattform mit Django, Produktverwaltung und Warenkorb.

## Features

- Produktkatalog mit Kategorien
- Warenkorb (Session-basiert)
- Bestellverwaltung
- Admin-Bereich
- Zahlungsintegration vorbereitet

## Verwendung

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

## Tech Stack

- Django 5
- Class-Based Views
- Django Templates
- Session-basierter Warenkorb

## Erweiterungsmöglichkeiten

- Stripe/PayPal-Integration
- Bewertungssystem
- Rabattcodes
