# Django Templates

Übersicht aller Django-Template-Vorlagen für die Build-Your-App Plattform.

## Verfügbare Templates

| Template | Beschreibung |
|----------|-------------|
| **WebApp** | Vollständige Webanwendung mit Class-Based Views |
| **RESTAPI** | REST-API mit Django REST Framework |
| **Blog** | Blog-Plattform mit Admin-Interface |
| **ECommerce** | E-Commerce-Anwendung mit Produktverwaltung |
| **Admin** | Erweitertes Admin-Panel mit Customization |

## Gemeinsame Technologien

- Django 5 mit Class-Based Views
- Django REST Framework (DRF)
- PostgreSQL / SQLite
- HTML-Templates mit Django Template Language
- WhiteNoise für Static Files

# Django Templates

Overview of all Django template presets for the Build-Your-App platform.

## Available Templates

| Template | Description |
|----------|-------------|
| **WebApp** | Full web application with Class-Based Views |
| **RESTAPI** | REST API with Django REST Framework |
| **Blog** | Blog platform with admin interface |
| **ECommerce** | E-commerce application with product management |
| **Admin** | Enhanced admin panel with customization |

## Shared Technologies

- Django 5 with Class-Based Views
- Django REST Framework (DRF)
- PostgreSQL / SQLite
- HTML templates with Django Template Language
- WhiteNoise for static files
