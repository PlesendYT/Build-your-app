# Next.js App Router Template

> Next.js 14 mit App Router und Server Components. / Next.js 14 with App Router and server components.

## Features
- App Router mit layout.tsx / App Router with layout.tsx
- Server Action für Form-Submit / Server action for form submit
- Tailwind optional / Tailwind optional

## How to Use
```bash
cd NextJS-App-Router
npm install
npm run dev
```
