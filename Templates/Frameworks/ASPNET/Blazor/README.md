# ASP.NET Blazor Template

## Beschreibung

Interaktive Webanwendung mit Blazor WebAssembly.

## Features

- Blazor WASM
- Komponenten-Modell
- HttpClient-Integration
- Routing
- Responsive UI

## Verwendung

```bash
dotnet run
```

## Tech Stack

- .NET 8
- Blazor WebAssembly
- C# 12
- CSS/Bootstrap

## Erweiterungsmöglichkeiten

- PWA
- Authentication
- GraphQL-Integration
