# ASP.NET RESTAPI Template

## Beschreibung

REST-API mit .NET 8 Minimal API und Entity Framework.

## Features

- .NET 8 Minimal API
- Entity Framework Core
- Swagger/OpenAPI
- CORS-Unterstützung
- Dependency Injection

## Verwendung

```bash
dotnet run
```

## Tech Stack

- .NET 8
- C# 12
- Entity Framework Core
- SQLite

## Erweiterungsmöglichkeiten

- JWT Authentication
- Health Checks
- Docker
