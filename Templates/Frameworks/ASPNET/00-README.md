# ASP.NET Templates

Übersicht aller ASP.NET-Template-Vorlagen für die Build-Your-App Plattform.

## Verfügbare Templates

| Template | Beschreibung |
|----------|-------------|
| **RESTAPI** | REST-API mit .NET Minimal API |
| **WebApp** | Webanwendung mit Razor Pages |
| **MVC** | MVC-Anwendung mit Controllern |
| **Blazor** | Interaktive WebApp mit Blazor WASM |

## Gemeinsame Technologien

- .NET 8 mit C# 12
- Entity Framework Core
- ASP.NET Core Identity
- Swagger/OpenAPI
- SQLite/SQL Server

# ASP.NET Templates

Overview of all ASP.NET template presets for the Build-Your-App platform.

## Available Templates

| Template | Description |
|----------|-------------|
| **RESTAPI** | REST API with .NET Minimal API |
| **WebApp** | Web application with Razor Pages |
| **MVC** | MVC application with controllers |
| **Blazor** | Interactive web app with Blazor WASM |

## Shared Technologies

- .NET 8 with C# 12
- Entity Framework Core
- ASP.NET Core Identity
- Swagger/OpenAPI
- SQLite/SQL Server
