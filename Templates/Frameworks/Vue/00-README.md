# Vue Templates

Übersicht aller Vue-Template-Vorlagen für die Build-Your-App Plattform.

## Verfügbare Templates

| Template | Beschreibung |
|----------|-------------|
| **WebApp** | Vollständige Webanwendung mit Vue Router |
| **SPA** | Single Page Application mit Vue 3 |
| **Dashboard** | Admin-Dashboard mit Composables |
| **ECommerce** | E-Commerce-Plattform mit State-Management |

## Gemeinsame Technologien

- Vue 3 Composition API mit `<script setup>`
- Vue Router 4 für Navigation
- Pinia für State-Management
- Vite als Build-Tool
- Axios für HTTP-Anfragen

# Vue Templates

Overview of all Vue template presets for the Build-Your-App platform.

## Available Templates

| Template | Description |
|----------|-------------|
| **WebApp** | Full web application with Vue Router |
| **SPA** | Single Page Application with Vue 3 |
| **Dashboard** | Admin dashboard with composables |
| **ECommerce** | E-commerce platform with state management |

## Shared Technologies

- Vue 3 Composition API with `<script setup>`
- Vue Router 4 for navigation
- Pinia for state management
- Vite as build tool
- Axios for HTTP requests
