# Vue ECommerce Template

## Beschreibung

E-Commerce-Plattform mit Vue 3, Warenkorb und Produktverwaltung.

## Features

- Produktkatalog mit Kategorien
- Warenkorb mit Pinia
- Checkout-Prozess
- Benutzer-Authentifizierung
- Admin-Bereich

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- Vue 3
- Vue Router 4
- Pinia
- Axios
- Vite

## Erweiterungsmöglichkeiten

- Zahlungsintegration
- Bewertungen
- Wishlist
