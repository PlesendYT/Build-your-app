# Vue Dashboard Template

## Beschreibung

Admin-Dashboard mit Vue 3, Composables und Chart-Integration.

## Features

- Sidebar-Navigation
- Datenvisualisierung
- Statistik-Karten
- Benutzerverwaltung
- Responsive Layout

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- Vue 3
- Vue Router 4
- Pinia
- Chart.js
- Vite

## Erweiterungsmöglichkeiten

- Dark Mode
- Export-Funktionen
- Benachrichtigungen
