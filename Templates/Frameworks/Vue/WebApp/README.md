# Vue WebApp Template

## Beschreibung

Vollständige Vue 3 Webanwendung mit Router und State-Management.

## Features

- Vue Router 4 für Navigation
- Pinia State-Management
- Composition API mit `<script setup>`
- API-Integration mit Axios
- Responsive Design
- Lazy Loading

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- Vue 3
- Vue Router 4
- Pinia
- Axios
- Vite

## Erweiterungsmöglichkeiten

- Dark Mode
- i18n
- PWA
- SSR mit Nuxt
