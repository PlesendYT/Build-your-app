# React Templates

Übersicht aller React-Template-Vorlagen für die Build-Your-App Plattform.

## Verfügbare Templates

| Template | Beschreibung |
|----------|-------------|
| **WebApp** | Vollständige Webanwendung mit Routing und State-Management |
| **SPA** | Single Page Application mit React Router |
| **Dashboard** | Admin-Dashboard mit Charts und Datenvisualisierung |
| **ECommerce** | E-Commerce-Plattform mit Warenkorb und Checkout |
| **SocialMedia** | Social-Media-Anwendung mit Posts und Feeds |

## Gemeinsame Technologien

- React 18 mit Hooks und Functional Components
- React Router v6 für Navigation
- Axios für HTTP-Anfragen
- Modulares CSS/Styled Components
- Vite als Build-Tool

# React Templates

Overview of all React template presets for the Build-Your-App platform.

## Available Templates

| Template | Description |
|----------|-------------|
| **WebApp** | Full web application with routing and state management |
| **SPA** | Single Page Application with React Router |
| **Dashboard** | Admin dashboard with charts and data visualization |
| **ECommerce** | E-commerce platform with cart and checkout |
| **SocialMedia** | Social media application with posts and feeds |

## Shared Technologies

- React 18 with Hooks and Functional Components
- React Router v6 for navigation
- Axios for HTTP requests
- Modular CSS / Styled Components
- Vite as build tool
