# React Dashboard Template

## Beschreibung

Administrations-Dashboard mit Datenvisualisierung, Charts und Verwaltungsoberfläche. Ideal für Backoffice-Anwendungen.

## Features

- Interaktive Charts und Diagramme (Recharts)
- Daten-TableView mit Sortierung und Filterung
- Responsive Sidebar-Navigation
- Benutzer- und Rollenverwaltung
- Dark Mode
- Echtzeit-Updates

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- React 18
- React Router v6
- Recharts
- Context API
- CSS Modules
- Vite

## Erweiterungsmöglichkeiten

- Drag & Drop Widgets
- Export-Funktionen (PDF/CSV)
- Benachrichtigungssystem
- Multi-Sprachunterstützung
