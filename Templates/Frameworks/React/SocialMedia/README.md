# React SocialMedia Template

## Beschreibung

Social-Media-Plattform mit Feed, Posts, Likes und Benutzerprofilen.

## Features

- News Feed mit unendlichem Scrollen
- Post-Erstellung mit Bild-Upload
- Like- und Kommentarfunktion
- Benutzerprofile mit Avatar
- Follow-System
- Benachrichtigungen

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- React 18
- React Router v6
- Context API
- Axios
- CSS Modules
- Vite

## Erweiterungsmöglichkeiten

- Direct Messaging
- Stories (wie Instagram)
- Hashtag-Suche
- Gruppen und Communities
