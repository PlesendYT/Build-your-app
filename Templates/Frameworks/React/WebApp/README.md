# React WebApp Template

## Beschreibung

Vollständige React-Webanwendung mit Routing, State-Management und API-Integration. Ideal für mittlere bis komplexe Webprojekte.

## Features

- React Router v6 für clientseitiges Routing
- Globaler State mit Context API und useReducer
- API-Integration mit Axios
- Responsive Design mit CSS Modules
- Lazy Loading für Code-Splitting
- Suchmaschinenoptimierung (SEO)

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- React 18
- React Router v6
- Axios
- CSS Modules
- Vite

## Erweiterungsmöglichkeiten

- Theme-Switcher (Dark Mode)
- Internationalisierung (i18n)
- PWA-Funktionen
- Authentifizierung mit JWT

# React WebApp Template

## Description

Full React web application with routing, state management and API integration. Ideal for medium to complex web projects.

## Features

- React Router v6 for client-side routing
- Global state with Context API and useReducer
- API integration with Axios
- Responsive design with CSS Modules
- Lazy loading for code splitting
- Search engine optimization (SEO)

## Usage

```bash
npm install
npm run dev
```

## Tech Stack

- React 18
- React Router v6
- Axios
- CSS Modules
- Vite
