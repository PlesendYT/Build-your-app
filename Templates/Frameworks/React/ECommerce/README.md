# React ECommerce Template

## Beschreibung

Vollständige E-Commerce-Plattform mit Produktkatalog, Warenkorb und Bestellabwicklung.

## Features

- Produktkatalog mit Kategorien und Suche
- Warenkorb mit Mengenverwaltung
- Checkout-Prozess mit Bestellübersicht
- Benutzerkonten und Authentifizierung
- Admin-Bereich für Produktverwaltung
- Responsive Design

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- React 18
- React Router v6
- Context API (Warenkorb)
- Axios
- CSS Modules
- Vite

## Erweiterungsmöglichkeiten

- Zahlungsintegration (Stripe/PayPal)
- Bewertungen und Rezensionen
- Wishlist-Funktion
- Rabattcodes und Aktionen

# React ECommerce Template

## Description

Complete e-commerce platform with product catalog, shopping cart, and order processing.

## Features

- Product catalog with categories and search
- Shopping cart with quantity management
- Checkout process with order summary
- User accounts and authentication
- Admin area for product management
- Responsive design

## Usage

```bash
npm install
npm run dev
```

## Tech Stack

- React 18
- React Router v6
- Context API (Cart)
- Axios
- CSS Modules
- Vite

## Extension Ideas

- Payment integration (Stripe/PayPal)
- Reviews and ratings
- Wishlist functionality
- Discount codes and promotions
