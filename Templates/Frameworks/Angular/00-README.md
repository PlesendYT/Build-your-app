# Angular Templates

Übersicht aller Angular-Template-Vorlagen für die Build-Your-App Plattform.

## Verfügbare Templates

| Template | Beschreibung |
|----------|-------------|
| **WebApp** | Vollständige Webanwendung mit Angular Router |
| **SPA** | Single Page Application mit Standalone Components |
| **Dashboard** | Admin-Dashboard mit Signals und Charts |
| **Enterprise** | Enterprise-Anwendung mit Modulen und Guards |

## Gemeinsame Technologien

- Angular 17+ mit Standalone Components
- Angular Signals für State-Management
- Angular Router für Navigation
- RxJS für asynchrone Operationen
- SCSS für Styling

# Angular Templates

Overview of all Angular template presets for the Build-Your-App platform.

## Available Templates

| Template | Description |
|----------|-------------|
| **WebApp** | Full web application with Angular Router |
| **SPA** | Single Page Application with Standalone Components |
| **Dashboard** | Admin dashboard with Signals and charts |
| **Enterprise** | Enterprise application with modules and guards |

## Shared Technologies

- Angular 17+ with Standalone Components
- Angular Signals for state management
- Angular Router for navigation
- RxJS for asynchronous operations
- SCSS for styling
