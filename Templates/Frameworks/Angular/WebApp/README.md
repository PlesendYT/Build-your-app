# Angular WebApp Template

## Beschreibung

Vollständige Angular-Webanwendung mit Standalone Components und Signals.

## Features

- Standalone Components
- Angular Signals für State
- Angular Router
- RxJS für Async-Operationen
- SCSS-Styling
- Lazy Loading

## Verwendung

```bash
npm install
ng serve
```

## Tech Stack

- Angular 17+
- Standalone Components
- Signals API
- RxJS
- SCSS

## Erweiterungsmöglichkeiten

- Angular Material
- PWA
- SSR mit Angular Universal
