# Angular Dashboard Template

## Beschreibung

Admin-Dashboard mit Angular, Signals und Chart-Integration.

## Features

- Sidebar-Navigation
- Statistik-Karten
- Signals State-Management
- Daten-Tabellen
- Responsive Layout

## Verwendung

```bash
npm install
ng serve
```

## Tech Stack

- Angular 17+
- Standalone Components
- Signals
- RxJS
- SCSS
- Chart.js

## Erweiterungsmöglichkeiten

- Dark Mode
- Export-Funktionen
- Drag & Drop
