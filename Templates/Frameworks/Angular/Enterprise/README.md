# Angular Enterprise Template

## Beschreibung

Enterprise-Anwendung mit Angular, Modulen, Guards und komplexem Routing.

## Features

- Feature-Module
- Route Guards (Auth, Roles)
- Lazy Loading
- Interceptor für HTTP
- Error Handling
- Testing-Setup

## Verwendung

```bash
npm install
ng serve
```

## Tech Stack

- Angular 17+
- Standalone Components
- Signals
- RxJS
- SCSS
- Karma/Jasmine

## Erweiterungsmöglichkeiten

- NgRx State-Management
- MSAL/Azure AD Auth
- Micro-Frontends
