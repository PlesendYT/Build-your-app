# Angular SPA Template

## Beschreibung

Single Page Application mit Angular und Standalone Components.

## Features

- Standalone Components
- Angular Router
- Signals
- Dynamische Inhalte
- Responsives Design

## Verwendung

```bash
npm install
ng serve
```

## Tech Stack

- Angular 17+
- Standalone Components
- Angular Router
- Signals
- SCSS

## Erweiterungsmöglichkeiten

- Formular-Validierung
- Charts
- HTTP-Interceptor
