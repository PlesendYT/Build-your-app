# Nuxt.js Templates

Übersicht aller Nuxt.js-Template-Vorlagen für die Build-Your-App Plattform.

## Verfügbare Templates

| Template | Beschreibung |
|----------|-------------|
| **WebApp** | Vollständige Webanwendung mit Nuxt 3 |
| **Blog** | Blog mit Content-Modul |
| **ECommerce** | E-Commerce mit State-Management |
| **Portfolio** | Portfolio-Seite mit Static Generation |

## Gemeinsame Technologien

- Nuxt 3 mit Composition API
- Auto-Import von Komponenten
- Nuxt Content für Blog
- Pinia für State-Management
- Tailwind CSS / UnoCSS

# Nuxt.js Templates

Overview of all Nuxt.js template presets for the Build-Your-App platform.

## Available Templates

| Template | Description |
|----------|-------------|
| **WebApp** | Full web application with Nuxt 3 |
| **Blog** | Blog with Content module |
| **ECommerce** | E-commerce with state management |
| **Portfolio** | Portfolio site with Static Generation |

## Shared Technologies

- Nuxt 3 with Composition API
- Auto-import of components
- Nuxt Content for blog
- Pinia for state management
- Tailwind CSS / UnoCSS
