# Nuxt.js WebApp Template

## Beschreibung

Vollständige Nuxt 3 Webanwendung mit Composition API.

## Features

- Nuxt 3 Composition API
- Auto-Import von Komponenten
- Vue Router
- Pinia State-Management
- SEO-Modul

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- Nuxt 3
- Vue 3 Composition API
- Pinia
- UnoCSS/Tailwind

## Erweiterungsmöglichkeiten

- Content-Modul
- i18n
- PWA
