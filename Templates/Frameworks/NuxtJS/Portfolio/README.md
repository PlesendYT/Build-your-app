# Nuxt.js Portfolio Template

## Beschreibung

Portfolio-Seite mit Nuxt 3 und Static Generation.

## Features

- Static Generation
- Projekte-Galerie
- Kontaktformular
- SEO-optimiert
- Responsive Design

## Verwendung

```bash
npm install
npm run generate
```

## Tech Stack

- Nuxt 3
- Static Generation
- Vue 3
- Tailwind CSS

## Erweiterungsmöglichkeiten

- CMS-Integration
- Mehrsprachigkeit
- Blog
