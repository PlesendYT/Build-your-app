# Nuxt.js Blog Template

## Beschreibung

Blog mit Nuxt 3 und dem Content-Modul.

## Features

- Nuxt Content
- Markdown-Unterstützung
- Kategorien
- Suchfunktion
- RSS-Feed

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- Nuxt 3
- Nuxt Content
- Vue 3
- Tailwind CSS

## Erweiterungsmöglichkeiten

- Kommentare
- Bildergalerie
- Newsletter
