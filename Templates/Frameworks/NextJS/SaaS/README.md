# Next.js SaaS Template

## Beschreibung

SaaS-Plattform mit Next.js 14, Auth und Abonnement-Modell.

## Features

- NextAuth.js-Integration
- Abonnement-Verwaltung
- API-Routen
- Dashboard
- Landing Page

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- Next.js 14
- NextAuth.js
- Prisma (vorgeschlagen)
- Tailwind CSS
- TypeScript

## Erweiterungsmöglichkeiten

- Stripe-Abonnements
- Team-Verwaltung
- Analytics
