# Next.js Portfolio Template

## Beschreibung

Portfolio-Seite mit Next.js 14 und Static Site Generation.

## Features

- Static Generation
- Projects-Galerie
- Blog-Integration
- Kontaktformular
- SEO-optimiert

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- Next.js 14
- Static Generation
- Tailwind CSS
- TypeScript

## Erweiterungsmöglichkeiten

- CMS-Integration
- Mehrsprachigkeit
- Dark Mode
