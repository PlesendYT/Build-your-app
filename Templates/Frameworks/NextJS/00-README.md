# Next.js Templates

Übersicht aller Next.js-Template-Vorlagen für die Build-Your-App Plattform.

## Verfügbare Templates

| Template | Beschreibung |
|----------|-------------|
| **WebApp** | Vollständige Webanwendung mit App Router |
| **Blog** | Blog mit MDX und ISR |
| **ECommerce** | E-Commerce mit Server Components |
| **Dashboard** | Dashboard mit Server Actions |
| **SaaS** | SaaS-Plattform mit Auth |
| **Portfolio** | Portfolio-Seite mit Static Generation |

## Gemeinsame Technologien

- Next.js 14 mit App Router
- React Server Components
- Server Actions
- Tailwind CSS
- TypeScript
