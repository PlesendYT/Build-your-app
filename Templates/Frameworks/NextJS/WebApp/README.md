# Next.js WebApp Template

## Beschreibung

Vollständige Next.js 14 Webanwendung mit App Router.

## Features

- App Router
- React Server Components
- Server Actions
- Tailwind CSS
- TypeScript

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- Next.js 14
- React Server Components
- Tailwind CSS
- TypeScript

## Erweiterungsmöglichkeiten

- Auth (NextAuth.js)
- Datenbank (Prisma)
- API Routes
