# Next.js Blog Template

## Beschreibung

Blog mit Next.js 14, MDX und ISR.

## Features

- MDX-Unterstützung
- Incremental Static Regeneration
- Kategorien und Tags
- Suchfunktion
- RSS-Feed

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- Next.js 14
- MDX
- Tailwind CSS
- TypeScript

## Erweiterungsmöglichkeiten

- Kommentare
- Newsletter
- CMS-Integration
