# Next.js ECommerce Template

## Beschreibung

E-Commerce mit Next.js 14, Server Components und Warenkorb.

## Features

- Server Components
- Produktkatalog
- Warenkorb (Client Component)
- Checkout
- Server Actions

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- Next.js 14
- React Server Components
- Server Actions
- Tailwind CSS
- TypeScript

## Erweiterungsmöglichkeiten

- Stripe-Integration
- Kundenkonten
