# Next.js Dashboard Template

## Beschreibung

Dashboard mit Next.js 14, Server Actions und Charts.

## Features

- Server Actions für Daten
- Interaktive Charts
- Statistik-Karten
- Daten-Tabellen
- Responsives Layout

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- Next.js 14
- Server Actions
- Recharts
- Tailwind CSS
- TypeScript

## Erweiterungsmöglichkeiten

- Authentifizierung
- Dark Mode
- Export-Funktionen
