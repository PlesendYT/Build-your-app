# Spring WebApp Template

## Beschreibung

Webanwendung mit Spring Boot 3 und Thymeleaf.

## Features

- Spring Boot 3
- Thymeleaf-Templates
- Spring Data JPA
- Formularvalidierung
- Session-Handling

## Verwendung

```bash
./mvnw spring-boot:run
```

## Tech Stack

- Spring Boot 3
- Thymeleaf
- Spring Data JPA
- H2/PostgreSQL

## Erweiterungsmöglichkeiten

- Spring Security Login
- Internationalisierung
- Datei-Upload
