# Spring Batch Template

## Beschreibung

Batch-Verarbeitung mit Spring Batch und Spring Boot 3.

## Features

- Spring Batch
- Chunk-basierte Verarbeitung
- ItemReader/Processor/Writer
- Job-Parameter
- Scheduling

## Verwendung

```bash
./mvnw spring-boot:run
```

## Tech Stack

- Spring Boot 3
- Spring Batch
- Spring Data JPA
- H2/PostgreSQL

## Erweiterungsmöglichkeiten

- Multi-Step-Jobs
- Partitionierung
- Datenvalidierung
