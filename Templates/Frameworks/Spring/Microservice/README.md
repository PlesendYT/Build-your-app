# Spring Microservice Template

## Beschreibung

Microservice mit Spring Boot 3, Eureka und Cloud-Konfiguration.

## Features

- Spring Boot 3
- Eureka/Service Discovery
- Spring Cloud Config
- Resilience4j
- Distributed Tracing

## Verwendung

```bash
./mvnw spring-boot:run
```

## Tech Stack

- Spring Boot 3
- Spring Cloud
- Eureka
- Resilience4j
- PostgreSQL

## Erweiterungsmöglichkeiten

- API Gateway (Spring Cloud Gateway)
- Event Bus (RabbitMQ/Kafka)
- Docker Compose
