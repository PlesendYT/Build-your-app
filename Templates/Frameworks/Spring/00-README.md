# Spring Templates

Übersicht aller Spring-Template-Vorlagen für die Build-Your-App Plattform.

## Verfügbare Templates

| Template | Beschreibung |
|----------|-------------|
| **RESTAPI** | REST-API mit Spring Boot 3 |
| **WebApp** | Webanwendung mit Thymeleaf |
| **Microservice** | Microservice mit Eureka/Discovery |
| **Batch** | Batch-Verarbeitung mit Spring Batch |

## Gemeinsame Technologien

- Spring Boot 3 mit Java 17+
- Spring Data JPA / Hibernate
- Spring Security
- Maven/Gradle
- H2/PostgreSQL-Datenbank

# Spring Templates

Overview of all Spring template presets for the Build-Your-App platform.

## Available Templates

| Template | Description |
|----------|-------------|
| **RESTAPI** | REST API with Spring Boot 3 |
| **WebApp** | Web application with Thymeleaf |
| **Microservice** | Microservice with Eureka/Discovery |
| **Batch** | Batch processing with Spring Batch |

## Shared Technologies

- Spring Boot 3 with Java 17+
- Spring Data JPA / Hibernate
- Spring Security
- Maven/Gradle
- H2/PostgreSQL database
