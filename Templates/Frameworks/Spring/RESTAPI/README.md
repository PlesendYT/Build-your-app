# Spring RESTAPI Template

## Beschreibung

REST-API mit Spring Boot 3, JPA und Records.

## Features

- Spring Boot 3
- Java Records für DTOs
- Spring Data JPA
- Spring Security
- Swagger/OpenAPI
- H2-Datenbank

## Verwendung

```bash
./mvnw spring-boot:run
```

## Tech Stack

- Spring Boot 3
- Java 17+
- Spring Data JPA
- Spring Security
- H2/PostgreSQL

## Erweiterungsmöglichkeiten

- JWT Authentifizierung
- Spring Cloud
- Message-Integration
