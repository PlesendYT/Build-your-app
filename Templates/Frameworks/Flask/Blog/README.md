# Flask Blog Template

## Beschreibung

Blog-Plattform mit Flask, SQLAlchemy und Admin-Interface.

## Features

- Blog-Posts
- Kommentare
- Kategorien
- Admin-Interface
- Markdown-Unterstützung

## Verwendung

```bash
pip install -r requirements.txt
python run.py
```

## Tech Stack

- Flask
- SQLAlchemy
- Flask-Admin
- Flask-Login

## Erweiterungsmöglichkeiten

- RSS-Feed
- Suchfunktion
- Tags
