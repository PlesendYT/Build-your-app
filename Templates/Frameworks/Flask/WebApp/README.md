# Flask WebApp Template

## Beschreibung

Vollständige Flask-Webanwendung mit Blueprints und SQLAlchemy.

## Features

- Blueprint-Struktur
- SQLAlchemy ORM
- Jinja2 Templates
- Formularverarbeitung
- Session-Management

## Verwendung

```bash
pip install -r requirements.txt
python run.py
```

## Tech Stack

- Flask
- SQLAlchemy
- Jinja2
- SQLite

## Erweiterungsmöglichkeiten

- Flask-Login Auth
- Flask-Admin
- REST-API
