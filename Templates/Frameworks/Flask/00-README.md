# Flask Templates

Übersicht aller Flask-Template-Vorlagen für die Build-Your-App Plattform.

## Verfügbare Templates

| Template | Beschreibung |
|----------|-------------|
| **WebApp** | Vollständige Webanwendung mit Blueprints |
| **RESTAPI** | REST-API mit Flask-RESTful |
| **Blog** | Blog-Anwendung mit SQLAlchemy |
| **Microservice** | Microservice mit Docker-Unterstützung |

## Gemeinsame Technologien

- Flask mit Blueprints
- SQLAlchemy für Datenbank
- Flask-RESTful für APIs
- Jinja2 Templates
- Gunicorn als WSGI-Server

# Flask Templates

Overview of all Flask template presets for the Build-Your-App platform.

## Available Templates

| Template | Description |
|----------|-------------|
| **WebApp** | Full web application with Blueprints |
| **RESTAPI** | REST API with Flask-RESTful |
| **Blog** | Blog application with SQLAlchemy |
| **Microservice** | Microservice with Docker support |

## Shared Technologies

- Flask with Blueprints
- SQLAlchemy for database
- Flask-RESTful for APIs
- Jinja2 Templates
- Gunicorn as WSGI server
