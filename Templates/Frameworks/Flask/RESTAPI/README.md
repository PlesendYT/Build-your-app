# Flask RESTAPI Template

## Beschreibung

REST-API mit Flask-RESTful und SQLAlchemy.

## Features

- Flask-RESTful Resources
- Request Parsing
- Serialization
- CORS-Unterstützung

## Verwendung

```bash
pip install -r requirements.txt
python run.py
```

## Tech Stack

- Flask
- Flask-RESTful
- SQLAlchemy
- Marshmallow

## Erweiterungsmöglichkeiten

- JWT Auth
- Swagger-Dokumentation
- Rate Limiting
