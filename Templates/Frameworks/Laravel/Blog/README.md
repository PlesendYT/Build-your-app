# Laravel Blog Template

## Beschreibung

Blog-Plattform mit Laravel, Eloquent und Admin-Bereich.

## Features

- Blog-Posts mit Kategorien
- Kommentarsystem
- Tags
- Admin-Dashboard
- SEO-freundliche URLs

## Verwendung

```bash
composer install
php artisan migrate --seed
php artisan serve
```

## Tech Stack

- Laravel 11
- Eloquent ORM
- Blade
- MySQL/PostgreSQL

## Erweiterungsmöglichkeiten

- Newsletter
- Social Sharing
- Markdown-Editor
