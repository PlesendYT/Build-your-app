# Laravel ECommerce Template

## Beschreibung

E-Commerce-Plattform mit Laravel, Livewire und Warenkorb.

## Features

- Produktkatalog
- Warenkorb (Session/Database)
- Livewire-Komponenten
- Bestellverwaltung
- Admin-Bereich

## Verwendung

```bash
composer install
php artisan migrate --seed
php artisan serve
```

## Tech Stack

- Laravel 11
- Livewire
- Eloquent ORM
- Alpine.js
- Tailwind CSS

## Erweiterungsmöglichkeiten

- Stripe/PayPal
- Bewertungen
- Rabattcodes
