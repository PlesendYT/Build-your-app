# Laravel Templates

Übersicht aller Laravel-Template-Vorlagen für die Build-Your-App Plattform.

## Verfügbare Templates

| Template | Beschreibung |
|----------|-------------|
| **WebApp** | Vollständige Webanwendung mit Blade |
| **RESTAPI** | REST-API mit Laravel Sanctum |
| **Blog** | Blog-Plattform mit Eloquent |
| **ECommerce** | E-Commerce-Anwendung mit Livewire |

## Gemeinsame Technologien

- Laravel 11 mit Eloquent ORM
- Blade-Templates
- Laravel Sanctum für API-Authentifizierung
- Migrationen und Seeder
- Vite als Build-Tool

# Laravel Templates

Overview of all Laravel template presets for the Build-Your-App platform.

## Available Templates

| Template | Description |
|----------|-------------|
| **WebApp** | Full web application with Blade |
| **RESTAPI** | REST API with Laravel Sanctum |
| **Blog** | Blog platform with Eloquent |
| **ECommerce** | E-commerce application with Livewire |

## Shared Technologies

- Laravel 11 with Eloquent ORM
- Blade templates
- Laravel Sanctum for API authentication
- Migrations and seeders
- Vite as build tool
