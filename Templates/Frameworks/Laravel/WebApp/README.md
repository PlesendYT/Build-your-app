# Laravel WebApp Template

## Beschreibung

Vollständige Laravel-Webanwendung mit Blade-Templates und Eloquent.

## Features

- Blade-Templates
- Eloquent ORM
- Laravel Mix/Vite
- Authentifizierung
- Formular-Validierung

## Verwendung

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

## Tech Stack

- Laravel 11
- Eloquent ORM
- Blade
- Vite
- SQLite/MySQL

## Erweiterungsmöglichkeiten

- Livewire
- Filament Admin
- API mit Sanctum
