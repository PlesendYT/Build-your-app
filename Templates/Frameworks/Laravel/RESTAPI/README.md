# Laravel RESTAPI Template

## Beschreibung

REST-API mit Laravel Sanctum und API-Resources.

## Features

- Laravel Sanctum Auth
- API Resources
- Form Request Validation
- Rate Limiting
- CORS

## Verwendung

```bash
composer install
php artisan migrate
php artisan serve
```

## Tech Stack

- Laravel 11
- Laravel Sanctum
- API Resources
- MySQL/PostgreSQL

## Erweiterungsmöglichkeiten

- OAuth Integration
- API Versionierung
- WebSockets
