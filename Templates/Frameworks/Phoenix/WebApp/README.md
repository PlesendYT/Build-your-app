# Phoenix WebApp Template

## Beschreibung

Vollständige Phoenix-Webanwendung mit Ecto und Templates.

## Features

- Phoenix Router
- Ecto ORM
- HTML-Templates (HEEx)
- LiveView-bereit
- PostgreSQL

## Verwendung

```bash
mix deps.get
mix ecto.migrate
mix phx.server
```

## Tech Stack

- Phoenix
- Elixir
- Ecto
- HEEx Templates
- PostgreSQL

## Erweiterungsmöglichkeiten

- LiveView
- PubSub
- API-JSON
