# Phoenix LiveView Template

## Beschreibung

Echtzeit-WebApp mit Phoenix LiveView und Socket-Kommunikation.

## Features

- LiveView Echtzeit-UI
- Socket-Verbindung
- State-Management
- Events
- Templates

## Verwendung

```bash
mix deps.get
mix phx.server
```

## Tech Stack

- Phoenix
- LiveView
- Elixir
- HEEx
- PostgreSQL

## Erweiterungsmöglichkeiten

- Charts (LiveView)
- Chat
- Dashboard
