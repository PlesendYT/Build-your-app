# Phoenix RESTAPI Template

## Beschreibung

REST-API mit Phoenix, JSON-Responses und Ecto.

## Features

- JSON API
- Ecto Queries
- Changesets
- CORS
- API-Versionierung

## Verwendung

```bash
mix deps.get
mix ecto.migrate
mix phx.server
```

## Tech Stack

- Phoenix
- Elixir
- Ecto
- JSON
- PostgreSQL

## Erweiterungsmöglichkeiten

- JWT Auth
- GraphQL (Absinthe)
- Rate Limiting
