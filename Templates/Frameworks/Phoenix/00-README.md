# Phoenix Templates

Übersicht aller Phoenix-Template-Vorlagen für die Build-Your-App Plattform.

## Verfügbare Templates

| Template | Beschreibung |
|----------|-------------|
| **WebApp** | Vollständige Webanwendung mit Phoenix |
| **RESTAPI** | REST-API mit JSON-Antworten |
| **LiveView** | Echtzeit-WebApp mit LiveView |
| **Realtime** | Echtzeitanwendung mit PubSub |

## Gemeinsame Technologien

- Phoenix mit Elixir
- LiveView für Echtzeit-UI
- Ecto für Datenbankzugriff
- PubSub für Kommunikation
- Phoenix Channels für WebSockets

# Phoenix Templates

Overview of all Phoenix template presets for the Build-Your-App platform.

## Available Templates

| Template | Description |
|----------|-------------|
| **WebApp** | Full web application with Phoenix |
| **RESTAPI** | REST API with JSON responses |
| **LiveView** | Real-time web app with LiveView |
| **Realtime** | Real-time application with PubSub |

## Shared Technologies

- Phoenix with Elixir
- LiveView for real-time UI
- Ecto for database access
- PubSub for communication
- Phoenix Channels for WebSockets
