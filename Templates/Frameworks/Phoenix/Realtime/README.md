# Phoenix Realtime Template

## Beschreibung

Echtzeitanwendung mit Phoenix PubSub und Channels.

## Features

- Phoenix PubSub
- Channels/WebSockets
- Presence-Tracking
- Broadcasts
- Skalierbar

## Verwendung

```bash
mix deps.get
mix phx.server
```

## Tech Stack

- Phoenix
- PubSub
- Channels
- Elixir
- Redis/PostgreSQL

## Erweiterungsmöglichkeiten

- Chat-System
- Live-Benachrichtigungen
- Multiplayer
