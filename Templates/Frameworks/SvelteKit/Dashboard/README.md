# SvelteKit Dashboard Template

## Beschreibung

Dashboard mit SvelteKit, Stores und Charts.

## Features

- Svelte Stores
- Datenvisualisierung
- Statistik-Karten
- Daten-Tabellen
- Responsive Layout

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- SvelteKit
- Svelte Stores
- Chart.js (optional)
- TypeScript
- CSS

## Erweiterungsmöglichkeiten

- Dark Mode
- Export-Funktionen
- Auth
