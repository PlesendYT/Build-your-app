# SvelteKit WebApp Template

## Beschreibung

Vollständige SvelteKit-Webanwendung mit Routing und Stores.

## Features

- SvelteKit Routing
- Svelte Stores
- Formularverarbeitung
- API-Endpunkte
- SSR/SSG

## Verwendung

```bash
npm install
npm run dev
```

## Tech Stack

- SvelteKit
- Svelte Stores
- TypeScript
- Vite
- CSS

## Erweiterungsmöglichkeiten

- Auth
- Datenbank (Prisma/Supabase)
- PWA
