Component escapes everything except A–Z a–z 0–9 - _ . ! ~ * ' ( ). URI keeps ; , / ? : @ & = + $ # intact. Path segment encodes / so the value is safe inside a single path piece. Form encodes spaces as +, like browsers do for HTML forms.
